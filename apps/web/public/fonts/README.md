`GakjaShare-Semibold.ttf` is a static weight 600, glyph-subset derivative of the
bundled `PretendardVariable.woff2`, renamed Gakja Share in accordance with the
reserved font name requirement. It contains only the Korean and Latin characters
used in the Open Graph card and avoids runtime font downloads.
