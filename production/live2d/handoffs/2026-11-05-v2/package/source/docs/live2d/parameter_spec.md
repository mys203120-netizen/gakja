# 면접관 파라미터 계약

작성일: 2026-11-04, Asia/Seoul.

아래 ID·범위·기본값은 두 전용 면접관의 **제작 계획값**이다. 실제 `.moc3` 내보내기가 없어 모델에서 추출한 값이 아니다. 모델을 연결하기 전에 Core가 반환하는 실제 목록과 대조하고 차이가 있으면 명세·곡선·MotionSync 설정을 함께 수정해야 한다.

모든 수치는 **모델 파라미터 값**이다. `Angle`이 들어간 ID라도 숫자를 실제 회전 각도로 해석하지 않는다. `-0.3`이 어느 방향으로 얼마나 움직일지는 모델의 변형 설계에 달려 있다. 이전 문서에 물리적 각도 기호로 설명한 부분이 있다면 이 명세의 해석을 우선한다.

## 모션 파일이 사용하는 ID

남성 `interviewer-1`과 여성 `interviewer-2`는 아래 ID를 각자의 모델 인스턴스에서 독립적으로 가진다. 같은 ID명은 두 모델의 수치·상태를 공유한다는 뜻이 아니다.

| 계획 ID | 의미 | 계획 최소 / 최대 / 기본 | 이번 모션 데이터의 절댓값 상한 | 담당·충돌 조건 |
|---|---|---|---|---|
| `ParamAngleX` | 고개의 좌우 변형 | -5 / 5 / 0 | 0.50 이하, 실제 최대 0.28 | head/body 모션과 director 중 한쪽만 쓰기 |
| `ParamAngleY` | 고개의 상하 변형 | -4 / 4 / 0 | 0.40 이하, 실제 최대 0.32 | 모델 연결 후 위/아래 부호 확인 |
| `ParamAngleZ` | 고개의 기울임 변형 | -3 / 3 / 0 | 0.15 이하, 실제 최대 0.055 | 안경·귀·목·머리의 함께 변형 확인 |
| `ParamBodyAngleX` | 몸통의 좌우 자세 | -2 / 2 / 0 | 0.12 이하, 실제 최대 0.055 | 새로 제안한 ID. 현재 director에 없음 |
| `ParamBodyAngleY` | 몸통의 전후 자세 | -2 / 2 / 0 | 0.10 이하, 실제 최대 0.045 | 새로 제안한 ID. 책상·소매 접촉 유지 필요 |
| `ParamBodyAngleZ` | 몸통의 작은 기울임 | -2 / 2 / 0 | 0.08 이하, 이번 파일은 0 | 새로 제안한 ID. 미래 확장용 중립 채널 |
| `ParamQuestionGesture` | 기본 손 자세↔질문 손짓 | 0 / 1 / 0 | **0 고정** | 책상·펜 가림 검수 전 비활성 |

여성 파일은 같은 상한 안에서 고개/몸 값에 0.88 강도를 적용한다. 세부 값·시간은 각 motion3 파일과 `catalog.json`이 실제 기록이다. Listening의 고개 세 채널은 모두 0이며 몸통의 낮은 강도 변화만 있다. 기본 자세에 손·턱 접촉을 넣지 않는다.

모션 시작·끝은 기본값이며 `ReturnToNeutral`의 블렌딩은 현재 자세 또는 outgoing motion에서 인계해야 한다. 기본값으로 끝난다는 사실만으로 중간 취소의 매끄러운 복귀가 자동 보장되지는 않는다.

## 표정 파일이 사용하는 ID

| 계획 ID | 의미 | 계획 최소 / 최대 / 기본 | 이번 표현 범위 | 담당·충돌 조건 |
|---|---|---|---|---|
| `ParamBrowLY`, `ParamBrowRY` | 좌/우 눈썹의 높이 | -1 / 1 / 0 | 0–0.025 | exp3. 머리 모션·깜빡임은 쓰지 않음 |
| `ParamBrowLAngle`, `ParamBrowRAngle` | 좌/우 눈썹의 모양 변화 | -1 / 1 / 0 | -0.018–0 | exp3. 실제 눈썹 변형 부호 확인 |
| `ParamEyeLSmile`, `ParamEyeRSmile` | 좌/우 눈 주변의 미세 표정 | 0 / 1 / 0 | 0–0.060 | exp3. 눈 열림 채널을 직접 덮지 않음 |

모든 표정의 계획 안전 상한은 절댓값 0.08이다. 여성 표정값은 남성의 0.92배다. `Neutral`은 위 채널 전부 0, `SoftSmile`은 낮은 눈 미소·눈썹 높이, `Attentive`는 미세한 눈썹 높이/모양만 사용한다. 세 파일 모두 입 열림·입꼬리·모음과 눈 깜빡임 채널을 포함하지 않는다.

현재 얼굴에 이미 그려진 미소를 이 표정값이 제거하거나 새 입 모양을 그려 주지는 않는다. 사용자가 승인한 원화 인상은 유지하고, 표정용 변형이 실제 리깅에 만들어진 뒤 이 작은 값의 효과를 검수한다.

## 실시간 제어용으로 예약하는 ID

아래는 현재 director 또는 향후 입 리깅의 계약이다. 이번 motion3/exp3에는 들어 있지 않다.

| 계획 ID | 계획 최소 / 최대 / 기본 | 소유자 | 실제 모델 연결 전 확인 |
|---|---|---|---|
| `ParamEyeLOpen`, `ParamEyeROpen` | 0 / 1 / 1 | 눈 깜빡임 director | 눈꺼풀·속눈썹·눈 흰자 마스크, 좌우 독립 시간 |
| `ParamEyeBallX`, `ParamEyeBallY` | -1 / 1 / 0 | 시선 director | 홍채가 흰자 밖으로 나오지 않는 작은 범위 |
| `ParamBreath` | 0 / 1 / 0.5 | 호흡 director | 머리/손 접촉을 깨지 않는 낮은 강도 |
| `ParamMouthOpenY` | 0 / 1 / 0 | 실제 출력 음성 립싱크 | 닫힌 입 기본값과 0–0.85 발화 범위의 형태 |
| `ParamMouthForm` | -1 / 1 / 0 | 실제 내보낸 입 설정에 따라 립싱크 전담 | 입꼬리/폭의 계획 채널. 표정 파일은 쓰지 않음 |
| `ParamA`, `ParamI`, `ParamU`, `ParamE`, `ParamO` | 각 0 / 1 / 0 | 실제 MotionSync 매핑에 포함될 경우 MotionSync | 선택적 계획 ID. 실제 모음 원화/변형·매핑이 있어야 함 |
| `ParamHairFront` 등 머리카락 보조 | 계획 -1 / 1 / 0 | 실제 physics3의 제한된 물리 연산 | 필수 ID로 단정하지 않음. 머리와 분리·과도 흔들림 방지 |

MotionSync가 사용하는 파라미터 목록의 정본은 **실제로 Editor가 내보낸 설정**이다. 위 모음 ID를 모델에 자동으로 생성하거나 이미 구현됐다고 가정하지 않는다. `ParamMouthOpenY`만 존재하는 모델로 다양한 입 모양이 완성됐다고 표시하지 않는다.

## 현재 코드와의 연결·소유권

검토 시점의 director는 `ParamAngleX/Y/Z`, `ParamEyeLOpen/ROpen`, `ParamEyeBallX/Y`, `ParamBreath`, `ParamMouthOpenY`, `ParamMouthForm`, `ParamQuestionGesture`를 만든다. head/body motion 파일을 현재 director와 동시에 그대로 적용하면 머리 ID가 충돌한다. 모션 재생 중에는 해당 ID를 director의 쓰기에서 제외하고 종료/취소 시 블렌딩하여 돌려주는 연결이 필요하다.

현재 renderer는 매 프레임 `loadParameters → director 값 → physics → 립싱크 → model.update` 흐름을 사용하며, 이번 motion3/exp3를 읽는 관리자는 아직 연결하지 않았다. 이번 산출물은 기존 앱 파일이나 재생 흐름을 변경하지 않았다.

권장 소유권은 다음과 같다.

- **입:** 실제 재생 중인 한 면접관의 출력 오디오만 사용. MotionSync가 가진 모든 ID는 일반 모션·표정·학생 마이크에서 제외한다.
- **머리/몸:** 현재 활성 모션 또는 director 중 하나. 값의 무조건 합산·마지막 쓰기 방식은 사용하지 않는다.
- **눈 열림/시선/호흡:** director 전담. 이번 모션/표정은 이 ID를 쓰지 않는다.
- **눈썹/눈 미소:** expression manager 전담. 표정 전환은 fade로 처리하고 경청 기본은 Neutral이다.
- **손:** `ParamQuestionGesture=0`. 별도 손 모션을 승인하기 전까지 누구도 비영점 값을 쓰지 않는다.
- **머리카락:** 실제 physics 설정만 담당. body/head/mouth 소유 ID를 물리 출력으로 덮는 설정은 재검토한다.

실제 모델 연결 전에 각 motion3/exp3/MotionSync/physics의 ID 집합을 합쳐 누락·중복 소유자를 검사해야 한다. 현재 코드가 모르는 ID를 건너뛰더라도 그 결과를 “구현 완료”로 계산하지 않는다. 특히 새로 제안한 몸통·눈썹·눈 미소 ID는 실제 내보내기에서 확인해야 한다.

## 검증 기록과 남은 일

`scripts/prepare-interviewer-motions.mjs --check`에서 실제 저장된 18개 파일의 ID 허용 목록, 제한 범위, 유한한 수치, 중립 시작/끝, 증가하는 시간, 구간/점 메타데이터, 손 0, 입·깜빡임 채널 배제와 catalog 해시를 확인했다. `--self-test`의 손상 사례 12개도 거부했다.

실제 모델에서 파라미터를 조회하거나 변형을 재생한 검증은 수행하지 않았다. 남은 일은 전용 모델의 실제 ID/범위 추출, 모션/표정 관리자와 소유권 인계 연결, 정지/취소/재개 상태의 형태 검사, 안경·목·손·책상 가림 검사, 실제 출력 음성 립싱크와 웹/모바일 검수다. 실제 내보내기 정보가 확보되면 계획 수치를 모델의 정본 값으로 바꾸고 재검사한다.
