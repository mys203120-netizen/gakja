# 눈·입 리깅 작업 명세

작성일: 2026-11-04. 승인된 남녀 원화를 사용한다. 사용자가 앞서 제안받은 네 가지 외형 보정은 건너뛰기로 했다. 아래는 **실제 PSD 파츠를 대상으로 하는 리깅 작업 명세**이며 메쉬·디포머·키폼을 제작했다는 보고가 아니다.

## 현재 실제 원화

각 캐릭터의 `public/live2d/production/interviewer-{1,2}/`에 원본 PSD 37레이어, 가져오기 PSD 35레이어, PNG 파츠와 캔버스 좌표가 있다. L/R은 캐릭터 본인 기준이며 화면 왼쪽은 캐릭터 오른쪽이다. 원화 캔버스는 1672×941이다. 별도의 1920×1080 장면에 놓을 때는 하나의 비율 변환을 사용한다.

눈: `EyeWhite_L/R`, `Iris_L/R`, `EyeHighlight_L/R`, `UpperLid_L/R`, `LowerLid_L/R`. 눈썹: `Brow_L/R`.

입: `UpperLip`, `LowerLip`, `Mouth_Inside`, `Teeth_Upper`, `Mouth_Skin_Occlusion`. 아래 치아와 별도 혀는 이번 원화에서 독립 파츠로 제작하지 않았다. 빈 레이어로 추가하지 않는다. 단일 입 사진을 세로로 늘이는 구조로 끝내지 않는다.

`Face_Base`는 눈·눈썹·입·안경·머리카락을 제거한 밑그림을 사용한다. 실제 관찰된 피부는 승인 원화에서 유지하고, 가려진 피부는 ImageGen 밑그림으로 보완했다. 눈동자 뒤 흰자와 반사광 아래 홍채는 추출 단계에서 국소적으로 보완했다. 숨겨진 영역을 원본과 정확히 동일하게 복원했다고 주장하지 않는다.

## 입 파라미터 선택

우선 **2축 리깅**을 선택한다. 계획 ID는 `ParamMouthOpenY`(0–1, 기본0), `ParamMouthForm`(-1–1, 기본0)다. 개별 A/I/U/E/O 파라미터를 이번 단계에서 추가하지 않는다. MotionSync는 실제 Editor가 내보낸 매핑만 사용한다.

키폼 작업표:

| MouthForm | Open=0 | Open=0.3 | Open=1 |
|---|---|---|---|
| -1 | 닫힌 중립에서 폭만 미세하게 좁힘 | 작은 둥근 입, 입술 두께 유지 | 과장 없이 둥글게 열린 입 |
| 0 | 승인된 닫힌 입 | 작게 벌린 말하기 입 | 기본 열린 입·자연스러운 입안·윗니 |
| 1 | 닫힌 상태에서 입꼬리 폭만 미세 확장 | 가로로 벌어지는 작은 입 | 가로형 말하기 입, 웃음·치아 노출 과장 금지 |

위 9개 키폼은 **제작할 목표**이며 현재 PSD에 완성된 키폼으로 저장되어 있지 않다. 열린 입·둥근 입·가로 입 원화는 형태 참고용이며 전체 얼굴 교체나 타임라인 고정 립싱크로 사용하지 않는다.

`Mouth_Skin_Occlusion`은 실제 피부 픽셀과 닫힌 입 틈을 가진 원화 파츠다. SDK 클리핑 기능이 아니다. Editor에서 입술·입안·치아의 가림을 설계하고, 입을 열 때 피부 가림 범위와 입술을 함께 변형해야 한다. 입안이 얼굴 밖으로 새거나 치아가 닫힌 입 위로 나오면 불합격이다. 치아 상단은 윗입술·윗턱을 따르고, 아랫입술과 턱 주변은 열림에 맞춰 작게 이동한다.

입 모서리·윗입술 봉우리·아랫입술·입 틈을 따라 메쉬를 수동 정리한다. 자동 메쉬 결과만으로 완료 처리하지 않는다. 메쉬 밀도는 실제 변형 범위로 결정하며 숫자를 맞추려고 정점을 추가하지 않는다. 입술 두께, 코와의 거리, 턱선이 여러 MouthForm/Open 조합에서도 유지되는지 확인한다.

## 눈·안경과 고개

눈 열림 0/1의 실제 모양을 만들고 홍채·하이라이트를 흰자/눈꺼풀의 클리핑 관계에 넣는다. 눈을 감을 때 홍채를 통째로 찌그러뜨려 눈꺼풀로 대신하지 않는다. 머리/안경/눈/눈썹을 같은 상위 머리 디포머에 두되 눈동자·눈꺼풀에는 독립된 변형이 필요하다. 안경 렌즈 부분은 투명이며 프레임의 렌더 파츠는 `Glasses_Frame` 하나로 준비했다.

작은 머리 움직임부터 만들고 실제 얼굴이 유지되는 범위만 사용한다. 파라미터 숫자는 물리적 회전 각도를 의미하지 않는다. 고개+입, 고개+눈 감기, 옅은 미소+입의 복합 상태를 확인한다. 짧은 머리의 물리 연산은 작게 유지한다. 팔과 펜은 현재 기본 자세를 유지하며 손 제스처 파라미터는 0이다.

## 실시간 소유권

실제 출력 오디오를 현재 발화자의 MotionSync에만 공급한다. 발화 중 입 두 축과 실제 설정에 포함된 모든 입 ID는 MotionSync가 전담한다. 일반 모션·표정은 입을 덮어쓰지 않는다. 학생 마이크는 별도 녹음 경로다. 무음·일시정지·취소·학생 답변에서는 입을 닫고, 중간 취소는 현재 포즈에서 중립으로 블렌딩해야 한다.

모션 18개 파일에는 입 파라미터가 없다. 그러나 실제 모델의 입 모양, 현재 오디오와의 분석 지연, 한국어 발음의 자연스러움은 전용 모델과 공식 Core를 실행해야 검증할 수 있다. 현재 `.motionsync3.json`을 빈 예시로 만들지 않았다.
