# 각자의답 웹 가이드북 목차 및 학습 콘텐츠 배치 기준 v3.0

> **버전:** v3.0 · **변경:** Major — 여섯 목차와 학습 데이터 보존, G02 전체 학생부 원문 열람·G04 근거 하이라이트/최소 동작으로 학생용 화면 계약 재설계.
> **기준:** 2026-10-29 통합 회의록, 용어집 v2.1. 아래 `00. 가이드북 사용법`은 화면 진입용 안내이며, **사용자에게 보여주는 주요 탐색 목차는 01~05와 부록의 6개**다.
>
> **확정:** 웹 가이드북이 기본 제공물이며, 별도 암기 핸드북 PDF·DOCX 제작·발행은 종료한다. 학생은 개인 답변·암기 키워드·메모를 편집하고 필요한 내용만 선택적으로 PDF 저장·인쇄할 수 있다. 전체 가이드북 자동 다운로드는 기본 제공 의무가 아니다.

## 웹 가이드북 공통 UI 규칙

1. 대·소단원 접기/펼치기와 빠른 목차 이동을 제공한다.
2. 학년·학생부 영역·면접 우선도 S/A/B/C/F로 활동·문항을 필터링할 수 있도록 **데이터를 구조화**한다.
3. **G04 예상 질문·답변에서 근거 원문을 팝업·별도 버튼 뒤에 숨기지 않는다.** G02는 원문 전체를 항목별로 열람하며 G04는 원문 전체와 질문·예상 답변을 함께 배치한다(모바일에서는 같은 화면의 분할·전환). 보조 보기 모드는 원문 접근성을 저해하지 않는 범위에서만 허용한다.
4. 필요한 위치에서만 검색·학년/영역/우선도 필터를 노출한다. 검색 결과 강조와 이전/다음 결과 탐색은 지원하되, G04의 **질문 근거 하이라이트는 텍스트 검색의 임의 매칭이 아닌 원문 좌표+source_ref 연결**로 구현한다. 검색/필터는 안정적인 `activity_id`, `question_id`를 재사용한다.
5. 동일 활동을 여러 장에 다시 나타낼 때 활동을 복제하지 않고 정본 ID를 참조한다.
6. 가이드북의 `실전 훈련`은 **콘텐츠 목차**, 앱의 `실전 모의면접`은 **실행 기능**으로 구별한다.
7. 웹 가이드북 본문에는 가상 AI 비서 플로팅 아이콘을 노출한다. AI 비서의 실제 화면 조작 범위는 개발 검증 전이다.

## 1. 웹 가이드북 — 확정 목차

### 00. 가이드북 사용법
#### 1. 면접 준비 로드맵
웹 가이드북, 암기 훈련실, 연습 면접·실전 모의면접을 어떤 순서로 활용할지 안내한다. 별도 암기 핸드북 교재는 발행하지 않는다.

#### 2. 자료 활용법
각 영역의 표시 기준, 면접 우선도, 인재상 태그, 전공 연계도 등 가이드북의 읽는 법을 설명한다.

---

### 01. 나의 면접 전략
#### 1. 지원 정보
지원 대학·학과·전형과 면접 방식, 평가요소 등 기본 정보를 정리한다.

#### 2. 진로·학업 흐름
학년별 진로 변화, 과목 선택, 성적 변화와 주요 탐구 흐름을 한눈에 정리한다.

#### 3. 핵심 키워드
학생을 대표하는 전공, 탐구, 인재상, 가치관 키워드를 추출해 정리한다.

#### 4. 대표 활동
면접에서 우선적으로 활용할 전공·탐구·학업·공동체 활동을 선별한다.

#### 5. 면접 우선순위
학생부 전체 내용 중 반드시 준비해야 할 활동과 질문의 우선순위를 제시한다.

---

### 02. 학생부 분석
#### 1. 기본정보·출결·수상·자격
학적사항, 출결 특이사항, 수상경력, 자격·인증 등 학생부에 실제 존재하는 항목의 **원문 전체를 원래 순서와 내용 그대로 열람**하고, 사실 확인이 필요한 항목은 분석 표시를 구분해 점검한다.

#### 2. 창의적 체험활동·봉사활동
자율·동아리·진로·봉사활동의 **전체 원문을 빠짐없이 열람**하고, 역할·과정·결과·전공 연결·인재상에 관한 분석은 원문과 구분한다.

#### 3. 교과 성적·세부능력 및 특기사항
과목·학년별 교과 기록과 **세특의 원문을 그대로 읽을 수 있게** 하며, 성적 추이·탐구 내용·교과 간 연결과 면접 가능성 판단은 별도의 해석 계층에서 제공한다.

#### 4. 독서활동·행동특성 및 종합의견
독서활동 및 행동특성·종합의견의 **원문을 그대로 열람**하고, 전공·가치관 질문이나 공동체 역량에 관한 해석은 원문과 구분하여 제공한다.

#### 5. 학생부 종합 흐름
학년 간 반복·확장된 주제, 진로 변화, 대표 탐구, 강점과 보완 지점을 종합적으로 정리한다.

---

### 03. 대학·학과 분석
#### 1. 대학·학과 이해
지원 대학과 학과의 교육 방향, 전공 특성, 주요 교육과정을 정리한다.

#### 2. 인재상·평가요소
대학 및 학과가 중시하는 인재상과 면접 평가요소를 정리한다.

#### 3. 면접 특성
면접 방식, 질문 경향, 평가 구조 등 해당 대학·학과의 면접 특성을 정리한다.

#### 4. 학생부 매칭
학생의 대표 활동과 전공·인재상·평가요소를 연결하여 적합성을 분석한다.

#### 5. 강조 전략
지원 대학·학과별로 어떤 활동과 키워드를 우선적으로 강조할지 정리한다.

---

### 04. 예상 질문·답변

> **표시 경계:** 아래 1~7은 질문 생성·콘텐츠 분류에 사용하는 **제작 기준의 세부 단위**이며, 사용자에게 질문 의도·꼬리질문·답변 설계 단계별 메뉴를 모두 표시하라는 뜻이 아니다. 사용자 G04 기본 화면은 **학생부 원문 전체 + 근거 강조 + 예상 질문·예상 답변 + 답변 수정 + 질문 저장**에 집중한다.

#### 1. 최우선 예상 질문
면접 우선도가 가장 높은 질문을 선별해 집중 대비 영역으로 정리한다.

#### 2. 학생부·활동 질문
학생부 원문, 활동 과정, 역할, 결과와 배운 점에서 도출되는 질문을 정리한다.

#### 3. 전공·탐구·학업 질문
전공 개념, 탐구 과정, 교과 학습, 독서 및 배경지식에서 확장되는 질문을 정리한다.

#### 4. 인재상·공동체 질문
리더십, 협업, 의사소통, 문제해결, 가치관 등 대학 인재상과 연결되는 질문을 정리한다.

#### 5. 대학·학과·공통·시사 질문
지원동기, 자기소개, 학업·진로계획, 대학·학과 특성, 관련 시사 이슈 질문을 정리한다.

#### 6. 답변 설계
제작 엔진 내부에서는 주요 질문별 **질문 의도·답변 소재·구조·발화본·키워드**를 계속 설계한다. 단, **학생에게 보이는 기본 G04 화면은 예상 질문과 예상 답변, 학생부 원문 및 근거 강조가 중심**이고 `질문 의도`·답변 설계 단계·암기 키워드 편집을 별도 버튼·카드로 전시하지 않는다. 학생은 `답변 수정하기`, `질문 저장하기`만 기본 행동으로 사용한다.

#### 7. 꼬리·근거 검증 질문
꼬리·반박·근거 검증 질문은 **질문 엔진의 사전 설계·검수 데이터**로 준비하되, G04에 `꼬리질문 보기` 버튼이나 미리 펼쳐지는 후속 질문 카드를 두지 않는다. 실제 F1/F2는 연습·실전 면접에서 실제 답변에 따라 생성·검수한다.

---

### 05. 실전 훈련
#### 1. 기억 구조화
답변을 문장째 외우지 않고 핵심 구조와 키워드로 복원할 수 있도록 정리하는 방법을 안내한다.

#### 2. 발화 훈련
답변 길이, 두괄식 전달, 말의 속도와 흐름 등 실제 발화를 위한 훈련 기준을 정리한다.

#### 3. 돌발·꼬리·반박 대응
예상하지 못한 질문, 꼬리질문, 반박·근거 검증 질문에 대응하는 기본 원칙을 정리한다.

#### 4. 모의면접·피드백
연습 면접(채팅·화상 선택)과 **화상 전용 실전 모의면접**의 활용법, 답변 수정 및 반복 훈련 방식을 정리한다.

#### 5. 면접 직전 점검
최종 확인할 사실, 답변, 준비물과 면접 당일 행동을 체크리스트 형태로 정리한다.

### 2.1 편집과 콘텐츠 관리

1. **학생 수정 가능:** 개인 답변, 암기 키워드, 개인 메모. 원본 내용은 revision으로 보존하고 학생 수정본은 별도 계층에 저장한다. 저장한 최신 수정본은 연습/실전 코칭의 **참고 문맥**으로 자동 연동하지만 정답·평가 루브릭으로 사용하지 않는다.
2. **학생 수정 불가:** OCR 원문, 검증된 활동 분석, 대학 공식자료, AI 질문의 생성 근거/판정 등. 오류가 있으면 정정 요청 흐름을 사용한다.
3. **선택 출력 대상:** 학생이 고른 질문/답변, 핵심 키워드, 사실 확인표, 면접 직전 요약 등 **선택한 항목**에 한정한다. PDF에는 대상 지원처, 발행/수정 버전, 출력 시점, 학생 식별이 필요한 경우 최소한의 표시를 유지한다.
4. **부분 출력 권한:** 학생 본인의 발행된 자료에만 허용. 비공개 다운로드로 제공하며 무권한 접근·대량 추출·원문 노출을 차단한다. 출력된 파일의 보관·외부 전송은 별도 개인정보 고지/운영 영역이다.
5. **암기 훈련실 이용:** 실전·몰입플랜에 한하며, 준비플랜 학생도 가이드북의 개인 답변 키워드 열람·편집은 가능하다. 4번 PRD 및 약관 초안의 접근 정책을 참고한다.
6. **지식한입·이슈픽:** 승인 출처와 발행일·검증일 구분; 상세 갱신 주기는 미확정이므로 날짜·출처 없이 최신 정보라고 단정하지 않는다.

### 2.2 가이드북 장별 검수

| 장 | 필수 검수 | 실패 시 처리 |
|---|---|---|
| 00 사용법 | 네 메뉴·용어·출력/편집 설명 정확성 | 설명 수정 |
| 01 면접 전략 | 지원처별 우선도·대표 활동·진로 흐름 근거 | 해당 지원처 발행 차단 |
| 02 학생부 분석 | 원문-활동 ID 정합성·민감정보 범위 | 중대 오류 시 발행 차단 |
| 03 대학·학과 | 입학연도/전형별 공식 검증 상태·교재와 구분 | 중요 정보 미검증이면 발행 차단 |
| 04 예상 질문·답변 | 질문 의도·원문·발화본의 사실 상태/ID 일관성 | 허위 전제·핵심 누락 시 차단 |
| 05 실전 훈련 | 실전·연습 정책·꼬리질문 상한·개별 개선법 | 상위 규정과 충돌 시 수정 |
| 부록 | 질문 모음·사실 확인표·재사용 참조 링크 | 핵심 참조 오류 시 차단 |

**목차 변경 통제:** 기존 `01~05 + 부록` 6개를 유지한다. `00 사용법`은 안내 영역이다. 본문 목차의 추가·삭제·재배치는 콘텐츠기획팀 승인 후 버전 개정으로만 시행한다.

## 3. 2026-11-02 승인: 화면별 콘텐츠 제공 규칙 (v3.0 주요 개정)

### 3.1 G02 학생부 분석 — Full Source Viewer

- `record_ocr_md`와 원본 파일에 대조 가능한 학생부 **모든 실제 항목**(학생별/연도별 존재하는 항목 포함)을 원문 누락·재서술 없이 열람한다. 기존 제1장 02의 5개 하위 분류는 **분석 제작의 분류**로 보존하되 학생용 원문 목차를 축약·삭제하는 근거로 사용하지 않는다.
- 학년·학생부 영역·과목 순서 등 원본의 계층 구조를 유지한다. 표·행·수치·기호와 학생의 실제 기록에 대한 위치 근거를 연결한다. 민감정보 또는 법적 제공 제한 영역은 안전한 공개 권한 규정에 따르며 임의 생략을 원문 완전성으로 홍보하지 않는다.
- **AI 분석 텍스트는 원문과 섞지 않는다.** 요약 카드가 전체 원문을 대체하지 않는다. `정정 요청`은 오류 발견 시 문맥 내에서 진입하되 읽기 화면에 툴바를 난립시키지 않는다.

### 3.2 G04 예상 질문·답변 — Evidence-linked Master–Detail

1. 학생부 전체 문서를 **기본 화면에 다시 표시**한다. PC는 원문/예상 질문·답변을 병렬로, 모바일은 원문 접근을 잃지 않는 같은 화면 내 전환 패턴으로 처리한다.
2. 질문을 바꾸면 연결된 `source_ref_id`, `record_revision`, `anchor_start/end` 또는 구조적 셀/문단 좌표를 사용하여 **정확한 원문 부분에 형광펜을 칠하고 해당 위치로 스크롤**한다. 검색어 일치 문자열만으로 위치를 추정하지 않는다. 근거 없는 공통 질문은 형광펜을 만들지 않는다.
3. 사용자 기본 콘텐츠는 **예상 질문 + 예상 답변**이다. `질문의 의도`, `원문 근거 보기`, `꼬리질문 보기`, `연습하기`, 별도 `다시 준비에 저장`, 답변 구조 단계·내부 평가 코드 노출을 삭제한다. 엔진 내부에서 평가 의도와 질문 기능은 **계속 보존**한다.
4. 사용자 주요 행동은 **`답변 수정하기`(수정 완료 `저장`)**와 **`질문 저장하기`(다시 눌러 저장 취소)** 두 가지로 제한한다. 저장된 질문은 `면접 연습실 → 연습 면접 → 내가 추가한 항목`으로 연결한다. 선택한 질문의 예상 답변은 **평가 정답이 아니다**.
5. 원문·분석·대학 공식자료는 학생이 편집할 수 없다. 질문이 가진 근거 위치가 깨지면 임의 강조를 중단하고 검수 오류 상태를 남긴다.

### 3.3 공통 화면 절제와 학습 콘텐츠 범위

- 메뉴 카드에는 **아이콘과 메뉴 이름만** 배치한다. 읽을 거리마다 별도의 설명·버튼·팝업을 넣지 않고 문맥 AI 비서로 이해를 돕는다.
- `00 가이드북 사용법`은 보조 안내이며 여섯 본문 목차를 늘리지 않는다. `G05 실전 훈련`은 실행 기능이 아니라 훈련법을 알려주는 콘텐츠다.
- 가이드북 내 개인 답변/키워드/메모 수정 권한 및 선택 출력은 유지하지만 **모든 장에 같은 편집·필터·출력 버튼을 강제 배치하지 않는다**. 해당 콘텐츠에 필요한 조작만 문맥적으로 제시한다.
- `지식한입`은 세특·탐구 관련 실제 영상·논문·보고서·공식 학습자료의 **썸네일·출처·관련성 중요도·즐겨찾기**를 표시하고, `이슈픽`은 검증된 시사 자료의 **출처·발행일·즐겨찾기·면접용 질문 저장**을 제공한다. 갱신 주기/추천 알고리즘은 아직 미확정이다.
