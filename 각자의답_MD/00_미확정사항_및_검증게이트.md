# 2026-11-02 미확정 사항 및 개발 검증 게이트

## 2. 개발팀과 추가 협의해야 하는 미확정 항목

| 항목 | 현재 상태 | 필요한 검증·결정 |
|---|---|---|
| 관리자 IA·권한 | **미확정** | 운영·검수·발행·이용권 복구·개인정보 접근 권한 분리 회의 |
| STT/TTS/화상 | **성능 검증 필요** | 실전 음질·한국어 발음·전사 정밀도·재접속·브라우저 지원·품질 합격기준 |
| 대학별 실전 운영 프로필 | **지원처별 검증 필요** | 공식 모집요강·면접 시간/면접관/서류기반 여부 출처·연도 점검 |
| 면접 리포트 상세 | **미정** | PDF 상세 내용·페이지 레이아웃 A/B/C, 누적 비교/표본·다른 지원처 간 비교 |
| 면접 직전 요약 | **D-1 확정, 세부 미정** | 시각·시간대·학생 일정 변경·복수 지원처·면접 후 조회 |
| 퀴즈 반복학습 | **방향 확정, 파라미터 미정** | 오류 가중치·신규 문항 혼합 비율·반복 간격·채점 규칙 |
| 지식한입/이슈픽 운영 | **기능 방향 확정, 운영 미정** | 출처 허용목록·저작권·썸네일 수급·실자료 링크 검증·갱신 주기 |
| OCR 근거 앵커 | **기능 필수, 정확도 측정 필요** | 표/문단 span, 중복 문장 처리, OCR 수정 시 앵커 재검증, G02 완전성 |
| 알림·결제·법률 | **미승인/검증 전** | 개인정보·보호자/학생 동의, 알림 공급사/PG, 환불·무기한 이용권 처리 |
| UX 권장 토큰·컴포넌트 | **디자인 제안** | 실제 UI 검수, 반응형·접근성·성능/모션 설정 |

**정책 보호:** 미확정 사항은 디자인 미리보기나 테스트 더미가 실제 사용 가능한 제품이라는 의미가 아니다. 기획 승인과 개발 품질 검증은 분리한다.

## 관리자 IA의 명시적인 보류

운영용 대시보드·학생부 검수·발행·대학 검증·고객 지원·감사 메뉴는 과거 **구상안**으로만 존재한다. 운영 담당자·개발팀과 별도 협의하여 권한·화면·감사 로그·개인정보 접근 통제를 결정한다. 학생용 IA 승인으로 관리자 메뉴가 승인된 것은 아니다.
