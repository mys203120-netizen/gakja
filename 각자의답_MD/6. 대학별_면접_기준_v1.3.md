# 각자의답 대학별 면접 특징 및 콘텐츠 적용 기준 v1.3

- 기준 자료: 「2027 면접바이블」 업로드 병합본
- 목적: 대학별 면접 형식·평가관점·콘텐츠 제작 포인트를 지원처별 분석에 적용
- 연계 문서: 「각자의답 학생부 분석·데이터 계약 기준 v2.2」

> **자료 수록 범위 주의**
> 업로드된 병합 PDF는 420 PDF 페이지이며, 책의 목차에는 177개 대학이 제시되어 있으나 현재 병합본의 대학별 본문(PDF p.188~419)에서 실제로 확인되는 대학은 88개교다. 나머지 89개교는 목차에는 있으나 현재 업로드본에 해당 대학의 본문 페이지가 포함되어 있지 않다. 이 문서는 누락된 대학의 특징을 추정하거나 외부지식으로 보완하지 않는다. 89개교는 `본문 미수록`으로 명시하여 원문 확보 후 추가하도록 한다.


> **v1.1 변경 범위:** 177개교 수록 여부 및 본문 88개교의 참고자료 내용은 **일절 임의 변경하지 않음**. 검증된 실전 모의면접 운영 프로필로 전환하는 **조건·필드·미확인 시 기본 정책**만 추가한다. 아래 대학별 면접관 수·시간은 2027 면접바이블의 참고 서술일 뿐, 최신 해당 입학연도 공식 확인 완료를 뜻하지 않는다.

## 0. 대학별 실전 모의면접 운영 프로필의 생성 규정

1. 본 문서의 대학별 서술은 `source_status=bible_reference`로 시작한다. 실제 적용 전 `admission_year`, `campus`, `department`, `admission_track`을 조합한 단위로 공식 대학 모집요강·면접 안내를 검증한다.
2. 대학의 일반 인재상과 특정 전형의 공식 평가요소를 별도 저장한다. 서로의 출처·효력을 혼동하지 않는다.
3. 서류기반 면접 실시 여부가 불확실하면 **대학 맞춤 실전 재현 모드**를 검증된 것으로 표시하지 않는다.
4. 공식 면접관 수가 확인되면 그 수를 적용한다. **미확인 시 가상 면접관 2인**을 기본 사용하며 UI에 `가상 기본 구성`임을 구분한다. 남성/여성 음성은 연출 설정으로 실제 면접관 성별을 재현한다고 주장하지 않는다.
5. 면접관 역할(학업·전공, 경험·인재상, 종합·진로)은 각자의답의 가상 분담이며 대학이 실제로 그렇게 배치한다고 표시하지 않는다. 학생·회차별 발화자 식별 및 꼬리질문 2개 상한을 유지한다.
6. 면접 시간·진행형식은 `verified_value`가 없으면 **임의의 실제 대학 수치로 채우지 않는다**. 사용자가 훈련을 선택하는 경우 별도 `simulation_default`로 명시할 수 있다.
7. 검증 정보에는 `source_url`, `source_title`, `verified_at`, `valid_admission_year`, `reviewer`, `verification_status`를 저장한다. 공식 갱신/변경 공지에 따라 재검토한다.
8. 제시문·MMI·교과 구술 등 비서류 영역은 본 엔진의 재현 범위에 포함하지 않는다. 복합 전형은 서류기반 부분만 범위를 분명하게 지정한다.

### 최소 프로필 필드 (제안 스키마)

```yaml
support_target_id: "TARGET-ID"
admission_year: 2027
university: "예시 대학교"
campus: null
department: "예시 모집단위"
admission_track: "예시 전형"
document_based_interview: unknown  # yes / no / unknown
interviewer_count:
  verified_value: null
  simulation_default: 2
  status: unverified
interview_duration_minutes:
  verified_value: null
  status: unverified
interview_method: unknown
evaluation_elements: []
source_status: bible_reference
official_source_url: null
verified_at: null
```

> 위 예시는 **가상 필드 구조**이며 예시 대학교가 실재한다거나 위 모집 조건이 존재한다는 뜻이 아니다. 정식 enum과 관리자 검증·승인 UI는 PRD v2.1에서 구현 규격으로 승인해야 한다.

## 1. 적용 원칙

1. 면접바이블 대학별 정보는 2027 대비 제작 참고자료로 사용한다.
2. 실제 학생 제작 시 해당 입학연도의 대학 공식 모집요강·면접 안내·변경 공지를 다시 확인한다.
3. `대학 전체 특징`과 `특정 전형/모집단위의 특징`을 혼합하지 않는다.
4. 제시문/교직/의학/실기/과학기술원 등 면접 방법론이 다른 전형은 일반 서류기반 질문 규칙과 분리한다.
5. 대학별 평가요소는 활동 우선도와 질문 우선순위를 조정하는 근거로 쓰되 학생에게 없는 경험을 만들지 않는다.

# 6. 업데이트 규칙
