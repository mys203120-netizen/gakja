# 각자의답 프로젝트 공식 용어집 v2.2

- **문서 지위:** 전 문서 공통 명칭 정본 · **기준일:** 2026-11-02
- **개정 규모:** Minor — 2026-11-02 학생용 IA 승인 반영(최상위 네 메뉴 유지, 하위 명칭·매체·행동 갱신)
- **근거:** 「각자의답 서비스 리뉴얼 통합 회의록(2026-10-29)」, 브랜드 정체성 v1.0, 면접 엔진 3문서
- **효력:** 용어의 정의·이름은 본 문서를 따르되, 평가 알고리즘은 각자의 해당 전문 가이드라인을 따른다.
- **상태 기호:** `확정`=회의 명시 결정, `방향 합의`=목적은 합의·세부 미정, `미정`=추후 확정 필요, `제안`=개발 규격 제안.

## 제1장 공통 원칙

1. 동일 개념에는 동일한 공식 명칭을 사용한다. 내부 필드명과 화면 표시명이 다르면 양쪽을 명시한다.
2. **각자의답**은 브랜드명이고, **개인맞춤 면접대비 서비스**는 서비스 설명명이다. 슬로건은 **「물음 너머에는 각자의 답이 있다」**를 유지한다.
3. **생기부**는 학생이 누르는 서비스 메뉴, **학생부**는 학교생활기록부 및 데이터 분석의 공적·내부 표현으로 구분한다. UI에서 학생부 분석 대목은 `학생부 분석`이라고 표시한다.
4. S/A/B/C/F는 **면접 우선도**로 학생의 능력 점수나 답변 완성도 등급이 아니다.
5. `가이드북`은 웹 중심 개인별 콘텐츠의 공식 이름이며 **분석 리포트**라고 이름 붙이지 않는다. **면접 리포트**는 실전 모의면접 결과물의 이름이다.
6. 고정 명칭과 미정 정책을 구별한다. 기능명이 정해졌다고 기능 범위·유료 권한·외부 API가 검증된 것은 아니다.

## 제2장 사용자 화면의 공식 IA

```text
비회원 메인 → 회원가입·온보딩 → MY 홈
MY 홈
 ├─ 생기부
 │   └─ 가이드북
 │       ├─ 나의 면접 전략
 │       ├─ 학생부 분석
 │       ├─ 대학·학과 분석
 │       ├─ 예상 질문·답변
 │       ├─ 실전 훈련
 │       └─ 부록
 │       [우측 하단 플로팅 AI 비서]
 ├─ 면접 연습실
 │   ├─ 연습 면접
 │   └─ 실전 모의면접
 ├─ 내 답변
 │   ├─ 답변 보관함
 │   ├─ 면접 리포트
 │   └─ 면접 직전 요약 [면접 D-1 공개, 세부 시각 미정]
 └─ 암기 훈련실
     ├─ 퀴즈
     ├─ 지식한입
     └─ 이슈픽
```

| 공식명 | 정의 | 구분·금지/폐기 표현 | 상태 |
|---|---|---|---|
| **MY 홈** | 로그인 후 지원처·면접 D-Day·진행상태와 네 기능 진입을 제공하는 개인 시작화면 | 기존 `MY대시보드`는 과거 명칭 | 확정 |
| **생기부** | 웹 가이드북을 읽고 AI 비서를 사용하는 최상위 기능 | 독립 `학교·학과` 메뉴는 두지 않음 | 확정 |
| **가이드북** | 개인 학생부와 지원처를 분석한 웹 콘텐츠. 여섯 목차로 탐색 | `분석 리포트`, 기본 다운로드 PDF 중심 교재가 아님 | 확정 |
| **AI 비서** | 가이드북 우측 하단 플로팅 캐릭터로 호출하는 개인화 도우미 | 독립 `챗`/전역 채팅 메뉴가 아님 | 확정 |
| **면접 연습실** | 연습 면접·실전 모의면접으로 들어가는 메뉴 | 퀴즈는 여기 두지 않음 | 확정 |
| **연습 면접** | 학년·영역·질문 선택, 재답변·문항별 코칭을 하는 집중 훈련 | 종합 점수 PDF가 아님 | 확정 |
| **실전 모의면접** | 검증된 전형 정보에 기반한 **화상 전용** 세션, 종료 후 종합 점수 PDF 리포트 | `압박 모드` 같은 과거 여섯 모드로 IA 분할 금지 | 확정 |
| **채팅 / 화상** | **연습 면접에서 선택하는 매체**. 실전 모의면접은 **화상 전용** | `채팅 실전 모의면접` 상품·설정 금지 | 확정 |
| **내 답변** | 답변 보관함(연습 세션별/실전 회차별), 누적 면접 리포트, 면접 직전 요약 | `기록`이라는 독립 탭·`오답노트` 금지 | 확정 |
| **답변 보관함** | `연습 면접`·`실전 모의면접`으로 분리; 연습은 세션별·지원처/질문유형 필터, 실전은 회차별·점수 표시; 답변별 대표 지정 | 질문 낱개 전체보기 및 `답변 비교` 독립 메뉴 금지 | 확정 |
| **면접 리포트** | 실전 모의면접 회차별 평가 PDF와 누적 결과 | 웹 가이드북과 다른 결과물 | 확정 |
| **보완 추천** | 연습 면접의 질문 선택에서 취약 질문을 다시 제안하는 **목록** | `다시 준비할 질문` **독립 메뉴 폐기**, 오답노트 금지 | 확정 |
| **면접 직전 요약** | 학생이 등록·확정한 개인 면접일의 **D-1부터 공개**하는 짧은 카드형 핵심 요약 | 시간대·공개 시각·일정 변경·내용 부족 시 예외는 미정 | 공개 시점 방향 확정/세칙 미정 |
| **암기 훈련실** | 퀴즈·지식한입·이슈픽의 상위 학습 메뉴 | `학습 라운지`, `리콜 훈련실`은 미채택 | 확정 |
| **퀴즈** | 지식·사실·답변 구조 회상, 복수 유형과 **오답 가중 반복학습** | 가중치·간격·유형별 채점 세칙 미정 | 핵심 기능 확정 |
| **지식한입** | 학생부·세특·전공 연계 실제 영상·보고서·검증 자료를 썸네일·중요도·즐겨찾기로 탐색 | 출처·추천·저작권 세칙 미정 | 기본 구성 확정 |
| **이슈픽** | 검증된 시사·전공 이슈, 즐겨찾기와 면접 질문 저장을 제공하는 콘텐츠 | 구명칭 `이슈픽`; 갱신주기·콘텐츠 검증 세칙 미정 | 명칭/핵심 기능 확정 |
| **암기 핸드북(구 제공물)** | 과거 별도 교재로 기획된 결과물; 독립 제작·발행 종료 | 학습 데이터와 키워드 압축 설계는 웹 가이드북·암기 훈련실로 이전 | 종료 확정 |

> **유의:** 아이스브레이킹·자기소개·마지막 자유발언의 채택 여부와 강도는 공통 운영 원칙 v1.2 및 질문 생성 가이드라인 v2.2을 따른다. `실전 훈련`은 가이드북 목차이고 `실전 모의면접`은 앱 실행 기능이다.

## 제3장 콘텐츠·학생부 데이터 용어

| 용어/필드 | 정의 | 반드시 구분할 개념 |
|---|---|---|
| **생기부 OCR MD** (`record_ocr_md`) | 원문의 학년·영역·과목·원문 텍스트와 위치를 보존하고 오류 검증한 원천 데이터 | **분석 의견을 삽입하지 않는다** |
| **생기부 분석 MD** (`record_analysis_md`) | 활동 정본·지원처별 우선도·인재상 태그·가이드북 목차별 투영을 담은 구조화 자료 | 가이드북의 **기초 데이터**. 단순 요약 아님 |
| **학생부 원문** (`source_ref`) | OCR의 특정 문장·위치·원본 개정 연결 | 학생이 확인한 추가 경험과 별개 |
| **Activity ID** (`activity_id`) | 하나의 실제 활동을 식별하는 안정적 ID | 동일 활동의 복수 기록은 `source_ref_ids[]` 연결 |
| **활동 요약** | 원문에서 확인되는 행동을 간결하게 요약한 설명 | 추론한 성과·감정과 구분 |
| **면접 우선도** | 지원처 맥락의 S/A/B/C/F 준비 우선순위 | 학생 능력의 점수 아님 |
| **인재상 태그** | 특정 활동이 실제 행동 근거로 보여주는 인재상·역량 연결 | 교사의 평가어 자체와 다름 |
| **전공 연계도** | 전공과 활동의 실제 연결 설명 | 근거 없는 수치 등급화 금지 |
| **대표 활동** | 전공·문제해결·협업·가치관 등 질문에서 중심으로 사용할 활동 | 무조건 S만을 지칭하지 않음 |
| **지원처** (`support_target_id`) | 입학연도·대학·캠퍼스·모집단위·전형의 조합 | 대학명 하나만으로 면접 프로필 확정 불가 |
| **가이드북 섹션** (`guidebook_section_id`) | 웹 가이드북 목차에 투영된 항목 | 독립 활동 복제 금지; 원 `activity_id` 참조 |
| **답변 발화본** | 학생이 실제로 말할 수 있도록 설계한 예시 표현 | 그대로 암기해야 하는 정답 아님 |
| **암기 키워드** | 경험·개념·논리를 복원하는 단서 | 독립 암기 핸드북 발행 종료에도 계속 유지 |
| **발행 버전** (`publication_revision`) | 학생에게 실제로 열람이 허용된 분석·가이드북 버전 | 제작 중 초안과 구분 |

### 원문·해석·승인 상태

- `RECORD`: 승인된 학생부 원문, `STUDENT_CONFIRMED`: 학생이 따로 확인한 실제 경험, `AI_INFERENCE`: 해석·후보(확정 사실 아님), `ADMISSION_VERIFIED`: 지원 전형의 공식 검증 정보.
- `confirmed_from_record / confirmed_by_student / needs_confirmation / student_says_different / cannot_confirm`은 분석의 확인 상태다. 질문·답변 문서의 추가 상태 코드는 해당 문서 계약을 적용한다.
- `학생부 원문 → OCR MD → 분석 MD → 웹 가이드북 → 면접·퀴즈·AI 비서`는 논리적 처리 흐름을 뜻하며, 실제 저장 형식·업로드·승인 정책은 PRD v2.1과 제작 프로세스 v2.1에서 정의한다.

## 제4장 질문·답변·면접 용어

- **평가 질문(Q0):** 질문 의도를 가진 기본 질문 1개. **질문 묶음** (`question_cluster_id`)은 Q0와 **최대 2개 F1/F2**를 포함한다.
- **꼬리질문(F1/F2):** 동일 묶음의 후속 평가 질문. 면접관 변경으로 상한이 초기화되지 않는다.
- **재진술(`CLARIFICATION`):** 원질문의 뜻을 쉽게 다시 묻는 비독립 발화. 평가 꼬리질문인 `CLARIFY_CONTENT`와 구분한다.
- **질문 기능(`primary_function`):** `FACT`, `MOTIVE`, `ROLE`, `PROCESS`, `CHOICE`, `CONCEPT`, `EVIDENCE`, `RESULT`, `LIMIT`, `ALTERNATIVE`, `TRANSFER`, `CONNECTION`, `VALUE`, `CLARIFY_CONTENT`, `VERIFY_CLAIM`의 15개 코드. 질문 하나는 주기능 1개를 가진다.
- **질문 깊이:** D1~D4(개별 질문의 인지적 요구). **난이도:** 면접 회차의 사용자 설정(초기 3단계, 기본 2단계). 다른 값이다.
- **답변 완성도:** 답변 가이드라인에 따른 질문별 내용 점수. **전략 코칭:** 지원처·질문에 더 적합한 활동 사용 제안. **답변 구조 코칭:** 질문 기능별 표준 답변 프레임 훈련. **화상 전달 코칭:** 음성/시선 관련 관찰(내용 점수와 구분).
- **면접관 프로필:** 전형 검증 수, 역할(학업·전공/공동체·인재상/종합), 음성. 인원 미확인 시 **가상 기본 2인**, 실제 대학의 확정 인원으로 표기 금지.
- **실전 평가 리포트:** 세션 종료 후 점수와 근거·보완 사항을 포함하는 PDF. 연습 면접은 문항별 코칭을 제공하며 실전용 종합 PDF를 제공하지 않는다.

## 제5장 상품·온보딩 용어

| 공식명 | 설명 | 확인 상태 |
|---|---|---|
| **준비플랜 / 실전플랜 / 몰입플랜** | 최종 확정된 세 플랜 공식 표시명(구 BASIC/STANDARD/PREMIUM) | 가격·회수·법적 약관 및 예외는 독립 특별약관 초안과 정책결정대장 참조 |
| **39,000 / 99,000 / 169,000원** | 준비/실전/몰입플랜 각각의 내부 합의 가격 | 결제 서비스 배포 및 대외 약관 v1.0 승인·법률 검토는 별도 |
| **실전 모의면접 추가 이용권** | 모든 플랜에서 별도 구매 가능하며 1회 7,900원. 사용기한 없음 | 결제·환불 분쟁 처리 등은 약관 검토 초안 관할 |
| **학생부 등록** | 구매 흐름을 거쳐 학생 자료 업로드하는 기능 | 입력·법적 적합성 확인 필요 |
| **완료 알림** | 가이드북이 실제 열람 가능해진 뒤 외부 메시지 전송 | 솔라핏(회의 명칭) 연동 검증 필요 |

`크레딧`은 UI 상품·이용권의 공식 용어로 사용하지 않는다. 준비플랜은 웹 가이드북·플로팅 AI 비서를 포함한다. 실전플랜·몰입플랜에는 이에 더해 연습 면접과 실전 모의면접, 암기 훈련실이 포함되며 **양자의 기능 종류는 동일하고 기본 이용량이 다르다.** 이용권·가격의 세부 규칙은 특별약관 검토 초안에서 관리하며, 해당 초안을 대외 확정 약관으로 간주하지 않는다.

## 제6장 금지하는 혼용과 기존 용어의 처리

| 이전 표현 | 처리 | 대체 |
|---|---|---|
| `MY대시보드` | 과거 문서 검색용 호환 별칭 | `MY 홈` |
