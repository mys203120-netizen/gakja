# 1. 전체 면접 대비 체계

## 1.1. 최초에 설정한 3단계 면접 대비 흐름

`2025 면접가이드북.pdf` 첫 페이지에서 서류기반 면접 준비를 다음 세 단계로 나누었다.

1. **서류 분석**
   - 서류에서 질문이 나올 수 있는 포인트를 찾는 단계

2. **예상 질의응답 도출**
   - 예상 질문과 답변을 구체적으로 작성하는 단계

3. **모의면접 및 반복 연습**
   - 면접을 실제로 연습하고 피드백하는 방법을 정리하는 단계

또한 위 세 단계를 통한 공통 대비 이후에는 **학교별 특성을 살려 언급할 내용을 정리**하는 흐름을 설정하였다.

즉, 기존 자료의 기본 순서는 다음과 같다.

```text
학교생활기록부
→ 서류 영역별 분석
→ 질문 가능 포인트 추출
→ 예상 질문 제작
→ 답변 구조화
→ 학교별 인재상·학과 특성 반영
→ 모의면접·반복 연습
```

## 2.6. 대표 활동을 별도로 지정한 방식

비고란에는 일부 활동을 특정 역량의 **대표 사례**로 지정하였다.

| 대표 성격 | 지정 활동 |
|---|---|
| 문제해결 대표 | 학급 방송작가 활동 |
| 협업 대표 | 생명 탐구 실험 동아리 부장 활동 |
| 리더십 대표 | 생명 탐구 실험 동아리 부장 활동 |
| 전공가치관 대표 | 독서토론회 |
| 전공관련활동 대표 | 주거 공간 디자인 실내 건축 모형 제작 활동 |
| 창의적 사고 대표 | 친환경 패션 상품 제작 활동 |

따라서 기존 데이터에서는 모든 활동을 동일하게 다루지 않고, 전체 활동 목록 안에서 **특정 질문 유형이나 역량을 대표할 활동을 별도로 지정**해두었다.

# 3. 생기부를 영역별로 읽는 방식

`2025 면접가이드북.pdf`에서는 학교생활기록부를 한 번에 읽지 않고 영역별로 분리하여 분석하였다.

큰 영역은 다음과 같다.

1. 출결사항
2. 창의적체험활동상황
3. 교과학습 발달상황 / 세부능력 및 특기사항
4. 행동특성 및 종합의견

# 4. 출결사항 분석

## 4.1. 분석한 내용

출결에서는 학년별로 다음 항목을 표 형태로 제시하였다.

- 수업일수
- 결석일수
- 지각
- 조퇴
- 결과
- 질병 / 미인정 / 기타 여부
- 특이사항

학생의 경우 3학년 미인정 결석이 상대적으로 많았고, 행동특성 및 종합의견에 수시 면접 전형 응시로 인한 미인정 결석 증가가 기재되어 있다는 점을 함께 연결하였다.

## 4.2. 출결에서 확인하려 한 평가 요소

자료에는 출결 특이사항을 통해 다음을 확인하는 방식이 적혀 있다.

- 특이사항의 원인
- 이후 보완한 내용
- 빠진 수업을 보충하기 위한 개인적 노력
- 성실성과 관련된 설명

## 4.3. 출결 예상 질문

실제로 다음과 같은 질문을 작성하였다.

- 1, 2, 3학년 때 꾸준히 질병 결석이 있는데 이유를 설명해볼래요?
- 결석에 의해 빠지게 된 수업을 보충하기 위해 노력한 것이 있나요?
- 3학년 때 미인정 결석이 꽤 있는데 특별한 이유가 있었나요?

# 5. 창의적체험활동 분석

## 5.1. 면접관이 물을 수 있는 질문 요소를 5개로 정리

창체에서는 특정 활동마다 다음 다섯 요소를 중심으로 질문을 만들었다.

1. **특정 활동의 전반적인 과정**
2. **특정 활동에 참여하게 된 동기**
3. **특정 활동 속 본인의 역할과 노력**
4. **생기부 속 전공·진로 관련 키워드의 의미**
5. **특정 활동을 통해 배운 점**

이 질문들을 통해 확인하는 요소로 다음을 제시하였다.

- 학습에서의 주도성
- 전공 관련 호기심과 적성
- 진로 탐색에 대한 노력
- 협업 능력
- 논리적 의사소통 능력

## 5.2. 창체 원문에서 표시하려 한 요소

창체 기록을 읽으면서 다음 항목을 찾아 표시하는 방식으로 구성하였다.

1. 개별 또는 집단 단위로 참여한 활동 경험
2. 교내 임원 활동 및 역할 분담 활동
3. 활동별 전공 또는 진로 관련 주요 키워드
4. 학생에게 의미가 있는 활동 주제와 주요 키워드
5. 독서 활동 속 도서명 및 키워드

또한 어떤 활동을 중요하게 볼지는 **강조하고 싶은 역량과 노력이 드러나는 활동 과정**, 그리고 **대학교별 인재상에서 어떤 역량에 무게를 두는가**와 연결하여 정리하였다.

## 10.2. 면접 진행 구조

면접 질문 흐름을 다음 세 부분으로 구분하였다.

1. 도입 질문
2. 본 질문
3. 마무리 질문

## 10.3. 활동·도서·주제에서 질문을 만드는 방식

활동명, 활동 주제, 도서명에 대해서는 다음 세 방향으로 질문을 파생하였다.

1. **왜?**
   - 이유가 무엇인가요?
   - 계기가 있나요?
   - 어떻게 참가하게 된 건가요?

2. **무엇을 어떻게?**
   - 어떤 활동이었나요?
   - 구체적으로 말해볼래요?
   - 무슨 역할을 했나요?
   - 어떤 노력을 했나요?

3. **그래서? 결과는?**
   - 활동을 통해 배운 점이 있나요?
   - 변화된 것이 있나요?

---

## 10.4. 전공 키워드·역량·성격에서 질문을 만드는 방식

전공 관련 키워드, 활동 속 주요 키워드, 공동체 역량, 성격에서는 다음 방향으로 질문하였다.

1. **왜?**
   - 왜 관심을 두게 되었나요?
   - 선정 계기가 있나요?
   - 왜 그렇게 생각했나요?

2. **무슨 뜻이지?**
   - 무엇을 의미하나요?
   - 무엇인지 설명해보세요.

3. **어떻게 생각하지?**
   - 어떻게 생각하나요?
   - 어떤 입장인가요?

# 11. 답변을 구조화한 방식

## 11.1. 기본 원칙

답변 작성 원칙을 다음 세 가지로 설정하였다.

1. **두괄식으로 답변한다**
2. **간결하게 답변한다**
3. **결론-동기-과정-결과 구조를 기본으로 한다**

## 11.2. 답변 길이

자료에서는 답변 길이를 다음과 같이 제시하였다.

- 전공 관련 내용처럼 강조할 발화: **1분 내외**
- 그 외의 답변: **30~40초 내외**

## 11.3. 활동 설명 질문의 구조

```text
결론
→ 활동 동기
→ 진행 과정
→ 활동 후 결과와 배운 점
```

## 11.4. 의견 질문의 구조

```text
주장
→ 근거
→ 사례
→ 주장 재정리
```

## 11.5. 답변 수정 순서

작성한 답변을 다시 다듬는 과정도 단계화하였다.

1. 전달하고자 하는 말을 한 문장으로 만든다.
2. 구체적인 설명을 붙인다.
3. 결론과 관계없는 내용을 제거한다.
4. 실제 발화 시간을 재며 분량을 조절한다.

# 25. 질의응답과 암기 핸드북의 변환 방식

동일한 내용을 두 문서에서 서로 다른 형식으로 만들었다.

예를 들어 `1순위 질의응답`에서:

```text
Q. 미래에는 어떤 형태의 원예를 지향하게 될 것으로 전망하나요?

A. 미래 원예는 IT, BT, RT와 같은 기술과 결합하여...
```

라고 장문 답변을 작성한 뒤, 핸드북에서는 다음과 같이 분해하였다.

```text
미래 원예와 조경 디자인의 발전 방향

1. 미래 원예의 발전
   ① 기술 융합: IT, BT, RT
   ② 기술 사례: 식물공장, 수경재배, 수직농업
   ③ 기술 목표: 효율성과 지속 가능성

2. 대도시 원예의 방향
   ① 문제: 공간적 제약
   ② 해결: 녹지 재배치, 접근성 향상
   ③ 개인 목표: 미래 원예 발전에 기여

3. 조경 디자인의 방향
   ① 심리적 안정
   ② 해당 요소의 연구와 적용
```

즉, 기존 파일에서 다음 두 형태를 별도로 제작하였다.

```text
질의응답집 = 실제 발화 문장
암기 핸드북 = 발화를 복원하기 위한 키워드·구조
```
