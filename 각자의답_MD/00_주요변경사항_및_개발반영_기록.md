# 각자의답 2026-11-02 주요 변경사항 및 개발 반영 기록

**근거:** 업로드된 13개 MD와 2026-11-02 PART1~6 승인·후속 UX 합의. 기존 자료의 내용과 새로운 승인 정책을 분리한다.

## 1. 이번 회의 반영 — 핵심 변경사항

### 1) 사용자 IA·공통 UX
- **최상위 4개 메뉴 고정:** `생기부 / 면접 연습실 / 내 답변 / 암기 훈련실`. 모바일 하단도 4개, 홈은 로고로 돌아간다. 상단 지원처 선택기 및 프로필 메뉴는 유지한다.
- **메뉴 아래 기능 설명 최소화:** 메뉴는 이름과 아이콘만으로 의미를 전달한다. 필요한 상태(`발행 중`, `잔여 3회`, `면접 하루 전 열려요`)만 표시한다.
- **기능의 유일한 소속:** 질문 저장은 가이드북/이슈픽에서 발생하지만 연습 면접의 `내가 추가한 항목`에서 사용한다. `다시 준비할 질문` 독립 메뉴는 폐기하고 `보완 추천` 목록으로 통합한다.
- 불필요한 CTA·팝업·독립 오답노트·전역 AI 챗·독립 암기 핸드북·홈 중복 메뉴는 생성하지 않는다.

### 2) 생기부·가이드북
- **G02:** 학생부를 요약 카드로 대체하지 말고 승인·공개 범위의 **원문 전체를 원래 항목과 순서대로 열람**한다. 활동 분석은 원문과 분리한다.
- **G04:** 예상 질문을 고르면 **전체 학생부의 정확한 근거 문장에 형광펜**을 표시한다. `source_ref_id + record_revision + anchor range` 등 안정적 좌표 연결이 필수이며 동일 문자열 오인 강조 금지. 학생부와 질문·예상답변을 같은 화면에 배치한다.
- **G04의 기본 버튼:** `답변 수정하기`/수정본 `저장`, `질문 저장하기`/저장 취소. `질문 의도`, `원문 근거 보기`, `꼬리질문 미리보기`, `연습하기` 버튼은 제거. 질문 의도 등 **엔진 내부 검수 데이터는 보존**한다.
- 가이드북 주요 목차 `01~05 + 부록` 6개, AI 비서의 가이드북 한정 플로팅, 선택적 부분 출력은 유지한다.

### 3) 연습·실전 모의면접
- **연습 면접:** 채팅/화상 선택 가능. `내가 추가한 항목`·`보완 추천`·가이드북 질문/AI 생성/직접 입력에서 연습. 묶음 Q0+최대 F1/F2 종료 후 피드백 제공.
- **연습 피드백:** `핵심 전달`·`구체성`·`논리`·`학생부 정합성` 같은 실제 평가 항목별 카드, 긍정/보완을 민트·코랄+레이블/아이콘으로 구분, 카드당 1~2문장. 마지막에 **답변 개선 방향 + 사실 기반 모범 답변 예시**. 공개 숫자 점수 없음.
- **피드백 버튼 두 개:** `다시 연습하기`, `다음`. 다시 연습하기에서는 필요 시 단일 질문/전체 묶음 선택. 재답변 이력은 보존하고 단일 질문 재연습에서 신규 F를 만들지 않는다.
- **실전 모의면접은 화상 전용:** 채팅/화상 선택 자체 삭제. 지원처 선택→마이크/카메라 검사→실제 작업에 연동된 3단계(`면접관이 학생부를 살펴보고 있습니다`→`면접관이 질문을 정리하고 있습니다`→`곧 면접장에 입장합니다`)→화상 면접. 허위 로딩시간/가짜 진행률 금지.
- **엔진 불변:** 질문 한 번에 하나의 핵심 평가 목적(비교 자체는 예외), 검증된 근거, F1/F2 최대 2개. 실전 Q0 정상 제시 시에만 이용권 차감, 10분 재접속, 기술 오류는 학생 감점 금지/이용권 복구. 기존 Q0 100%·70/30·70/15/15, 동일 묶음 평균 및 60%/2묶음 게이트 유지.

### 4) 내 답변·암기 훈련실
- **답변 보관함:** `전체보기` 없이 `연습 면접`/`실전 모의면접` 2탭. 연습은 세션별 묶음+지원처(미지정 `공통`)/질문 유형 필터, 실전은 회차별 묶음+점수/평가상태. 답변마다 **대표 답변 별표 지정**, 실제 발화 원본·점수 변경 없음.
- **면접 리포트:** 상단 누적 수치(평가 완료 회차·평균·최근·점수 추이), 하단 회차별 `Accordion`. 정상/부분/평가불능 상태 구분. **리포트 상세 내부·PDF A/B/C 레이아웃 미확정**.
- **면접 직전 요약:** 학생이 확인한 **개인 면접일 D-1** 공개. 사전 `면접 하루 전 열려요` 잠금, 이후 핵심 활동·질문·반복 보완·사실 확인·지원처 유의사항을 카드로 제공. 공개 시각/복수 지원처 예외 미정.
- **퀴즈:** 단일/복수 선택·순서 배열·짝 연결·빈칸 등의 목적 맞춤 유형 및 **오답 가중 반복출제**. 세부 가중치/간격은 미확정.
- **지식한입:** 세특·탐구·전공 연계 실제 영상·보고서 등 신뢰 가능한 자료, 대표 썸네일·원출처·관련성 중요도·즐겨찾기.
- **이슈픽:** 기존 `시사 코너` 교체. 검증된 시사 카드·썸네일·출처·발행일·즐겨찾기, 면접용 질문이 있을 때만 `질문 저장하기`로 연습 면접과 연결.

### 5) 공통 계정·관리 및 출시 주의
- 지원처 추가/유료 변경/무료 전환 구분, 개인 면접일 직접 등록, 요금제·실전 이용권·결제 내역·고객센터/계정 분리. 상품 금액·권한·환불 조항을 이번 UI 개정만으로 변경하지 않는다.
- **관리자 IA는 미확정**, 개발팀 공동 회의 후 승인한다. 기존 학생용 IA에서 관리자 화면을 신규 확정/개발 완료로 취급하지 않는다.
- 요금제·환불 특별약관은 **v0.2 검토 초안**이며 대외 공개·PG 운영·법적 고지의 승인본이 아니다.
- 가이드북 자동 발행의 기존 5대 Critical·차단 이력 건 사람 승인, 정본 버전·출처, 개인정보 보호·대학 공식 자료 재검증은 그대로 유지한다.

## 2. 개발팀과 추가 협의해야 하는 미확정 항목

| 항목 | 현재 상태 | 필요한 검증·결정 |
|---|---|---|
| 관리자 IA·권한 | **미확정** | 운영·검수·발행·이용권 복구·개인정보 접근 권한 분리 회의 |
| STT/TTS/화상 | **성능 검증 필요** | 실전 음질·한국어 발음·전사 정밀도·재접속·브라우저 지원·품질 합격기준 |
| 대학별 실전 운영 프로필 | **지원처별 검증 필요** | 공식 모집요강·면접 시간/면접관/서류기반 여부 출처·연도 점검 |
| 면접 리포트 상세 | **미정** | PDF 상세 내용·페이지 레이아웃 A/B/C, 누적 비교/표본·다른 지원처 간 비교 |
| 면접 직전 요약 | **D-1 확정, 세부 미정** | 시각·시간대·학생 일정 변경·복수 지원처·면접 후 조회 |
| 퀴즈 반복학습 | **방향 확정, 파라미터 미정** | 오류 가중치·신규 문항 혼합 비율·반복 간격·채점 규칙 |
| 지식한입/이슈픽 운영 | **기능 방향 확정, 운영 미정** | 출처 허용목록·저작권·썸네일 수급·실자료 링크 검증·갱신 주기 |
| OCR 근거 앵커 | **기능 필수, 정확도 측정 필요** | 표/문단 span, 중복 문장 처리, OCR 수정 시 앵커 재검증, G02 완전성 |
| 알림·결제·법률 | **미승인/검증 전** | 개인정보·보호자/학생 동의, 알림 공급사/PG, 환불·무기한 이용권 처리 |
| UX 권장 토큰·컴포넌트 | **디자인 제안** | 실제 UI 검수, 반응형·접근성·성능/모션 설정 |

**정책 보호:** 미확정 사항은 디자인 미리보기나 테스트 더미가 실제 사용 가능한 제품이라는 의미가 아니다. 기획 승인과 개발 품질 검증은 분리한다.

## 4. 상태 구분

- **확정:** 네 메뉴, 실전 화상 전용, 질문 저장 연계, 피드백 UI, 보관함 분리, 이슈픽 명칭, D-1 공개 방향, 퀴즈 오답 가중 기능 등.
- **권고/구현안:** 원문 앵커 스키마, 데이터 필드명, 디자인 컴포넌트·모션 토큰, 차트 산출 구현. 기술 승인 전 실제 스키마로 고정하지 않는다.
- **미확정:** 관리자 IA·리포트 최종 상세·STT/TTS 품질·학습자료 수집/갱신·법률/PG.
