[각자의답 개발팀 전달용] 2026.11.02 학생용 IA·UX 회의 반영 / 13개 MD 최신화

이번 전달본은 기존 13개 MD를 기반으로 사용자 화면·기능·상호작용 규칙을 갱신한 정본입니다. 13개 기존 원본, 13개 개정본, 파일별 diff, 해시 검증표, 변경 이력 및 미확정 목록을 ZIP에 포함했습니다. 문서별 버전 증가는 변경 폭에 따라 Major/Minor로 구분했습니다. 관리자 IA는 확정하지 않았으며 개발팀과 별도 협의 예정입니다.

[반드시 우선 반영할 사항]
1. 최상위 학습 메뉴는 생기부/면접 연습실/내 답변/암기 훈련실 4개만 유지. 공통 지원처 선택과 프로필 관리 외에 중복 메뉴/버튼 생성 금지. 메뉴명 아래 설명 문장은 원칙적으로 없애고 상태 안내만 유지.
2. 생기부 G02: 학생부 원문 전체를 실제 항목/학년/과목 순서로 열람 가능해야 함. 분석 요약 카드만으로 대체 불가.
3. G04: 학생부 전체와 예상 질문·예상 답변을 한 화면에 표시하고 선택 질문의 원문 근거에 형광펜 표시. source_ref_id+원문 버전+정확한 문장 좌표로 구현하며 추측 매칭 금지. 기본 버튼은 답변 수정·저장, 질문 저장·해제뿐. 원문 근거 팝업·질문 의도·꼬리질문 미리보기·즉시 연습 버튼 삭제. 질문 의도 등 내부 QA 데이터는 유지.
4. G04/이슈픽의 질문 저장은 연습 면접의 '내가 추가한 항목'으로 연결. '다시 준비할 질문' 독립 메뉴 삭제, 실제 기록 기반 '보완 추천'을 연습 질문 목록에 통합.
5. 연습 면접: 채팅/화상 선택 허용. Q0와 최대 F1/F2가 끝난 뒤 항목별 강점/보완 카드, 개선 방향, 사실 기반 참고 답변 제시. 숫자점수 없음. 기본 하단 버튼은 '다시 연습하기' / '다음' 2개. 단일/묶음 재연습 기능과 원본 답변 이력은 유지.
6. 실전 모의면접: 화상 전용 확정. 채팅/화상 선택 화면 삭제. 지원처 선택→카메라/마이크 검사→실제 처리에 연동된 3단계('면접관이 학생부를 살펴보고 있습니다'→'면접관이 질문을 정리하고 있습니다'→'곧 면접장에 입장합니다')→화상 진행. STT/TTS 품질 불량을 정상 평가로 처리하거나 가짜 로딩으로 은폐 금지.
7. 실전 이용권은 첫 평가 Q0 정상 제시 시에만 1회 차감, 동일 회차 10분 재접속 및 오류 복구 필수. Q0/F1/F2 100%·70:30·70:15:15, 유효 묶음 동일 평균, 60% 이상/최소 2묶음 부분 평가 게이트 유지. 전사 오류를 학생 답변 오류로 감점 금지.
8. 답변 보관함: 연습/실전 2탭만 사용('전체' 삭제). 연습은 세션 묶음+지원처/질문유형 필터, 실전은 회차 묶음+획득 점수. 각 답변 대표 지정(별표)은 원본 기록/평가 수정이 아님.
9. 면접 리포트: 누적 수치와 점수 추이 상단, 회차별 펼침(Accordion) 하단. 정상/부분/평가불능 결과 구분. 상세 구성/PDF 디자인은 아직 미확정.
10. 면접 직전 요약: 학생이 확인한 개인 면접일 D-1에 오픈. 이전에는 '면접 하루 전 열려요' 표시. 시각/일정 변경 등 세부 예외 추후 협의.
11. 암기 훈련실: '시사 코너' → '이슈픽' 용어 일괄 변경. 퀴즈는 복수 문제유형+오답 가중 반복학습. 지식한입은 세특/탐구 연계 영상·보고서 등의 실자료+썸네일·출처·중요도·즐겨찾기. 이슈픽은 시사 카드·출처·썸네일·즐겨찾기·검증된 질문 저장.
12. 계정/요금제/지원처 변경·추가/결제/고객센터는 승인 IA대로 유지. 상품 가격 및 법적 권리·환불 조건을 이번 UX 개선 명목으로 변경하지 않음. 특별약관은 v0.2 검토 초안으로 미승인 상태.
13. 관리자 IA는 미확정. 기존 관리자 메뉴 제안안을 승인본으로 간주하지 말고 개발팀 공동 회의에서 기능/역할/권한/검수 프로세스를 별도 확정해야 함.

[개발팀에서 우선 증명해야 하는 P0 기능]
- G02 원문 전체와 OCR 파일의 항목별 일치(누락 없음), G04 question_id→source_ref_id→앵커 하이라이트 정확성, 저장 질문→연습 목록 동기화.
- 질문마다 검증 가능한 근거와 단일 핵심 평가 목적 유지, 허위 전제 질문 차단, F1/F2 상한 준수.
- 실전 화상 음성 품질(TTS), 한국어 전사 정확도(STT), 미디어 권한/연결 실패 복구, 10분 세션 복원, 이용권 차감·복구 로그 실측.
- 연습 피드백의 사실 정합성, 숫자 점수 미노출, 실전 평가불능/부분 리포트 점수 규칙 검산.
- 내 답변 세션·회차 데이터 원본 보존, 정상 회차 누적 리포트, 지원처별 접근 격리.

[남은 협의]
관리자 IA와 권한, 리포트 상세/PDF A-B-C, STT/TTS 품질 수용 기준, 면접 직전 요약의 정확한 공개 시각과 복수 지원처 처리, 오답 가중 공식, 지식한입/이슈픽 출처 검수·갱신·저작권, 학생부/미디어 개인정보·외부 위탁·PG/환불 약관 승인 등은 미확정입니다. 검증되지 않은 기능을 구현 완료 또는 공식 대학 재현으로 표시하지 마세요.
