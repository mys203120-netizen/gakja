# 질문 영상의 로컬 움직임 관측 운영

2026-10-23부터 신규 `/api/nonverbal-analysis` 요청은 브라우저의 MediaPipe 추적을 사용합니다. **전체 영상 움직임 살펴보기**는 처음부터 끝까지 100ms 간격으로 영상 위치를 순서대로 디코딩하고, 최대 640px 프레임을 같은 출처의 Worker에서 처리합니다. 원본의 모든 촬영 프레임을 분석하거나 100ms 사이의 행동을 추정하는 기능은 아닙니다. 낮은 원본 프레임률에서는 여러 시간 위치에 같은 영상 프레임이 대응할 수 있습니다.

## 배포와 비용

`npm run dev/build --workspace=@gakja/web`의 pre hook가 `scripts/prepare-nonverbal-assets.mjs`를 실행합니다. 정확한 `@mediapipe/tasks-vision@1.1.1` 런타임과 공식 revision 1 Face/Pose/Hand 모델을 준비하며, 모델 SHA-256을 검증합니다. 생성된 `public/nonverbal/vendor/`와 `public/nonverbal/models/`가 배포 결과에 포함되어야 합니다. 오프라인 빌드는 검증된 모델을 미리 준비해야 합니다.

런타임은 같은 출처의 자산만 사용합니다. 새 관측에는 OpenAI 키, `NONVERBAL_ANALYSIS_ENABLED`, `NONVERBAL_ANALYSIS_MODEL`이 필요하지 않으며 외부 AI 사용료가 없습니다. 브라우저 계산·메모리·영상 다운로드와 서버 저장 자원은 사용합니다. GPT Live1을 도입하지 않았습니다.

## 관측과 표시

얼굴의 수직축 회전 근사값을 **얼굴 방향 이탈**로 표시합니다. 눈의 시선·동공·표정·감정·성격·태도·능력·합격 가능성을 측정하거나 평가하지 않습니다. 상체는 어깨 중심의 화면상 왕복, 손은 몸통에 대한 어깨 폭 단위의 왕복을 별도로 셉니다. 카메라 움직임이 섞일 수 있으므로 원본 확인을 안내합니다.

가림, 미검출, 화면 밖, 낮은 신뢰, 여러 사람, 디코딩 실패는 미관측 구간으로 남깁니다. 해당 채널의 상태를 초기화하므로 누락 전후를 연결해 횟수를 늘리지 않습니다. 얼굴 방향의 시작 또는 복귀가 확인되지 않으면 부분 구간만 표시합니다. 관측 비율은 계획된 시간 위치 중 좌표를 얻은 범위이며 정확도 확률이 아닙니다. 관측 0%는 행동 0회를 증명하지 않습니다.

구간 버튼은 같은 질문의 원본 영상 시점으로 이동합니다. `NonverbalReview({mediaId, durationSeconds?, videoUrl?, onSeek?})`의 부모 영상에 `data-nonverbal-media={mediaId}`를 붙이거나 `onSeek(seconds)`를 제공합니다. 자세한 집계 기준과 한계는 [연속 시간축 영상 관측 구현](local-video-tracking-2026-10-23.md)에 기록합니다.

## 권한·저장·취소

서버는 본인 매체, 동일 학생·면접·문항 연결, 면접 종료, 유효 문항, `answer_recording`, 영상 MIME, 저장 동의를 조회와 저장 때 확인합니다. `/api/nonverbal-analysis`의 `begin`은 소유 매체에 lease를 만들고, `cancel`과 `save`는 같은 lease를 요구합니다. 진행 중 중복 시작은 409이며 45분 지난 요청은 재시작할 수 있습니다. 취소 뒤 늦게 도착한 저장은 거절합니다. 완료된 현재 버전은 재처리하지 않고 반환합니다.

서버는 숫자 신호의 전체 시간축·순서·길이·품질과 좌표의 대응을 검사하고 관측 결과를 재계산합니다. 프레임 이미지, 원본 얼굴 랜드마크, 음성은 전송하지 않습니다. 계산에 사용한 숫자 신호도 영속 저장하지 않고 구간·횟수·미관측·모델 버전만 `media_assets.metadata.nonverbalTimeline`에 저장합니다. 원본 영상 바이트는 그대로 보존합니다. 클라이언트 숫자 신호가 원본에서 생성되었다는 암호학적 증명은 제공하지 않으므로 공적인 평가나 부정행위 판정에 사용할 수 없습니다.

## 지원 범위와 실패 처리

최대 20MB, 20분 영상입니다. Worker, WebAssembly, OffscreenCanvas, createImageBitmap을 지원해야 하며 최신 Chrome/Edge를 안내합니다. 낮은 메모리 기기에서는 모델 준비나 처리가 실패할 수 있습니다. 모델/프레임 타임아웃과 연속 디코딩 오류는 처리를 중단하며, 부분 결과를 완료로 저장하지 않습니다. 취소하면 Worker를 종료하고 영상·캔버스·객체 URL을 해제합니다. 실패 후 명시적으로 재시도할 수 있고 자동 유료 경로로 전환하지 않습니다.

## 이전 표본 분석

기존 최대 6개 정지 표본 결과는 `metadata.nonverbalAnalysis`에서 읽어 별도 접기 영역에 표시합니다. 과거 유료 분석 함수와 사용량 기록은 보존하지만 신규 HTTP 경로에서 호출하지 않습니다. 과거 `NONVERBAL_ANALYSIS_ENABLED`·모델 설정과 2분 lease는 이전 구현의 조건이며 현재 로컬 추적 설정이 아닙니다. 기존 결과를 새 연속 관측 결과로 해석하지 않습니다.

## 검증 범위

집중 검사 18개와 독립 코드 검토를 수행했습니다. 실제 브라우저에서는 합성 영상 및 출처·허용 조건을 기록한 공개 영상으로 디코딩, 모델 실행, 미검출 표시, 원본 시점 이동을 확인했습니다. 개발 서버의 HTTP+DB 검사에서는 합성 매체로 소유권, 중복 lease, 누락 시간축, 취소, 재시도, 결과 보존과 원본 불변을 확인하고 임시 매체를 제거했습니다. 브라우저 영상 fixture와 실제 DB API 검사는 분리되어 있으며 일반 면접 영상의 횟수 정확도를 정답 데이터로 검증한 결과는 아닙니다.
