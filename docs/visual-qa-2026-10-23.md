# 2026-10-23 시각 QA 및 UI 개선

1·2차 통합 회의록과 3차 UI/UX 회의록을 기준으로, 화면의 목적·정보 위계·모바일 조작을 개선했다. 데이터 모델과 면접 공급자 로직은 이번 작업 범위가 아니다.

## 반영 내용

- 홈 `/my`: 훈련하기와 마이 대시보드 두 진입점으로 단순화.
- 훈련 `/training`: 기존 학습 계획을 별도 화면으로 이동. 모바일에서 숨겨졌던 시작 버튼 복구, 반복 시간·분류 문구 축소. 기존 `/my/today`, `/my/train`, 진단 및 수동 과제 주소 보존.
- 대시보드 `/preparation`: 진행률·학교 면접 일정·캘린더·기록·설정 통합. 활동별 준비 상태는 선택해서 펼침.
- 기록 `/records`: 날짜 선택 → 해당 날짜 훈련 → 질문 → 답변·피드백·질문별 녹화. 모바일 뒤로가기도 선택 날짜 유지.
- 리포트: 네 가지 음성 지표와 선택한 지표의 상세 표시. 중복 비교 카드·질문·재연습 안내 및 상단 재생 UI 제거. 질문을 펼치면 해당 질문의 녹화 확인 가능.
- 음성 면접: 어두운 무대·원형 면접관·발화 효과. 질문은 기본 접힘. 녹음 중 답변 마침 버튼은 모바일 메뉴 위에 고정.
- 공통 UI: 진한 초록색 주요 버튼, 이름이 있는 지속 표시 모바일 메뉴, 입력 중 메뉴 숨김 및 입력창 여백 조정. 로고 색상은 유지.
- 실행 중 발견한 캘린더 CSS 모듈의 전역 선택자 컴파일 오류 수정.

## 범위와 남은 사항

- 브라우저 화면은 합성 테스트 계정의 기존 자료로 확인했다. 면접 진행 화면은 합성 세션·가상 마이크·로컬 음성 응답을 사용했고, 실제 면접 저장과 외부 AI/음성 호출은 차단했다.
- 실제 휴대폰 카메라·마이크, 외부 STT/TTS 품질과 실전 면접은 별도 검증 대상이다.
- 기존 5초 침묵 종료 로직, 연습/실전 데이터 모델, 생기부 분석 MD 및 커리큘럼·질문 생성 개편은 변경하지 않았다. 실전 모드 구분 필드가 없으므로 도움 기능을 임의로 실전으로 판별해 차단하지 않았다.
- 오래된 기록은 기존 페이지네이션을 사용한다. 달력에서 없는 기록을 단정하지 않고 ‘이전 기록 더 불러오기’를 제공한다.
