# 2026-10-20 모바일·면접관·계정 정리

이번 요청의 변경 및 실제 로컬 검증 기록이다. 하린의 학교·활동·진단 초기화 상태는 유지하고, 캘린더·면접 실기는 별도의 합성 학생으로 확인했다.

## 반영한 동작

- 모바일 캘린더 카드와 날짜 격자를 콘텐츠 좌우 끝까지 확장했다. 날짜를 누르면 기존 하단 상세로 이동하며, 최초 진입·달 이동에는 자동 스크롤하지 않는다. 동작 줄이기 설정과 고정 헤더를 반영한다.
- ImageGen으로 투명 배경 클레이 3D 캐릭터 세 명을 제작했다. Chat·Live·답변 이력에서 고정된 동일 얼굴을 사용한다. SVG 표정·눈깜박임·끄덕임·새 AI 표정 평가·반응 설정을 제거했다. 과거 기록의 전사 정정 무효화 처리는 유지한다. [자산과 최종 프롬프트](interviewer-clay-assets.md).
- 학교 없는 학생의 홈 진입은 학교 선택으로 안내한다. 과거 온보딩 완료 플래그가 남아 있어도 적용한다. 나의 자료 검색을 숨기고 실행도 차단한다. 모바일 상단은 앱 로고를 표시한다. 설정과 내 계정은 계속 접근 가능하다.
- 펼침 버튼은 사이드바의 쌓임 맥락 밖으로 이동해 일반 화면 요소보다 위에 배치한다. 네이티브 모달의 포커스·최상위 레이어는 유지한다.
- 검색 테두리, 토글 테두리, 설정 선택 메뉴를 정리했다. 설정의 설명 길이·방식은 학교 변경 메뉴와 같은 팝오버를 사용하며 방향키·선택·Escape·포커스 복귀를 지원한다. 준비 메모 항목을 제거했다.
- 초록 기본 버튼의 글자색은 `#220D2A`, 굵기는 600이다. 모달에서 덮어쓰던 550 굵기도 수정했다. 면접 종료 문구는 `저장 후 종료`이며 줄바꿈을 막았다.
- 글 답변 모드로 Live를 종료하면 입력창·초안 저장도 종료한다. 마지막 질문이 서버에 보존된 경우까지 회귀 검증했다.
- 학교 미등록 상태의 설정 화면에서 내용 없는 하단 플로팅 메뉴가 나타나던 문제를 수정했다.
- 관리자 홈과 학생 상세에 학교·학습 시간·진단·저장된 오늘 훈련·최근 답변 상태를 추가했다. 기존 담당 학생 권한을 따르며 새 요약에 답변 본문·준비 메모·쉬는 날 목록을 추가 전송하지 않는다. 관리자 조회가 학생의 다음 계획을 변경하지 않는다.

## 로컬 계정 정리

명시된 `doyun@gakja.test`, `pending@gakja.test`, `staff@gakja.test` 세 프로필과 연결 데이터·세션을 트랜잭션으로 삭제했다. 삭제 전 백업은 Git에서 제외되는 `.local/account-cleanup/2026-10-20T12-37-13-230Z/accounts-backup.json`에 저장했다. 기존 관리자·하린 프로필이 변경되지 않았음을 비교했다. 초기 계정 스크립트도 해당 세 계정을 다시 만들지 않는다.

## 브라우저 관찰

390×844 모바일에서 다음을 직접 확인했다.

- 학교 없는 하린: 홈 → 학교 선택, 로고 표시, 나의 자료 검색 없음, 설정 접근 가능.
- 설정 팝오버: 방향키 후 Escape로 기존 선택 유지, 트리거로 포커스 복귀. 빈 하단 메뉴 없음.
- 캘린더: 스크롤바를 제외한 콘텐츠 폭 375px에서 카드 x=0, 폭 375px. 날짜 선택 후 상세 top≈80px, 헤더 bottom=64px로 상세가 헤더 아래 16px에 정렬된다. 전역 scroll-padding과 개별 scroll-margin의 중복을 상쇄했다.
- Live: 새 클레이 이미지 로드, 녹음 전 글 답변 전환, 종료 모달 표시. 종료 버튼의 실제 계산 스타일은 `rgb(34, 13, 42)`, `font-weight:600`, `white-space:nowrap`이다. 종료 후 글 입력창이 제거된다.
- 관리자 API: 미등록 하린은 다음 단계 `학교 등록`, 등록·시간 설정한 합성 학생은 `첫 진단`으로 구분된다.
- 관리자 홈에서도 두 상태를 직접 확인했다. 펼침 버튼은 실제 크기 24×24px, z-index 2100이며 버튼 중앙의 최상단 클릭 대상임을 확인했다.

화면 증거는 `.local/ui-request-2026-10-20/`에 저장했다. 이번 변경은 외형·흐름 회귀 검증이며, 이전 음성 전사·피드백 실기 결과는 [기존 안정화 기록](ui-stabilization-qa.md)에 별도로 남아 있다.
