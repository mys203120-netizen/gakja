## 유지·수정 분류와 변경 정책

원본 확정안 7개와 기존 자료 2개는 그대로 보존했다. 그중 브랜드·목차·학생부 분석은 현재 도메인 기준으로 유지하고, 용어집/PRD/통합 프로세스는 새 버전을 정본으로 선택했다. 대학별 참고 본문은 수정하지 않고 공식자료 적용 계약을 별도 추가했다.

[기존 자료/전역 검수](../.local/document-reconciliation-2026-10-14/legacy-project-review.md)의 유지 15개/갱신 후보 19개는 당시 목록 기준이며 새 정본을 추가한 현재 전역 목록은 아래에 기록한다.

- 기존 자료 두 파일은 동일 SHA256의 1,900행·52,615바이트다. 파일 수정 시각이 다르다고 내용의 새 버전이 아니다. 당시 103개 활동/등급 분포·특정 학교 전략·학생 사례를 다른 학생의 사실이나 전국 기본 비율로 적용하지 않는다.

- 과거 구현/QA는 당시 수치/범위 그대로 유지한다. 최신 변경의 해결/미검증 상태는 새 후속 QA로 기록하며 과거 화면을 현재 UX 통과 증거로 재사용하지 않는다.
- 현재 기능 설명의 사실 변화만 담당자가 갱신한다. 상품 정책·AI/음성 가용성·실기기 정확도·개인정보 보관 수치를 임의 확정하지 않는다. 충돌 시 위 정본과 실제 증거로 검토한다.

브라우저에서 첫 로컬 사용자의 실제 학교·학과·전형·2027학년도 수시(2026 실시) 공개 일정 검토/등록·캘린더·학교 인재상 질문 진입, 하린 합성 계정의 같은 질문 회상·도움 이용 면접·새 탭 초안 복귀·리포트·원래 지원처 보완·답변 비교를 확인했다. 즉시 24시간 내 재시도·입력 답변·도움 사용과 역할 표현 관찰을 구분했으며, 이를 장기 기억·음성 성능·독립 실력 향상으로 해석하지 않는다.

## 적용 결정을 기록하는 규칙

변경마다 사용자 결정/필요 근거, 대체되는 문서/조항, 유지하는 원칙, 구현 파일·마이그레이션/호환 범위, 실행 테스트·화면·저장값, 후속 미검증을 구분한다. 이 기록은 제품 PRD의 대체표/변경 이력과 이번 후속 QA에서 함께 관리한다.

현재 사용자 결정의 핵심은 브랜드 각자의답/서비스 각자ON/기능 AI 비서, 밝고 담백한 UI, 인간 검수 후 FINAL HTML 한 파일, 같은 활동/질문/지원처의 회상→답변→피드백→새 독립 시도, 도움·정정·시간 구분, 2027학년도 수시(2026 시행) 학교/학과/전형/일정 가입이다. 원본 학생 기록·학교 공식자료·과거 답변/리포트를 새 AI가 덮어쓰지 않는다.

### 2026-10-14 음성 처리 결정 추가

사용자는 STT를 Google 대신 `gpt-4o-mini-transcribe`로, 표시 전 문장/줄바꿈 후가공을 `gpt-6-luna`로 변경하도록 명시했다. 이 결정은 첨부 v2.1의 Google STT 선정과 현행 문서의 이전 Google 기본 설명을 대체한다. 한 키를 쓸 수 있다는 허용에서 자동 전환을 추론한 것이 아니다. 기존 TTS 공급자 `SPEECH_PROVIDER=google`, 원음/원전사/학생 정정 분리, 원전사 기반 실제 발화 관찰과 과거 리포트 보존은 유지한다.

현행 PRD v2.2에 당일 개정으로 반영하고 [환경 설정](environment.md)·[전사 계약](transcription-pipeline.md)·면접/퀴즈/발화 기록 설명을 함께 갱신한다. 과거 원본 PRD·Google/Whisper QA는 당시 결정과 검증으로 보존하며 새 모델의 실행 성공으로 바꾸지 않는다. 실제 호출·품질·지연 검증은 이번 전환 결과의 범위로 기록한다. `.env.example`에는 빈 키와 비밀이 아닌 설정 예시만 넣는다.

이번 확인 범위 밖의 소셜 실제 왕복·Live/STT·실기기/물리적 통신 장애·Supabase 운영 RLS/FK/저장소·장기 기억 2일/7일은 미검증이다. 88교 전 학과의 공식자료·질문 콘텐츠 동등 품질과 승인 질문의 필수/확장 요소 기획 검수도 후속 게이트다. 88교 모든 학과 UX, 실제 학습 효과와 브랜드 애착은 한 표본/자동 테스트로 완료 선언하지 않는다.


## 2026-10-17 Live 낭독 공급자 변경

사용자가 기존 OpenAI 연결로 Live 질문 읽기를 전환하도록 명시했다. 이전 Google TTS 유지 결정은 이 요청으로 대체한다. `SPEECH_PROVIDER=openai`, 기존 서버 전용 `OPENAI_API_KEY`, `OPENAI_TTS_MODEL=gpt-4o-mini-tts`를 사용한다. STT·전사 후가공 설정은 별도로 유지하며 자동 공급자 우회는 하지 않는다. 실제 MP3 생성과 저장된 공급자 확인은 통과했고, 카메라·마이크 녹음부터 전사까지의 전체 기기 E2E는 별도 검증 범위다.
