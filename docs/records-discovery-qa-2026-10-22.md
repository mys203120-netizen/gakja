# 기록 화면과 학습 진입 후속 정리

## 반영

- 앱 로고는 모바일(700px 이하)의 `/my`에서만 학교·학과 왼쪽에 표시한다. 다른 화면과 데스크톱에는 적용하지 않는다.
- 면접 연습 이력의 아이콘도 리포트 목록과 동일하게 정사각형 상자 안에서 가운데 정렬한다.
- 세 기록 탭의 전체 폭과 간격을 통일했다. 답변 비교만 내보내기 버튼이 없어 탭 영역이 56px 넓어졌던 차이를 없앴다. 기존에는 탭 간격도 24px와 8px로 달랐다.
- 답변 비교는 공통 질문 선택창에서 질문을 한 번 표시한다. 답변 하나는 한 카드, 여러 답변은 데스크톱 두 열·좁은 화면 한 열로 표시한다. 저장 시점, 지원처, 도움 사용, 원문·녹음, 겹쳐 보기 및 재연습 맥락은 유지한다.
- 지식한입·시사 브리핑을 오늘 훈련의 안내 카드 바로 아래와 자유 연습의 연습 방식 바로 아래에 두 개의 작은 진입 카드로 노출한다. 모바일에서도 두 열을 유지한다. 지식한입은 선택한 지원처를 전달한다.
- 폰트는 기존 13 / 15 / 18 / 24px를 유지한다.

## 검증

- 전체 테스트 1,116개, bootstrap 검사 31개, 최종 빌드 및 diff 검사 통과.
- 현재 계정의 지원 학교가 보관 상태이므로 별도 synthetic 계정과 실제 클라이언트 컴포넌트·CSS로 화면을 검증했다. Next 라우터·동적 로딩만 미리보기용으로 대체하고, 조회 API는 해당 테스트 계정 범위에서 사용했다. 뉴스는 외부 갱신 없이 가상 자료로 확인했다.
- 1920px 화면에서 세 기록 탭 모두 main 1440px, 본문·탭 영역 1376px, 탭 간격 24px로 동일하다. 세부 측정은 로컬 `records-widths.json`에 저장했다.
- 모바일 이력 아이콘 3개는 모두 36×36px이며 SVG와 상자의 중심 차이가 가로·세로 0px이다.
- 320px 화면에서 긴 비교 질문과 선택 메뉴의 수평 넘침이 없다. 학교 메뉴는 좌측 16px·우측 304px에 머문다.
- `/my` 로고는 모바일에서 표시되고 데스크톱에서는 숨겨진다. `/learn`에는 표시되지 않는다.
- 단일·복수 답변, 질문 변경, 겹쳐 보기, 지식한입·시사 브리핑 진입을 확인했다.

화면과 로그는 로컬 `.local/records-discovery-qa-2026-10-22/`에 저장했다. 임시 테스트 계정과 미리보기 서버는 검증 후 정리했다.
