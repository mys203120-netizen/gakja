# 학생 흐름 E2E — 2026-10-22

로컬 PostgreSQL과 프로덕션 빌드에서 별도 UUID 학생으로 검증했습니다. 기존 학생과 하린 계정은 변경하지 않았습니다.

## 발견한 문제와 수정

- 자유 연습의 이어하기가 오늘 계획에 속한 면접을 일반 면접 화면으로 열었습니다. 원래 계획 ID의 통합 차시로 복귀하도록 수정했습니다.
- 학과·전형 검색에서 한글 조합 중 Enter가 항목을 선택할 수 있었습니다. 조합 키를 보존하고, 비활성화된 선택창의 남아 있는 목록 조작도 차단했습니다.
- AI 응답만 유실된 뒤 도움창을 다시 열면 요청 ID가 사라졌습니다. 동일 소유자·지원처·시도·문항·자료 범위에 원래 요청 ID와 원문을 전송 전에 보관하여 재시도합니다.
- 도움 준비 중 질문·계정이 바뀌거나 응답 도착 전에 창이 닫히면 이전 결과가 새 화면에 영향을 줄 수 있었습니다. 각 방문을 구분하여 이전 결과·콜백·입력 초기화를 무시합니다.
- 작성 중 AI 응답이 같은 메시지 ID로 완료돼도 이전 본문이 남을 수 있었습니다. 같은 ID의 최신 상태와 본문을 병합합니다.
- 돌아보기를 선택하지 않은 Q&A가 ‘다시 준비’로 표시됐습니다. 미확인은 ‘돌아보기 전 · 미채점’으로 구분하고 추천 이유도 ‘다시 확인할 문항’으로 표시합니다. 저장값·복습 간격·정오 판정은 유지했습니다.
- 준비 현황의 답변한 항목 수가 답변 제출 횟수처럼 표시됐습니다. ‘답변한 항목’으로 명시했습니다. 개별 항목의 원답변·재답변 집계는 유지합니다.
- Chat에서 AI 도움을 열 때 초안과 일시정지는 저장됐지만 ‘초안 저장 중…’ 표시가 남았습니다. 저장 확인 응답에 맞춰 표시를 갱신합니다.
- Chat 답변 자동 저장 후 로그아웃은 인증 세션을 종료했지만, 기존 면접의 이탈 방지 기능이 로그인 화면 이동을 막았습니다. 모든 초안·학습 기록 저장과 인증 종료가 성공한 직후에만 해당 계정의 Chat·Live 화면에 이탈을 허용합니다. 기기 보관만 성공하거나 이후 로그아웃이 실패하면 기존 보호를 유지합니다.

## 실제 화면 흐름

390×844 모바일 뷰포트에서 로그인 → 미등록 학생의 학교 선택 → 서울시립대학교 환경공학부 면접형 전형·공개 일정 확인 → 평일·주말 시간 설정 → 첫 진단 3문항 제출 → 받은 과제 → Q&A 퀴즈 → 집중 보완과 같은 질문 재답변 → 다음 집중 보완 → 연결 면접의 4개 본질문 → 오늘 정리까지 진행했습니다.

오늘 계획은 120분·7개 차시를 모두 마쳤고 캘린더도 7/7 완료였습니다. 오늘 정리에는 본질문 답변 10개·퀴즈 1개·과제 1개가 반영됐습니다. 진단에서 선택한 보완이 도움 없는 후속 답변으로 해결되고, 오늘 정리에서 새로 고른 질문은 다시 ‘보완 중’이 되는 흐름을 확인했습니다.

AI 연결을 끈 상태에서는 실패 안내 후 도움 요청 초안과 원래 답변을 유지했습니다. 창을 다시 열어도 같은 질문과 도움 요청이 복구됐습니다. 데스크톱의 자유 연습 이어하기가 원래 계획으로 돌아오는 것도 확인했습니다. 내 기록에서는 원답변과 시간 단위를 보완한 재답변이 각각 보존돼 비교됐습니다.

실제 AI 연결에서도 Chat 초안에 관한 도움을 요청해 구체적인 행동을 보완하는 응답을 받았습니다. ‘같은 질문으로 돌아가기’ 후 원래 질문과 72자 초안이 유지되고 입력을 계속할 수 있었습니다. 도움 사용 표시가 같은 질문에 반영됐으며, AI 도움만으로 답변을 제출하거나 차시를 완료하지 않았습니다.

최종 빌드에서는 88자로 수정한 초안을 도움창 열기와 함께 보관하고 즉시 ‘초안 저장됨’으로 표시했습니다. 도움창 닫기 → 계정 메뉴 로그아웃 → 로그인 화면 자동 전환 → 재로그인 → 같은 질문 이어하기까지 다시 진행해 88자 초안과 도움 기록·일시정지 상태가 복구되는 것을 확인했습니다. 생성한 테스트 학생과 소유 데이터는 검증 후 정리했습니다.
