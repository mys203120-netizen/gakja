# 학교·학과 학습 축 연결 검토

검토일: 2026-10-13. 구현 중인 변경의 코드 검토 기록이다. 브라우저 전체 QA나 최종 통과 보고서를 대신하지 않는다.

## 검토 범위

- 등록한 학교·학과 → 공식 학교 정의 → 확인된 개인 활동 → 퀴즈·과제 → 지식한입 → 모의면접 → 답변·발화 비교.
- 다른 학생의 자료, 다른 학교·학과, 이전 공식 자료 개정본이 현재 학습에 섞이는지 확인.
- 실제 경험을 만들어 내는 모범 답안이나 객관식 정답, 학교가 공개하지 않은 평가 점수를 생성하는지 확인.
- 수정 중인 파일은 담당 작업에 넘기고 별도로 덮어쓰지 않았다. 테스트를 중복 실행하지 않았고, 실제 학생 기록을 변경하지 않았다.

## 확인한 구조

- 공식 대학 공통 정의와 별도로 확인한 학과 정의를 구분한다. 대학 공통 정의가 모든 학과에 적용된다고 해서 학과 고유의 공식 정의가 확보된 것으로 표시하지 않는다.
- 학교 질문의 암기 항목 식별자는 학교·학과·캠퍼스·연도·전형·자료 개정본을 반영한다. 이전 학교의 정답·자기 평가가 새 학교의 학습 숙련도로 넘어가지 않는다.
- 학교 가치에 관한 경험형 답변은 자기 점검 대상이며, 내용이 마음에 든다는 이유로 객관적인 정답이나 면접 점수를 부여하지 않는다.
- 실제 활동 연결은 명시적으로 고른 확인된 활동에 한정한다. 학교의 가치와 학생의 실제 수행 내용은 각각의 출처를 보존한다.
- 기존 면접과 학습 기록은 시작 당시 자료를 보존하며, 대상 변경이 과거 답변을 새 학과 답변으로 바꾸지 않는다.

## 발견하여 담당 구현에 전달한 사항

| 연결 지점 | 발견 내용 | 필요한 수정·검증 |
| --- | --- | --- |
| 퀴즈 → 리포트 | `source_kind`가 `source_type`에서 읽혀 학교 공통 연습이 개인 자료처럼 분류됨 | 공통/개인 계열과 구체 자료 종류를 분리하여 읽기 |
| 공통 질문 재연습 | 공통 질문의 자료 개정 번호를 개인 발행본 번호로 해석하여 이전 지원처를 선택할 수 있음 | 공통 자료 개정과 개인 발행본을 별도로 처리 |
| 면접 준비 → 시작 | 공통 연습의 미리보기에서는 자료 개정을 보존하나 시작 요청에서 삭제함 | 미리보기와 시작 질문이 같은 개정본이어야 함 |
| 학교 가치 + 내 활동 | 활동을 고른 뒤 면접 후보 필터가 활동 연결이 비어 있는 공식 가치 질문을 제외함 | 검증된 명시적 활동 연결 또는 선택한 본 질문을 보존 |
| 학교 퀴즈 → 면접 추천 | 퀴즈의 회상 기록은 `question_id`로 저장되나 추천 단계는 `questionId`만 읽음 | 저장 이름을 정규화하여 복습 시점·약점이 같은 질문으로 이어지게 함 |
| 면접 추천 | 공유 공통 질문의 답변 이력을 질문 ID로만 합산함 | 선택한 학교·학과·개정본의 이력과 일반 회상 이력을 구분 |
| 녹음 퀴즈 → 발화 추이 | 개인 퀴즈의 지원처는 세션 메타데이터에 있으나 녹음 분석은 문항 필드에서만 읽음 | 세션에 고정한 지원처로 보완하여 같은 맥락의 면접 녹음과 비교 |
| 수동 답변 비교 | 동일 질문·지원처 ID만으로 후보를 묶어 지원처 ID가 유지된 학과 변경이나 공식 자료 개정이 섞일 수 있음 | 자동 내용 비교와 동일한 맥락 키로 후보를 나누거나 다른 맥락임을 명시 |
| 지식한입 저장 설명 | JSON 객체의 필드 순서를 문자열로 비교하여 PostgreSQL JSONB에서 돌아온 같은 맥락을 다르게 판단할 수 있음 | 순서와 무관한 의미 기반 대상 키를 서버와 UI에서 같이 사용 |
| 지식한입 다중 지원처 | 같은 영상을 다른 학교에서 학습하면 최신 진행 행의 맥락이 교체됨 | 이전 학교 설명을 새 학교에 재사용하지 말고, 이력에 학교·학과를 표시하거나 해당 맥락의 최신 설명을 복원 |

위 표는 구현 도중 발견한 내용을 남긴 것이며 미해결 오류 목록을 의미하지 않는다. 최종 수정 여부와 테스트 결과는 해당 작업의 최종 QA 기록에서 확인한다.

## 필요한 경계 검증

1. 개인 발행본이 없는 학생도 학교 정의 → Q&A 과제 → 공식 원문 학습 → 면접 → 실제 답변 비교로 이어진다.
2. 개인 발행본이 있는 학생은 학교 가치와 확인된 활동을 함께 선택할 수 있으며, 개인 발행본 번호와 공통 자료 개정 번호가 달라도 같은 질문으로 시작한다.
3. 임의의 실제 학교·학과 선택은 동일한 기능 수준을 유지한다. 학과 고유 정의가 없는 경우 대학 공통 정의를 명확히 표시하고 학과 관련 학습 자료·추가 탐색을 제공한다.
4. 같은 지원처 ID에서 학과·캠퍼스·전형·연도를 바꾸거나 공식 자료 개정본을 갱신해도 이전 연습이 새 맥락의 완료나 향상으로 계산되지 않는다.
5. 저장한 퀴즈 답변과 후속 면접 답변은 같은 질문·대상·자료에서 실제 내용을 비교한다. 개념 확인 문제, 전사 오자 수정, 도움 사용은 서로 다른 관찰로 보존한다.
6. 공통 학교 연습은 없는 모범 답안이나 객관식 정답을 만들지 않는다. 실제 답변·녹음 없이 결과나 발화 지표를 생성하지 않는다.
