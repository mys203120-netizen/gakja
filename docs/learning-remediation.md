# 2026-10-14 학습 흐름·문서 통합 개선

현행 제품 정본은 [서비스 PRD v2.2](../확정안/4.%20서비스_PRD_v2.2.md)와 [문서 적용 순서](document-authority.md)다. [이전 24장 QA와 수정 후 화면을 함께 보는 보고서](../.local/learning-remediation-2026-10-14/report.html)는 당시 실패를 유지하고 후속 해결 증거를 별도로 연결한다.

## 문서 적용

확정안 7개와 기존 자료 2개를 전수 읽고 원본 9개를 보존했다. 브랜드·목차·학생부 분석 방법론은 유지한다. 용어집 v1.1·PRD v2.2·외부 제작 프로세스 v1.1을 새 정본으로 선택하고 대학별 자료는 [공식자료 적용 계약](university-source-contract.md)을 결합한다. 두 기존 자료는 같은 내용의 사례 원문이다. 현재 학생 사실이나 전국 기본 등급 분포로 복사하지 않는다.

첨부 PRD v2.1의 실질 요구를 v2.2에 계승했다. 큰 면접바이블 두 원문은 이번 전수 읽기 대상에 포함되지 않았으며 헤더·목록·해시 검수와 공식 자료 확인을 전체 본문 검증으로 보고하지 않는다. 과거 QA·원문은 최신 정본 색인에서 역사/참고 역할로 구분한다.

## 구현한 학습 연결

- 학교·실재 학과·전형·2027학년도 수시 일정 확인 → 등록 완료 → 첫 질문과 캘린더. 2027 수시 면접은 2026년 날짜를 사용한다. 공개일·개인 시각·미정·미실시·조회 실패를 구분하고 검토한 일정이 바뀌면 등록을 다시 확인한다.
- 같은 활동·질문·지원처·당시 발행본에서 원문 확인, 회상, Chat/Live, 보완, 새 답변으로 이동한다. 권장 흐름은 자유 연습을 막지 않는다. 교재가 없는 학생은 학교·전공 공통 질문을 사용한다.
- 퀴즈 저장과 자기 회상 상태를 분리한다. 불확실/사실 확인 필요는 먼저 다시 준비하고 개인 경험을 문자열 정답으로 채점하지 않는다. 새 시도의 서버 도움 관찰이 명시된 경우와 과거 미기록을 구분한다.
- 근거·힌트·영상·AI 도움을 소유한 현재 시도에 기록한다. 첫 유효 AI 스트림을 보여주기 전에 증빙을 저장하고 부분/완료/중단 상태를 유지한다. 출력 없는 실패는 AI 도움을 만들지 않는다. 답변 이후의 자료 조회는 원답변을 다시 분류하지 않는다.
- 리포트의 실제 답변 턴·지원처·당시 교재/공통 질문 검수 버전에서 보완 과제를 만든다. 재발행·질문 삭제·학교 전환이 원래 답변을 덮어쓰지 않는다. 과제의 전역 AI 메뉴도 현재 문항의 도움으로 연결된다.
- 같은 학교 스냅샷의 이름/공시 ID 표현 차이와 단계 누락을 비교에서 처리한다. 알려진 단계가 하나일 때만 누락 단계를 연결하고, 1·2단계 사이의 미확인 기록을 연결하지 않는다. 개인 교재 버전과 공통 질문 검수 버전은 별도 기준이다.
- 리포트는 실제 문장·질문별 승인 요소·도움·경과 시간·입력/음성 조건을 보여준다. 역할의 다른 표현을 잡되 단서를 의미 충족·사실 승인·실력 점수로 승격하지 않는다. STT 정정은 새 발화가 아니다. 학생의 자기 점검은 원답변과 별도 저장한다. 다음 연습은 질문이 직접 요청한 승인 요소를 우선하며, 관련 없는 공통 요소를 자동 부족 판정으로 만들지 않는다.
- 면접 피드백은 학생의 실제 문장 인용과 확인 질문을 사용하도록 지침을 강화했다. 원문·학생 진술·AI 제안을 구분하고, 확인되지 않은 실험 절차를 완성형 1인칭 답변에 추가하지 않는다. 기존 피드백 본문은 유지하며 표현 제안임을 표시한다. 자유 텍스트의 사실성을 결정적으로 보장하는 검증기는 아니므로 모델의 실제 준수는 별도 검수가 필요하다.

## 브랜드와 화면

각자의답 브랜드와 각자ON 서비스명을 통일했다. MY의 주 행동은 이번에 보완할 질문 하나다. 하위 내용은 들여쓰고 자료/도움/후속 행동을 묶었다. 밝은 배경, 로고 비율, 녹색 브랜드 포인트를 유지한다. 완료 개수 차트가 준비 완료를 뜻하지 않도록 했다. 신규 등록 중에는 학습 메뉴를 숨기고 완료 후 복원한다. 한국어 줄 균형·체크박스 배치·중복 비교 안내·한국어 인용 Markdown을 보완했다. 학교 기준 요약을 학생부 원문으로 부르지 않는다.

## 확인 범위

선택 순수 검사 87/87, 격리 PostgreSQL의 퀴즈 HTTP 81개·학교 등록 HTTP 42개·학습 기록 85개·음성/내용 기록 27개를 통과했다. 피드백 요청과 질문 의도 회귀 33개는 선택 순수 검사와 일부 중복되므로 합산하지 않는다. 도움 스트리밍·소유권·회상·원본 재훈련·비교·렌더 회귀와 최종 타입/빌드를 검증했다. 서로 다른 검사를 더해 전체 기능 커버리지로 해석하지 않는다. 정확한 실행 기록과 화면 수는 [후속 QA](../.local/learning-remediation-2026-10-14/report.md)를 따른다.

브라우저에서는 하린 합성 계정의 불확실 회상 → 같은 질문 면접 → 근거와 실제 AI 도움 → 새 탭 초안/도움 복귀 → 실제 답변/리포트 → 원래 학교 보완 과제 → 답변 비교 → 새 도움 조회 없는 답변/리포트를 실행했다. 강화한 지침의 실제 AI 리포트 한 사례에서 학생 진술·원문·확인 질문을 구분하고 미확인 실험 절차를 추가하지 않는 것을 확인했다. 자료 없는 첫 로컬 사용자도 서울시립대 → 실재 환경공학부(교육부 2026 공시) → 학생부종합전형Ⅰ(면접형) → 2027학년도 수시 공개 면접일 2026-11-29 검토 → 등록 → 캘린더 → 학교 인재상 질문 진입을 확인했다. 공개 시작 시각은 개인 응시 시각으로 등록하지 않았다. 실제 OAuth 왕복을 대신한 검증이 아니다.

테스트는 별도 스키마에서 수행했다. 운영 `public` 62개 테이블의 행 수·digest가 모두 동일했고 확정안·기존 자료 원본 9개도 보존했다. 자동 HTTP/저장값 검사에는 유료 AI 요청을 포함하지 않았으며 브라우저에서는 실제 AI 도움과 면접 답변 경로를 확인했다. 데이터·인덱스 복사본에 없는 FK/RLS 정책은 운영 보안 검증으로 인정하지 않는다.

| 운영 배포·보안 | Supabase 인증/RLS/FK/저장소·삭제 작업을 운영과 동등한 환경에서 검증. 데이터/인덱스 복사 QA는 RLS 검증을 대신하지 않음 |

기존 OpenAI 서버 키 하나를 공유하며 별도 키나 음성 공급자 자동 교체를 추가하지 않았다. 서버 도움/권한/일정/발행·기록 연결은 결정 규칙으로 처리한다. 추가 의미 평가 AI는 승인 기준·실제 인용·실패 상태를 검증하고 인간 검수권을 유지한다.
