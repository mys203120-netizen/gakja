# 학습 화면·문장 정리·일정 편집 QA

검증일: 2026-10-22~23 (Asia/Seoul)

## 반영 범위

- 학생부·교재, 지식한입, 시사 브리핑, 지원 학교의 중복 경로 표시 제거.
- 오늘 훈련과 자유 연습이 같은 제목 컴포넌트·간격·굵기를 사용. 글자 크기는 13/15/18/24px 유지.
- 오늘 훈련의 실제 지식 자료는 3.6초마다 전환, 뉴스는 위로 뒤집히며 전환. 일시정지, 포커스/호버, 화면 밖·백그라운드·동작 줄이기 지원.
- 첨부 HTML의 흰색 선택면과 탄성 모션을 대화/보관함, 계정 설정, 면접 설정, 카메라 설정, AI 정리에 적용. 동의 체크박스는 별도 유지.
- 여러 대학 선택 후 대학별 학과·전형·일정 입력, 앞 단계 입력 보존, 마지막 일괄 저장. 원자 저장과 같은 지원처 재시도 중복 방지.
- 준비 현황은 다음 행동과 학교 일정을 함께 배치하고 활동별 준비를 두 열로 구성. 내 기록은 실제 이전·최근 문장을 먼저 비교하고 상세 관찰은 펼쳐 확인.
- 내 경험·AI 비서에 기존 공통 질문 생성기를 재사용한 문장 정리 추가. 짧은 입력과 후속 질문, 편집 후 적용, 취소·원문 복원, AI 도움 이력 보존. 답변 제출·학습 성과로 기록하지 않음.
- 데이터 휴지통 이동 시 일시적인 AI 제안 캐시 제거. 복원할 원문은 기존 데이터 그래프의 휴지통 스냅샷에 보존.
- 계획 추가의 작성 방식·종류 선택을 앱 선택 메뉴로 통일. Q&A의 휴식 문구와 프로그램 포커스에 나타나던 질문 외곽선 제거.
- 캘린더의 날짜/개별 계획 이동, 모으기, 뒤 일정 밀기, 하루씩 나누기, 변경 전 확인, Ctrl+Z, 최근 병합 해제. 자연어 입력은 미리보기 후 적용.
- 시사 브리핑 본문 너비 제한과 목록 요약 줄 수 제한 제거, 언론사 자동 분산과 중복 제목 정리. 버튼명은 ‘기사 원문 링크’.

## 검증 환경

실제 사용자 계정의 학교·경험·답변·일정은 변경하지 않았다. 로컬 DB에서 무작위 UUID의 별도 `qa-records-…@gakja.test` 계정과 별도 API 검증 계정만 사용했다.

UI는 실제 제품 컴포넌트와 CSS를 번들한 격리 미리보기에서 확인했다. Next 라우팅 어댑터를 사용하며, 사용자 쓰기 요청은 실제 서비스에 전달하지 않는다. 캘린더 UI 변경은 실제 순수 날짜 모델을 사용하는 메모리 데이터에만 적용했다. DB 저장·동시성·롤백은 별도 실제 저장소 검증으로 확인했다. AI 제공자에는 실제 요청을 보내지 않았다.

- 마우스 PointerEvent 드래그 8개 검사 통과. 실제 데스크톱 날짜 23일→25일 드래그로 2개 계획의 확인 창이 열리는 것을 재검증. 터치 스크롤·일반 클릭·중복 적용·이벤트 정리 보호 포함.

- 모바일 AI 비서의 중복 ‘면접으로 이어가기’ 링크는 캡처에서 발견해 데스크톱 액션의 모바일 CSS 우선순위를 수정.

## 사용 범위와 제한

- 자연어 일정 수정은 날짜 표현을 검증하는 제한된 한국어 문법을 사용한다. ‘오늘 일정은 내일로 미뤄줘’, ‘이번 주 일정을 다음 주로 미뤄줘’, 며칠 뒤 이동, 월·일 이동을 지원한다. 해석하지 못한 문장은 적용하지 않는다.
- 한 번에 최대 31일 범위·200개 계획, 최근 20개 변경의 복원 이력을 보존한다. 진행·완료한 학습 및 실제 학교 면접일은 이동하지 않는다. 확인 이후 계획이 변경되면 재확인을 요구한다.
- 기사 전문 재게시와 프레임 삽입은 구현하지 않았다. 현재 공급된 요약을 읽기 화면에 표시하며 원문 링크로 연결한다. 전문을 제공하려면 해당 언론사의 이용 허락이나 라이선스된 공급원이 필요하다. 확인 출처: [경향신문 뉴스이용규칙](https://www.khan.co.kr/company/sub03_2.html).
- 새 DB 마이그레이션은 없다. 임시 UI 계정과 검증 데이터는 검증 후 제거했다.
