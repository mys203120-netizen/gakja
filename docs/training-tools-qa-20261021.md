## 반영 내용

- 오늘 훈련의 하위 탐색은 오늘 계획 / 자유 연습 / AI 비서입니다. 자유 연습에서 퀴즈·Chat·Live를 중복 없이 고릅니다.
- 현재 지원처·질문·자료 버전이 일치하는 퀴즈와 받은 과제를 집중 보완 시간 안에 배치합니다. 자유 연습 방문이나 시작 버튼만으로 계획을 완료하지 않습니다.
- 실제 제출과 원본의 유효성을 기준으로 완료·준비 현황을 계산합니다. 재시도와 과제의 복습용 미러를 중복 집계하지 않습니다.
- 차시 완료 뒤 결과 상단에서 다음 차시를 제안합니다. 연결 면접은 여러 본질문과 본질문별 최대 두 꼬리질문을 이어갑니다.
- 훈련 중 AI 도움창은 원래 질문과 미제출 초안을 유지합니다. 음성 진행은 잠시 멈추고 명시적으로 재개하며, 도움 사용을 원래 시도에 연결합니다.
- 오늘 정리에서 실제 답변·퀴즈·과제·도움 기록을 확인하고, 한 가지 보완과 내일 다시 답할 질문을 저장합니다. 다음 계획과 준비 현황은 같은 보완 요청을 읽습니다.

- 실제 DB/API 혼합 훈련 검사 193개, 오늘 정리 검사 11개 통과. 외부 AI를 끈 격리 서버에서 수행했습니다.
- 탐색 렌더 검사 206개, 초기 조회 검사 31개, 훈련 허브 렌더 검사 통과.
- 타입 검사와 프로덕션 빌드 통과.
- 퀴즈·과제의 소유권, 고정 문항·버전, 중복 생성·제출, 불완전 종료, 원본 무효화, 잘못된 지원처, 학교 간 공유 시간 예산을 확인했습니다.
- 도움창의 실패·재시도, 지연 응답의 계정/지원처 격리, 원래 녹음·초안 보존, 같은 질문 복귀를 검사했습니다.

## 실제 화면 검증
