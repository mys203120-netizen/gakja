# 모바일 UI·녹음 설정 정리

2026-10-20 요청에 대한 구현과 검증 기록입니다. 첨부 HTML은 디자인 참고 자료로 읽었고, 지정된 영상 경로가 없어 프로젝트의 `메뉴펼침.mp4`에서 실제 접기·펼치기 움직임을 확인했습니다.

## 주요 변경

- **녹음 설정**: 저장·전사 동의와 카메라 사용 선택을 계정별 서버 설정에 저장합니다. 다음 면접과 새로고침에도 유지하며, 설정된 경우 접혀 있습니다. 면접 시작 때 실제 마이크 연결을 확인합니다. 설정을 철회하거나 카메라를 바꿀 때 미제출 녹음을 보존하고 장치를 해제합니다. 늦은 bootstrap 응답이 최신 저장 설정을 되돌리지 않도록 보호했습니다.
- **인물**: 첨부 예시와 같은 이전 성인 비율 3D 얼굴 3종을 복원하고, 같은 스타일의 인물 2종을 추가했습니다. 총 5명까지 서로 다른 얼굴을 사용합니다. 표정으로 답변을 평가하지 않습니다. [파일·생성 프롬프트](interviewer-clay-assets.md)에 내장 `image_gen` 사용과 원본 경로를 기록했습니다.
- **입력·타이포**: 입력칸과 바깥 답변 작성 틀의 포커스 윤곽선을 함께 제거했습니다. 모바일 질문과 답안을 양측 정렬하고, 글 답변 모드에서는 면접관 영역을 작게 정리했습니다. 버튼 옆 링크의 높이·중앙선, 아이콘 간격, 주제 사이 여백과 진단 선택 항목을 정리했습니다. 훈련 완료 화면은 한 번만 표시합니다.
- **도움말·토글**: 설정의 ‘도움말 표시’가 계정별로 저장되고 `InfoTip`에 반영됩니다. 일반 홍보·반복 설명은 제거하고, 날짜 적용·저장·집계 등 행동을 결정하는 설명만 도움말에 남겼습니다. 알림·도움말·녹음·키워드·수능 전후 시간 구분은 동일한 토글을 사용합니다. 질문 선택·일정 확인 같은 다중 선택·확인 항목은 체크박스로 유지합니다.
- **이동·모션**: 세 메인 개요 화면에서 한 손가락 좌우 스와이프를 지원합니다. 입력·버튼·가로 목록·브라우저 가장자리·열린 모달·답변 화면은 제외합니다. 세로 스크롤과 핀치 확대는 유지합니다. 메뉴는 아이콘 위치를 유지하며 폭과 라벨이 함께 접히고, 펼침 아이콘도 회전합니다. 마우스 버튼 호버는 레이아웃을 움직이지 않고 작게 확대됩니다. 내부와 문서 스크롤바는 스크롤 후 점차 사라집니다. 동작 줄이기 설정을 따릅니다.
- **준비 현황**: 다음 행동, 면접까지 남은 시간, 실제로 제출한 질문·활동별 준비 항목 순으로 정리했습니다. 항목마다 확인·보완·답변 비교로 이동할 수 있으며, 질문 비교는 선택한 학교와 질문으로 한정합니다. 답변 횟수를 능력 점수로 표현하지 않습니다.
- **캘린더**: 월간 셀은 총 시간·제출 완료 개수·대표 면접 일정만 표시합니다. 선택일에 전체 항목을 보여주며 실제 예정·진행 중·완료를 구분합니다. 휴식은 답변 완료 집계에서 제외합니다. 긴 미래 질문은 펼쳐볼 수 있습니다. 모바일 여백을 복원하고 날짜 선택 시 아래 상세로 이동하는 동작을 유지했습니다.
- **로그인·등록**: 로그인은 앱과 같은 중립 배경·여백으로 정리했습니다. 일시정지·소개 모달·X 버튼을 제거하고, 아래 소개가 페이지 흐름 안에서 반복 진입 시 나타납니다. 이메일 포커스와 자동 완성에서도 둥근 모양과 색을 유지합니다. 학교 등록 전 데스크톱 메뉴에는 잠금 아이콘이 표시됩니다. 등록 단계 1·2·3의 굵기와 위계를 개선하고, UNIST 로고와 아주대 로고 크기를 보정했습니다. ‘유니스트’ 한글 검색도 지원합니다.

## 실제 브라우저 검증

하린 대신 별도 임시 학생을 사용했습니다.

1. 서울시립대학교 → 환경공학부 → 학생부종합전형I(면접형), 2027학년도 공개 면접일 11월 29일 확인 후 등록.
2. 수능 전 평일 120분·주말 180분을 저장하고 오늘 계획으로 이동.
3. 녹음 동의와 카메라 끄기를 저장. 새로고침 후 설정이 접혀 있고 선택이 유지됨을 확인.
4. 글 답변으로 진단 3문항을 실제 제출. AI 피드백 3건과 완료 리포트를 확인하고 전공 보완 주제를 다음 계획에 반영.
5. 준비 현황에서 글 답변 3개·음성 0개의 실제 집계와 학교·질문이 지정된 비교 링크 확인.
6. 도움말을 끄고 새로고침한 뒤, 시간 설정 화면에서 도움말 트리거가 사라지고 입력값은 유지되는지 확인.
7. 모바일 너비 390px에서 10월 22일을 선택한 뒤 상세 영역의 상단이 80px, 고정 헤더 하단이 64px인 것을 확인. 10월 21일로 날짜가 바뀐 뒤 다음 준비가 실제로 누적 복습으로 조정된 것도 확인.

이번 회차에서 실제 마이크 녹음은 새로 제출하지 않았습니다. 녹음 장치·저장·복구 흐름은 컨트롤러 회귀 검사로 확인했습니다. 모바일 검증은 브라우저 화면 크기와 실제 컴포넌트의 터치 이벤트 검사를 사용했으며, 특정 휴대전화의 OS 키보드 검증을 뜻하지 않습니다.

스크린샷·실행 로그·실제 AI 처리 증거는 `.local/ui-polish-2026-10-20/`에 저장합니다. 하린의 프로필·지원 학교·답변·면접 학습 데이터에는 새 테스트 데이터를 추가하지 않았습니다.
