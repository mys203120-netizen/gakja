# 학생부형 면접 범위·학과 학습·D-day 준비 개선

사용자의 2026-10-17 결정: 이 앱은 학생부형 면접을 준비하며, 제시문 면접을 제공하지 않는다. 기존의 88개 학교 원문은 보존하고 실제 선택·신규 연습 범위를 제한한다.

## 학교·학과 자료

- [공시 전수 대조](student-record-directory-audit-2026-10-17.json): 원본 88교·3,934행의 학교명·학교코드·학과코드·명칭·캠퍼스·단과대·계열을 2026 교육부 CSV와 양방향 대조했다. 누락·타 학교 소속·캠퍼스 혼입·메타데이터 불일치가 없었고 원본 SHA256도 일치했다.
- 광역 모집으로 인해 세부 전공의 모집인원이 0이라고 해서 그 전공이 폐지된 것은 아니다. 반대로 0인 과거 학과를 모두 현재 모집단위로 추가하지 않는다. 명지대·덕성여대·전북대·성균관대·한국항공대 공식 안내에서 26개 광역 단위의 223개 세부 전공 연결을 보완했다. 검색에서 세부 전공을 찾고 실제 광역 모집단위 안에서 관심 전공을 선택할 수 있다. 관심 전공은 그 모집단위의 검증 목록 안에서만 저장하고 안내 자료의 학년도도 표시한다. 전공 연결을 전국 모든 세부 전공의 완전한 목록으로 표시하지 않는다.
- 실제 지원 모집단위와 관심 전공은 별도 필드다. 관심 전공이 직접 모집이나 입학 후 배정을 뜻하지 않는다. 학과 소속의 공시 대조와 **2027학년도 전 학과·전형 모집요강 전수 확인은 다르다**. 후자는 완료로 표시하지 않는다.
- [현재 선택 범위 및 전 학과 질문 연결](student-record-flow-audit-2026-10-17.json)에 학교별 수와 제외 사유를 기록한다. 원본 자료와 과거 학생 지원처·면접·리포트는 보존한다.

전체 선택에서 제외한 학교는 연세대, 부산교대, 경인교대, 공주교대, 한국에너지공과대, 영남대, 홍익대, KAIST다. 제시문·문제지·창의성 과제·군 면접·공통 문항 영상 제출·수시 면접 미실시 등 학생부형 개인 면접 준비 범위와 다른 경우를 포함한다. KAIST 특기자도 적합성·영어 제시문을 포함하므로 서류형 예외로 남기지 않는다.

서울대 지역균형·기회균형, 고려대 사이버국방, GIST 특기자, POSTECH 일반전형Ⅱ 등 서류형이 있는 학교는 유지한다. 서울대 일반전형, 고려대 계열적합 등, 성균관대 과학인재, 한양대 공과·한양인터칼리지, 세종대 창의소프트, 삼육대 예체능인재, 제시문·상황 면접을 함께 치르는 일부 의학과는 전형·학과별로 제외한다. 직접 입력·구형 지원처·질문 ID를 보내도 신규 모의면접의 서버 범위 검사를 거친다.

성균관대 융합인재·탐구인재·기회균형 등 면접 미실시 전형과 성균인재에 해당하지 않는 모집단위도 신규 면접 준비 대상으로 확인할 수 없게 했다. 현재 확인 범위인 2027학년도를 다른 연도로 바꿔 범위 검사를 우회할 수 없다.

## 학과 개념에서 같은 질문으로

지식한입에 학과별 개념 설명·확인 질문·실제 학습 출처를 제공한다. 환경·컴퓨터·전기전자·간호·경영 등 세부 학과명을 공시 중계열보다 우선하고, 미분류 학과는 근거 검토 등 기초 개념으로 연결한다. 대학 공통 인재상을 학과 고유 교육목표로 표시하지 않는다.

학과 연습 질문은 공용 질문 은행에 고정 ID·revision·학습 출처와 함께 저장한다. 같은 질문을 지식한입, Q&A 퀴즈, 실제 과제, Chat/Live 면접, 계획에서 이어 간다. 학교·학과·캠퍼스·관심 전공이 다른 질문은 섞지 않는다. 일반 다문항 면접에는 사용 가능한 학과 질문과 학교 가치 질문을 함께 편성하고, 명시적으로 선택한 첫 질문과 승인된 편성 기준은 유지한다. AI 맥락에도 개념·확인 질문을 전달하며, 학습 개념을 학생의 과거 활동으로 만들지 않는다.

학과 개념 카드는 앱이 편집한 학습 설명이다. 화면에서 이를 학교의 공식 교육과정이나 기출로 표시하지 않는다. 기존 검증 영상 21개의 연결을 사용하며 새 영상을 검증했다고 주장하지 않는다.

## D-day와 오늘 할 일

- 개별 면접일 → 확인된 학교 단일 공개일 → 직접 설정한 준비 목표일 순으로 기준을 정하고 각각의 출처를 표시한다. 공개 기간만 있는 경우 개인 날짜를 만들지 않는다. 한국 날짜와 실제 실시 연도를 사용한다.
- 22일 이상은 기록·개념, 8~21일은 경험·전공 연결, 2~7일은 말하기·약점 보완, 전날은 10분 한 질문으로 조정한다. 면접 당일·지난 면접에는 새 자동 과제를 만들지 않는다.
- 접속 시 앞으로 최대 7일을 조정한다. 하루 설정 시간은 여러 학교와 직접 만든 계획이 나눠 쓴다. 실제 연습의 지원처·질문·개인 버전/공통 revision을 확인하며 이전 지원처나 다른 판본을 연습한 기록으로 계산하지 않는다.
- 밀린 미수행 자동 계획은 새 계획으로 대체하고 원래 날짜·출처·상태를 보존한다. 직접 만든 계획과 완료·실제 수행 기록은 보존한다. 오늘의 한 답변으로 과거 여러 자동 복습을 모두 수행한 것으로 표시하지 않는다. 직접 체크와 실제 수행도 구분한다.
- 목표일·시간·중지 상태는 학생 설정에 저장한다. 자동 계획을 중지하거나 다시 시작할 수 있고, 개인 면접일이 변경되면 새 날짜에 맞춰 조정한다. 학생별 잠금으로 동시 요청의 중복 생성을 막는다.

## 검증 증거

최종 단위 검사 106개, API·데스크톱·모바일 검사 54개가 통과했고 TypeScript 검사와 Next.js 프로덕션 빌드도 성공했다. 원본 88교·3,934행 가운데 학생부형 범위의 현재 선택 목록은 80교·3,551개 학교/학과/캠퍼스 조합이다. 광역 단위 관심 전공 223개까지 포함해 11,427개 고정 ID의 개념 연결 질문을 만들 수 있다. 이는 서로 다른 기출 11,427개를 수집했다는 뜻이 아니다.

[API 검증](../.local/student-record-preparation-2026-10-17/api-evidence.json), [화면 증거](../.local/student-record-preparation-2026-10-17/browser-evidence.json), [임시 계정 정리](../.local/student-record-preparation-2026-10-17/cleanup.json)에 실제 수행 결과를 기록했다. 임시 학생으로 학교 등록, 학과 지식·퀴즈·과제·모의면접, 계획 멱등성·완료 보존·밀린 과제·날짜 변경·중지/재개·타인 접근 차단과 데스크톱/모바일 표시를 확인했다. 원래 지원처 행의 digest를 전후 대조했으며, 유료 OpenAI 호출은 0회다. 실제 모델 피드백 품질이나 장기 학습 효과의 검증을 뜻하지 않는다.
