# 질문 생성 가이드 적용 점검

기준 문서는 루트의 `9. 면접엔진_질문생성_가이드라인_v2.1.md` 전체(L1–850)와 `interview_screen_build_prompt.txt` 전체(L1–663)다. 최신 실사용 회차 `2c6bf62b…`의 저장된 질문·답변·반응 및 150개 저널 이벤트를 대조했다. 원본 회차와 대화 로그는 변경하지 않았다. 이 문서에는 학생의 답변 원문·PDF 원문·비밀키를 포함하지 않는다.

## 서비스 정책과 가이드의 구분

- 질문 길이 한도 `main 100자 / 평가용 follow_up 75자 / clarification 80자`, main·평가용 후속의 `targetEvidence` 한 개, 일반 생성의 기본 출력 예산 1,200토큰은 이번 서비스의 운영값이다. 가이드에는 고정 글자 수가 없으며 “한 번 듣고 이해 가능한 길이”와 단일 요구를 명시한다. 근거가 여러 개이면 필요한 출력 여유를 추가한다.
- 가이드의 `target_evidence`는 정답 문장이나 완벽한 단계별 체크리스트가 아니다(L254, L292, L638). 실제 발화가 요청하지 않은 결과·수치·전문 지식을 사후에 답변 부족으로 추가하지 않는다.
- 정확한 활동명·전문 명사·수식어·숫자·단위는 검증된 title/원문 표기를 유지한다. 길이를 줄이기 위해 명칭을 부정확한 용어로 바꾸지 않는다. 이는 허위 전제·최종 발화 검수 규칙(L36, L150–152, L263–268)의 적용이다.

## 이미 적용되어 유지하는 항목

- 실제 학년도·대학·학과·전형의 공식 자료 선택과 구분: 제8조 L93–98, 별표2-1 L454–459. 대학/학과 인재상과 전형 평가요소를 출처별로 구분하며 배점을 문항 비율로 바꾸지 않는다.
- 실제 경험 영역의 분산과 허위 활동 금지: 제18조 L212–214. 현재 12분·주질문 목표 5개는 공식 시간과 서비스 진행 정책을 연결한 값이지 대학의 공식 문항 수가 아니다.
- 묶음별 F1/F2 상한, 부모·답변 턴 연결, 동일 묶음의 목소리 유지: 제14조 L175–179, 제20조 L231–236, 제22조 L251–255. 목소리의 실제 성별·대학 면접관 역할을 추정하지 않는다.
- 검증된 원문 ID/인용 후보 enum과 최종 ID별 PDF 원문 대조를 모두 유지한다. 다른 ID에 인용을 잘못 붙이는 경우도 최종 검수에서 거절한다. 제한된 재작성 후 아무 질문으로 대체하지 않는다: 제23조 L261–270.
- 새 주장과 자기모순은 실제 답변 인용에서 한 점을 확인하며, 정오·거짓말·성격·합격 판단으로 사용하지 않는다: 제3조 L45–49, 제4조 L54–58, 제15조 L187–188, 별표4-4 L587–591.

## 연결되지 않았거나 별도 검증이 필요한 항목

- 승인된 학생부 분석 MD의 S/A/B/C/F 우선도와 통합 activity 매핑은 현재 없다. S 활동 추천·출제 확률·준비 우선도를 임의 생성하지 않는다(제8조 L94–98, 제27조 L301–308). 현재 근거에 존재하는 활동·영역만 사용한다.
- 승인 공통 질문 모듈이 없으므로 자기소개·마지막 발언 같은 독립 공통 문항의 출처 ID를 꾸며내지 않는다(제7조 L88, 제22조 L252, L650).
- PDF 인용이 존재한다는 것은 해당 기록이 있다는 뜻이며, 모든 과학 명제의 진실성이나 질문의 모든 전제가 독립 검증됐다는 뜻이 아니다. 학술 정오를 확정할 별도 승인 근거와 구조화된 사실 확인 계약은 별도다(제15조 L187, 별표1 L382, 제23조 L263–268). 최종 의미 검수에는 여전히 모델·사람의 확인이 필요한 한계가 있다.
- 실제 기록과 답변의 차이는 중립 확인·정정 상태로 관리해야 하며 원문을 바꾸지 않는다. 모든 차이를 자동 판정하는 완전한 `confirmed_facts/uncertain_facts/student_says_different` 워크플로는 이번 좁은 수정에서 새로 만들지 않았다(L47–48, L591, L640, L652–654).

## 아직 구현하지 않은 항목과 실제 제약 · 2026-11-02 재점검

자료·콘텐츠 계약이 더 필요한 부분도 엔진에서 준비 단계를 만들 수 있다.

- **S/A/B/C/F 준비 우선도:** 현재 모든 근거의 `preparationPriority`는 null이며, 승인된 분석 정본이 없다. 제8·27조(L94–98, L301)의 정본으로 사용하려면 산출 기준·원문 근거·검수 상태가 필요하다. 엔진이 분석 초안을 만들고 원문 대조와 승인 상태를 관리하는 파이프라인을 구현할 수 있으며, 사용자가 반드시 분석 MD를 수작업으로 작성해야 한다는 뜻은 아니다. 준비 우선도를 출제 확률·학생 능력 점수로 만들지 않는다.
- **독립 공통 질문:** 자기소개·마지막 발언을 위한 실제 모듈 정의·지원처 맥락·버전·검수 상태가 현재 없다. 모듈을 작성·검수해 연결할 수 있고, 없는 `COMMON_APPROVED` ID를 존재하는 것처럼 사용할 수는 없다(L88, L252, L650).
- **학술 정오 확정:** 학생부의 문장은 기록의 존재를 증명한다. 새로운 전문 개념의 정확성이나 학생 답변의 정오를 확정하려면 별도의 적절한 교과·학술 근거가 필요하다(L187, L382). 이 한계가 기존 활동의 원리·판단 근거·해석 한계를 중립적으로 묻는 것까지 금지하는 것은 아니다.
- **제품 연결:** 연습·실전 모드, 답변 보관함, 다시 준비할 질문, 실전 PDF 리포트는 제27조(L303–306)의 별도 제품 구현이며 이번 진행 오류 수정으로 완료되지 않는다. 루트의 답변평가 가이드 `10. 면접엔진_답변평가_가이드라인_v2.1.md`는 이미 연결되어 있으므로 문서 자체가 없다고 설명하지 않는다.

다음 엔진 확장의 우선순위는 **실제 답변에 따른 후속 기능·깊이 선택 → 사전 검수 Q0 후보 은행과 실패 대안 → 활동·사실 상태 구조화**다. 기존 원문 검증·후속 상한·비평가 재진술 분리를 유지하면서 적용할 수 있다.

## 검증과 지연 해석

반응·질문·인용 관련 대상 자동 회귀에서는 같은 표적에 새 상세가 들어온 사례, 의미 없는 순서명, 무음, 모름, 부정 응답, 원문 인용, 새 주장 검증, 순수 재진술의 원래 메타데이터 보존을 검사했다. 원본 대화를 복사한 별도 회차의 실제 모델 재검증은 `artifacts/latest-dialogue-live-replay-v2.json`에 기록했다(4개 시나리오 통과, TTS·장치 재생 제외). 전체 타입·린트·테스트·빌드와 STT·TTS·브라우저 검증 결과는 [최신 로그 검토](interview-log-review-2026-11-02.md)에서 범위를 나누어 관리한다.

기존 회차에서 답변 제출→연결 음성 시작은 2.362초·3.106초, 제출→다음 질문 시작은 6.776초·9.236초였다(각 2개 관찰). 해당 진행의 질문 생성은 5.381초·3.098초였고 첫 질문 사전 준비의 모델 시간 7.678초는 별도다. 작은 표본이므로 보장값·일반적인 p95로 해석하지 않는다. 변경 후 지연은 다시 실측하며 긴 연결 멘트로 숨기지 않는다.
