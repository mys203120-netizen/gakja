기존 지원처 2개와 이전 발행본 5개를 보존하고 새 발행본 6에 개인 질문 15개를 새 지원처와 연결했다. 개인 경험은 기존 합성 테스터 자료이며 실제 대학 기출로 주장하지 않는다. 브라우저 검증용 기사 생각·대화·면접은 [QA 연습]으로 구분해 테스트 계정에 남겼다.

실제 브라우저 검증

  • 로그인 → 실제 선택 학교·로고 → 공식 안내 → 대학/학과 검색.
  • 대시보드 전공 RSS 기사 → 생각 저장·수정 → AI 비서 맥락 → 추천 즉시 전송.
  • 합성 문서 업로드 → 실제 GPT가 확인 문구를 답변 → 후속 질문에서도 파일 맥락 유지.
  • 완료 전 data-streaming=true 상태에서 24자 이상의 실제 GPT 문장을 관찰·촬영. 응답 완성본을 재생하는 모션을 사용하지 않음.
  • 대화 이름 변경 → 보관함 → 읽기 전용 보관 대화 → 복원 → 삭제 확인 모달 취소.
  • 같은 기사로 면접 시작·답변 저장·종료 → 기사 생각과 면접 원답변 비교 → 같은 기사 재연습.
  • 알림 점 표시 열람 전/후, 새로고침 뒤 읽음 유지.
  • 390×844 모바일 리포트와 채팅에서 가로 넘침 및 입력창/하단 메뉴 겹침 없음.

측정의 범위

실제 물리 마이크·카메라 권한을 켜서 녹음하는 검증은 이번에 하지 않았다. 시간 분류는 실제 오디오 신호와 원전사에 기반하며, STT가 누락한 습관어는 추정해 늘리지 않는다. 내용 변화는 인용 문장 단서 비교이며 정확성·면접 점수·실력 향상 여부를 꾸며 계산하지 않는다. 실제 환경의 잡음·STT 인식 품질은 사용자 녹음으로 추가 검증해야 한다.

개발 서버의 Turbopack 캐시 오류 이력이 있어 Windows 실행기와 npm 개발 실행은 Webpack으로 설정했다. PostgreSQL 연결과 start server.bat 실행 경로를 유지하며 환경 키는 변경하지 않았다.
