# 입력 UX QA 적용 결과

2026-10-19 · 기준 620b3f5 · 합성 데이터 및 로컬 PostgreSQL

초안 작성 → 기기/서버 보관 → 이탈·복구 → 같은 질문 답변 → 홈 이어하기의 연결을 수정했다. 원본 Excel은 변경하지 않았다.

검증: `npm test` 651개 통과 + bootstrap 28개, production build/TypeScript 통과, 별도 learning-flow render 통과. 실제 로컬 HTTP+PostgreSQL은 무기고 초안 14개, 공통/Quiz/Live 글 답변 9개 검사 통과. 별도 PostgreSQL RLS 38개 검사 통과. 내부 assertion 수는 Node 테스트 수에 더하지 않았다.

현재 Work 설정에서 로컬 브라우저 사용이 비활성화되어 브라우저 화면 조작·390px 실측은 실행하지 못했다. 실제 마이크·카메라·소프트키보드·프로세스 강제 종료·운영 Supabase/Vercel·유료 AI/STT 품질은 통과로 판정하지 않았다. 외부 AI/STT/Storage 호출 없이 검증했다.

운영 배포 전 신규 migration 두 개(`20261019042212_armory_persistent_drafts.sql`, `20261019043157_armory_draft_active_gate.sql`)를 적용해야 한다. 로컬 DB에는 적용했다. 기기 미제출 녹음은 7일 만료이며, 이미 커밋한 청크만 복구할 수 있다.
