# AI 면접관 전략 엔진 적용 결과

2026년 11월 3일 기준, 현재 면접 화면의 백엔드에 질문 전략 아키텍처를 적용했다. 디자인과 장치 조작 화면은 유지했다. 질문의 확인 대상을 먼저 정하고, 학생 기록·실제 답변·학교 공식 기준·책의 방법론을 서로 다른 권한으로 연결한다.

## 실제 적용 구조

사전 준비에서는 정본 정책과 학생 원문을 검증하고, 학생별 확인 대상과 전략 자료를 사용해 Q0를 생성한다. 최종 문장은 독립 전제 검수 후 음성과 함께 캐시한다. 현재 지원처의 주질문 5개와 대체 5개가 모두 준비됐다.

실시간에는 로컬 검색으로 답변에 적용할 전략 후보를 준비한다. 단일 코어가 관련성·요구 충족·다음 행동·후속 초점을 판단하고 승인된 질문 행위와 실제 답변 앵커를 선택한다. 서버가 출처·문장 구조·횟수·중복·시간을 검사한 뒤 발화한다. 비명백 답변의 실시간 모델 호출은 최대 1회이며, 정상 무응답 등 명백한 관찰은 0회다.

종료 후 평가에는 실제 발화·의도·요구·깊이를 함께 고정한 승인 계약을 전달한다. 계약이 바뀌면 평가를 진행하지 않는다. 기존 점수 산식과 실제 재생 기록에 따른 평가 분모는 유지한다.

## 대화 동작의 변경

- 충분한 답변을 더 파고들기 위해 partial로 바꾸지 않는다. 충족 여부와 다음 행동을 따로 기록한다.
- 충족한 요구를 같은 목적의 확장으로 다시 묻는 경우 서버가 전환한다. 실제 새 주장·수치·두 진술의 차이에 대한 확인은 구별한다.
- F2는 F1의 목표 하나로 고정하지 않는다. 원래 묶음 목적에 종속되는 다음 확인을 선택하며 후속 최대 두 번은 유지한다.
- 내부 정확한 인용과 실제 발화를 분리한다. 직접 질문·짧은 맥락·정확한 인용 중 필요한 방식을 사용한다.
- 정정·부정·모름·무관 발화·정상 무응답·기술 실패를 구분한다. 기술 실패를 학생의 부족한 답변으로 기록하지 않는다.
- 숫자만 있다는 이유로 측정 검증을 열지 않는다. 날짜·학년·자료 번호·질문 번호·순번과 실제 측정값·반복 횟수를 구별한다.
- 질문 계약과 이전 답변을 검증한 재진술은 새 평가 질문으로 세지 않는다.

실시간 F의 검수 방식은 approved_strategy_ir다. 사전 검수된 질문 구조와 런타임 출처·형태 검사이며, 독립 의미 검수 완료로 표시하지 않는다. 같은 묶음의 동일 operation 반복은 보수적으로 차단하므로 서로 다른 주장에도 같은 질문 행위가 필요한 경우 선택이 제한될 수 있다. 이를 의미 중복을 완전히 판정한 것으로 설명하지 않는다.

반복 실제 코어 검증에서는 충분하다고 판단한 근거를 다시 묻는 문제가 발견됐다. 충족한 요구의 확장 재질문을 차단하는 가드를 추가했고, met 상태의 실제 새 수치 주장 검증은 회귀 사례로 별도 유지했다. 실제 턴과 제출 ID의 저장 의미도 분리해 계약·장부의 무결성을 확인했다. 수정 전 관찰과 진단은 보존했다.

최종 합성 사례에서 모델 호출 4회의 코어 처리 시간은 약 1.90~2.95초였고 무응답은 모델 호출 0회였다. 마지막 서버 재시작 후 HTTP 사전 준비는 단일 관찰에서 109ms였다. 소수 사례의 관찰이며 p95나 실사용 지연 보장이 아니다. STT·전송·브라우저의 실제 음성 재생 시간은 이 코어 수치에 포함하지 않는다. 실제 마이크·카메라·브라우저 재생을 수행한 것으로 표시하지 않았다.

## 다음 로컬 테스트의 개선 경로

새 면접의 로그에는 코어 관련성·충족·요청한 행동과 실제 행동·전환 이유·전략 ID·문장 구조·출처·지연을 남긴다. 다음 명령으로 가장 최근 실사용 회차를 확인한다.

```text
npm run evaluate:interviewer -- --latest
npx tsx scripts/review-interview-logs.ts --latest --full
```

자동 검증용 합성 회차를 포함하려면 --latest --include-synthetic을 사용하고, 특정 회차는 --session UUID로 지정한다. 준비된 질문을 실제 재생된 질문으로 세지 않으며 미관찰 수치와 비율은 null이다. 품질 집계는 구조와 저장 관찰이며 전문 면접관의 의미 평가나 모델 재학습이 아니다.

다음 실사용 개선은 실제 답변과 질문 목적의 관계, F 선택의 필요성, 표현의 자연스러움을 사람 검토와 고정 회귀 사례로 확인하는 방식이다. 자유 문장 생성은 현재 실행 경로에 추가하지 않았다. 승인 구조를 확장하는 이번 설계와 별도로, 독립 의미 검수의 품질·지연을 비교한 뒤 결정한다.
