# 훈련 연결·모바일 입력 개편 검증

## 적용 내용

- 저장·설정 완료 알림은 본문 높이를 차지하지 않는 body portal로 표시하고 자동으로 사라진다. 같은 문구의 연속 알림도 별도 영수증으로 취급한다. 오류와 저장 중 상태는 유지한다.
- 공통 질문은 한 위치의 버튼으로 정리 → 확인·저장을 진행한다. 추가로 생각을 입력하면 다시 정리 단계로 전환한다.
- `Enter로 전송` 설정은 계정별 boolean으로 저장한다. 기본값은 켜짐이며, 끄면 Enter는 줄바꿈이다. Shift+Enter와 한국어 조합 중 Enter는 전송하지 않는다.
- 모바일 오늘의 순서는 별도 시작 버튼 대신 행 전체로 시작한다. 완료 후 최신 계획의 다음 훈련을 제안하고 마지막에는 오늘 정리를 연결한다. 완료 경계는 새 문서 링크로 이동해 직전 면접의 화면 상태가 다음 계획을 붙잡지 않게 한다.
- 하단 메뉴는 아래 방향 스크롤에서만 표시한다. 1.4초 정지 후 사라지며, 위 방향 스크롤에서는 숨긴다. 일반 환경은 투명도·작은 위치 이동을 사용하고, 동작 줄이기 환경은 위치 이동 없이 0.5초 투명도 전환만 유지한다. 전역 animation reset 때문에 전환이 사라지던 경우를 실제 계산된 스타일로 확인해 수정했다.
- 모바일 질문·답변은 좌측 정렬과 어절 단위 줄바꿈을 유지하고 추가 어절 간격을 제거했다.
- 로그아웃은 초안 저장부터 인증 종료까지 앱을 inert로 잠근다. 실패하면 잠금을 해제한다. 성공하면 기존 본문을 유지한 채 로그인 문서로 이동하며, 선택 학교 캐시 삭제 실패는 이동을 막지 않는다.
- 기존 면접관 5종은 음성 출력 RMS에 따라 원본 입술 주변만 canvas로 합성한다. 음성·다른 인물 분리와 정지 복귀 검증은 [음성·아바타 구현 기록](realtime-live2d-implementation.md)에 정리했다.

## 실제 브라우저 확인

하린 계정과 분리한 임시 학생으로 확인했다. 공통 질문의 실제 AI 정리 → 같은 버튼에서 저장 → 완료 기록 복원, 학교 등록 → 하루 시간 설정 → 첫 진단 3답변 → 집중 보완 본질문·꼬리질문 2답변 → 오늘 정리 완료까지 진행했다. 오늘 계획과 캘린더 모두 3/3 완료였고, 다음 날에는 첫 진단 대신 누적 복습이 배치됐다. 완료 후 다음 계획 이동을 새 문서 링크로 수정하고 실제 오늘 정리 진입을 재확인했다.

설정 저장 알림의 계산된 위치는 `fixed`, 상단 76px이고, 자동으로 사라진 뒤 본문 위치는 유지됐다. Enter 설정의 꺼짐·켜짐 저장과 켜짐 상태의 실제 답변 전송을 확인했다. 모바일에서 `word-spacing:0px`, 좌측 정렬·`keep-all`을 확인했다.

동작 줄이기 환경의 메뉴 전환은 `opacity 0.5s`로 계산됐다. 아래 방향에서 표시를 시작할 때 투명도 0.0202, 위 방향으로 바꿔 숨기는 중 0.3273을 확인해 즉시 0/1로 바뀌지 않음을 검증했다. 키보드 접근과 이벤트·타이머 해제는 자동 회귀로 검사했다.

증거는 Git에 포함하지 않는 `.local/interaction-polish-2026-10-21/`에 보관한다. 실제 개인 마이크나 물리 iPhone을 이번 추가 검증에서 사용하지 않았다.

자동 테스트 907개와 bootstrap 검사 31개, 실제 AppShell 바인딩 검사 89개, 훈련·시간·입력·대화 화면의 별도 렌더·핸들러 회귀를 통과했다. 로그아웃 중에는 실제 모바일 화면에서 본문 접근이 잠기고 `aria-busy=true` 및 390px 폭이 유지되는 것을 확인했다.
