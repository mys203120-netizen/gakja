# 각자ON 학습 흐름: 코드 확인과 개선 제안

확인일: 2026-10-12. 이 문서는 현재 코드의 연결과 데이터 사용을 분석한 결과다. 브라우저 재현·화면 평가는 별도 UX 감사 문서에서 다룬다. 앱이나 기존 학생 기록은 이 분석에서 수정하지 않았다.

## 판단

자료·퀴즈·면접·리포트·영상의 개별 저장 기반은 있다. 특히 면접에서 도움을 받아 같은 질문으로 돌아오기, 면접 피드백에서 재훈련 과제 만들기, 작성 답변과 면접 답변 비교는 이미 연결돼 있다. 다만 **저장된 기록이 다음 학습을 결정하는 순환은 아직 부분적**이다. 사용량이 늘면 기록은 늘지만, 현재 기본 출제와 누적 화면만으로 실력 향상을 확인하기는 어렵다.

원하는 제품 경험은 다음처럼 설계하는 것이 적합하다.

`오늘 할 일 선택 → 기억해 보기 → 이해 보완 → 내 말로 설명 → 면접에서 적용 → 한 가지 개선점 확인 → 날짜를 두고 다시 확인`

활동·개념·질문을 기준으로 이 흐름을 묶고, 각 단계에서 다음 행동을 한 번에 시작할 수 있게 한다. 자유롭게 메뉴를 고르는 방식도 유지한다.

## IA와 사용 흐름 제안

주 메뉴 다섯 개는 유지해도 된다. 현재 가장 필요한 것은 메뉴 추가보다 **오늘 할 학습 한 묶음**과 **맥락을 유지하는 다음 행동**이다.

- MY 대시보드: 첫 화면에 지원처·목표와 “오늘 시작 / 이어서” 한 개의 우선 행동을 둔다. 복습해야 할 이유·분량을 한 줄로 보여준다. 과제·진척·캘린더는 그 아래에서 확인한다.
- 퀴즈: “오늘 복습 / 자유 연습 / 과제”를 먼저 구별하고, 자유 연습 안에서 10초 선택형·Q&A·녹음을 고른다. 기존 전체 암기 유형 목록은 고급 탐색으로 둔다.
- 모의면접: “추천 설정으로 시작”을 기본 행동으로 두고 세부 질문 수·면접관 수·압박·피드백 시점은 펼쳐 조정한다. 학교 개요와 적용 중인 면접 주제 기준을 같은 화면에서 확인한다.
- 내 리포트: 첫 탭은 “달라진 점 / 다음에 할 것”을 보여주는 성장 화면으로 제안한다. 날짜별 세션과 원본 답변은 이력에서 찾는다. 종료 단위 학습 리포트와 면접 내용 피드백의 역할을 구별한다.
- 지식한입: 활동별 탐색은 유지하되 오늘 약점과 연결된 영상 한 개를 추천하고, 본 뒤 짧은 확인 질문·자기 말로 설명하기로 돌아온다.
- AI 비서·내 자료: 별도 메뉴도 유지하되 모든 풀이 화면에서 해당 질문의 근거와 도움으로 바로 열고 같은 작업으로 돌아올 수 있게 한다. 새 메뉴를 찾아 이동할 필요가 줄어든다.

## 축적할 데이터와 성장 화면

누적 횟수·저장 시간은 연습량 근거다. 실력의 근거는 같은 활동·개념·질문을 다시 수행한 결과에서 보여준다. 실제로 측정한 항목만 표시한다.

| 보여줄 변화 | 필요한 실제 기록 |
| --- | --- |
| 도움 없이 설명하는 질문이 늘었는가 | 질문 ID, 모드, 힌트/AI 도움, 직접 평가 근거, 학생/검토자 평가 구별 |
| 시간이 지난 뒤 다시 떠올렸는가 | 같은 개념의 후속 시도 시각, 직전 학습 간격, 정오/검토 결과 |
| 면접에서 질문에 직접 답했는가 | 질문 의도별 평가 항목, 답변 중 근거 구간, 평가 모델/루브릭 버전, 수정 전후 |
| 내 역할·실제 행동·결과를 구체적으로 설명했는가 | 해당 질문에 필요한 요소와 실제 답변의 증거, 불확실한 사실 확인 상태 |
| 새 표현의 질문에도 적용했는가 | 같은 개념에 연결된 다른 문항 ID, 처음 본 문항 여부, 도움 여부 |

현재 답변 비교는 글자 수와 문자열 포함 여부를 보조로 계산한다(`packages/content-contracts/src/workflows.ts:93–96`). 이를 내용 품질이나 실력 점수로 바꾸지 않는다. 성장 화면에서는 학생의 실제 전후 답변 일부와 확인된 개선 요소를 보여주는 편이 설득력이 크다.

사용자가 애착을 느끼는 계기는 앱이 “나를 기억하고 다음 준비를 덜어 준다”는 경험이다. 지난번 어려웠던 질문을 적당한 날 다시 만나고, 해결한 부분을 인정받고, 자신의 말이 좋아진 기록을 확인하도록 설계한다. 체류시간 목표만 높이는 방식이나 복귀하지 못한 날의 벌점은 권하지 않는다. 짧게 공부한 날도 끝낼 수 있게 하고 다음 계획은 사용자가 조절한다.

## 다음 검증 시나리오

1. 선택형에서 오답 → 근거 확인 → 같은 개념 Q&A → 면접 적용 → 리포트에서 관련 기록을 한 흐름으로 찾는다.
2. 힌트 사용 답변을 저장 → 다음 접속에서 도움 없이 재확인 → 현재 취약 목록이 해결 상태로 바뀌고 과거 기록은 남는다.
3. 과제·암기 복습·영상 메모를 각각 수행 → 같은 날 학습 리포트에 올바른 기록 유형으로 연결되는지 확인한다.
4. 새로운 문항이 12개/8개보다 많을 때 → 여러 학습 세트에서 전체 적격 문항이 선택 가능한지, 학교 주제 편성과 개인 약점 보완을 함께 지키는지 확인한다.
5. 발행 자료 버전이 바뀐 뒤 과거 리포트 열기 → 당시 질문·답변을 읽고 가능한 최신 재훈련으로 이어지는지 확인한다.
6. MY 계획에서 시작 → 중간에 자료/AI 도움 → 동일 질문 재개 → 수행 사실과 수동 완료 표시가 혼동되지 않는지 확인한다.
