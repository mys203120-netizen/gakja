# CSS 소유권과 회귀 기준

2026-10-21 기준, 최상위 레이아웃의 전역 CSS 41개를 문서 기반 1개와 로컬 클래스 소유 모듈로 이전했습니다. 기능 CSS를 다른 라우트에서 전역 import하는 방식은 사용하지 않습니다.

## 책임 범위

| 위치 | 책임 |
| --- | --- |
| `src/app/globals.css` | 폰트·토큰·초기화·문서 기본 타이포·문서 스크롤·공유 keyframe 이름 |
| `src/styles/shell.module.css` 및 네비게이션 컴포넌트 모듈 | 헤더·사이드바·앱 배치·하단 네비게이션 |
| `src/styles/controls.module.css` | 버튼·입력·선택·토글의 공통 모양, 호버·포커스·비활성·고대비 상태 |
| `src/styles/brand.module.css` | 로고·워드마크 |
| `src/styles/dialogs.module.css`, `feedback.module.css` | 공통 다이얼로그·알림 표시 |
| `src/styles/layout.module.css` | 공통 페이지 제목·행·그리드 등 배치 |
| `auth`, `marketing`, `admin`, `learning`, `interview`, `assistant`, `training`, `schools`, `resources` 모듈 | 각 영역의 고유 클래스 |
| 기존 개별 컴포넌트의 `*.module.css` | 해당 컴포넌트의 구체적인 상태·배치 |

새 페이지는 배치와 컴포넌트 조합을 담당합니다. 공통 컨트롤의 색상·포커스·비활성 상태를 페이지 전역 선택자로 추가하지 않습니다. 차이가 필요하면 공통 컴포넌트의 명시적인 variant 또는 CSS 토큰으로 표현합니다. 새로 작성하는 컴포넌트는 자신의 CSS Module을 직접 사용합니다.

## 기존 DOM hook의 보존

`owned-class-name.ts`는 기존 class 토큰에 소유 모듈의 로컬 토큰을 덧붙입니다. 화면 전환, GSAP, DOM 검색, 접근성 처리에서 사용하는 원래 토큰을 삭제하지 않습니다. 해석 순서는 서버와 브라우저에서 같으며 결과 캐시는 최대 2,048개입니다.

네이티브 요소에는 순수 CSS Module의 기본 요소 앵커를 붙입니다. 타입 선택자의 앵커는 `:where()`를 사용해 원래 우선순위를 높이지 않습니다. 포털로 그리는 메뉴·다이얼로그도 같은 처리를 사용하므로 앱 루트의 후손이어야만 입력 스타일이 적용되는 구조가 아닙니다. `:global()`은 기존 문맥과 상태 hook을 표현하며, 실제 소유 클래스는 로컬 토큰을 사용합니다. 앱 밖에서 자체 렌더링한 버튼에 원래 `button primary` 문자열만 붙여도 공통 버튼 모양이나 호버 효과가 적용되지 않는 검사를 포함합니다.

기존 40개 기능 전역 파일을 제거했습니다. 같은 선택자·미디어/지원 조건·중요도에서 뒤의 선언에 가려진 속성 1,320개를 제거하고 같은 규칙 안의 대체 선언은 보존했습니다. 서로 다른 선택자의 선언을 마지막 규칙으로 몰아넣어 우선순위를 바꾸지 않습니다.

## 동작 보존

- 모바일 주 메뉴: 700px 이하에서 아래로 스크롤하면 표시하고 마지막 표시 동작 후 1.4초에 숨김 상태로 전환합니다. 숨길 때 800ms opacity 전환을 사용하고, 위로 스크롤하면 다시 표시하지 않습니다.
- 키보드 탐색: 메뉴와 선택 컨트롤의 `:focus-visible`을 유지합니다. 선택된 컨트롤의 테두리 제거가 키보드 포커스 표시를 지우지 않게 합니다.
- 동작 줄이기: 메뉴의 공간 이동과 토글 이동을 제거하며 메뉴의 opacity 전환과 접근은 유지합니다. 로그인 미세 움직임은 중단합니다.
- 강제 색상: 평상시 입력 테두리 제거보다 고대비 필드 복구 규칙의 우선순위가 낮아지는 문제를 수정했습니다. 입력 경계와 키보드 outline을 복구합니다.
- 공통 버튼: `#00ed77` 배경·`#220D2A` 글자·600 두께를 유지합니다. 입력은 테두리 없이, 검색 입력은 둥근 모양을 유지합니다.
- 공유 애니메이션: 전역 keyframe의 이름을 `--gakja-keyframe-*` 토큰으로 참조합니다. CSS Loader와 Turbopack이 다르게 처리할 수 있는 `animation:global(...)`에 의존하지 않습니다.

## 검증

```powershell
node --import tsx --test tests/style-ownership.test.ts tests/style-ownership-css.test.mts tests/scroll-navigation.test.mts
node --import tsx tests/style-ownership-browser.mjs
npm run build
```

브라우저 검사는 합성 DOM과 실제 저장소 CSS로 390·700·701·1280px, 화면 CSS의 정방향·역방향 로딩, 포커스·강제 색상·동작 줄이기·방향별 메뉴 표시와 사라지는 중간 opacity를 확인합니다. 컴포넌트 로컬 모듈까지 포함해 검사하며 실제 학생 데이터를 읽거나 수정하지 않습니다.

이전 전역 CSS와 이전 후 CSS의 합성 화면 computed style은 27,280개 값을 비교했습니다. 로그인 float의 실행 시각 차이와 표시되지 않는 모바일 사이드바의 계산 폭 4건을 제외한 표시 요소의 정적 값은 같았습니다. 별도의 네비게이션 컴포넌트 모듈을 포함한 브라우저 검사에서는 실제 표시 범위와 동작을 확인했습니다. 실제 프로덕션 로그인에서도 가로 넘침 없음, 둥근 무테 입력, 브랜드 버튼과 8초 float 애니메이션, 동작 줄이기 시 중단을 확인했습니다. 실제 iOS 기기 검증을 했다는 뜻은 아닙니다.

## 크기와 다음 유지보수

분리 전 원문은 506,425B, 분리 후 소유 모듈과 기반 원문은 약 556KB입니다. 문맥 표기로 원문은 증가했으며, 같은 방식으로 gzip한 합계는 84,102B에서 약 85KB입니다. 이는 원문 비교이며 실제 네트워크 전송 크기와 동일하지 않습니다. 이 작업을 CSS 전송량 절감으로 평가하지 않습니다.

호환 class 해석기는 15개 소유 모듈을 고정 순서로 가져옵니다. 따라서 기능 CSS의 다운로드를 지연하는 작업은 포함하지 않습니다. 새 컴포넌트는 직접 로컬 모듈을 사용하고, 기존 hook 의존성이 없어지는 영역부터 호환 매핑을 제거할 수 있습니다. 이때도 화면 이동 순서와 공통 컨트롤 상태 회귀 검사를 유지합니다.
