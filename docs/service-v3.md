# 각자ON 구현 정리

> 현행 계약·검증 갱신: 2026-10-14. [문서 적용 순서](document-authority.md)와 [서비스 PRD v2.2](../확정안/4.%20서비스_PRD_v2.2.md)를 따른다. [개선·검증 요약](learning-remediation.md)과 [후속 QA](../.local/learning-remediation-2026-10-14/report.md)·[화면 보고서](../.local/learning-remediation-2026-10-14/report.html)에 실제 API/저장값·학교 등록·같은 질문의 학습 연결 검증을 기록했다. 아래 이전 테스트와 화면은 당시 범위로 보존한다. 실제 OAuth·Live/STT·장기 회상·88교 전 학과 콘텐츠 품질·운영 보안은 후속 인수 게이트이며, 이번 결과가 모든 기능이나 실제 학습 효과의 완료를 뜻하지 않는다.

## 2026-10-14 서비스 기준

각자의답은 브랜드이고 각자ON은 전체 학습 서비스다. AI 비서는 자료를 이해하는 보조 기능이며, 모의면접은 학생이 직접 답변을 제출하는 별도 세션이다. 학생의 상태에 따라 **이번에 보완할 한 가지 → 필요한 이해·확인 → 자료를 덮고 회상 → 내 답변 → 피드백 → 새 답변 → 이후 회상**으로 이어진다. 모든 학생에게 같은 순서를 강요하지 않고 자유 연습도 유지한다.

MY·퀴즈·모의면접·내 리포트·지식한입 다섯 메뉴는 유지한다. 학교·활동·질문·당시 자료는 화면이 바뀌어도 같은 학습 맥락이다. 주 행동 한 개를 먼저 두고 도움·근거·설정·이력을 보조 영역에 묶는다. 밝은 바탕, 원본 비율의 초록 로고, Pretendard를 유지하며 반복 설명·괘선·둥근 사각형·글자 굵기만으로 구분하는 위계를 줄인다. 하위 내용은 여백과 들여쓰기로 구분한다.

신규 등록은 학교 → 학과·전형 → 2027학년도 수시 일정 자동 조회(실제 2026년) → 확인·등록 완료로 연결한다. 공개 일정과 개인 배정 시간은 별개다. 교재는 외부 검수된 FINAL 가이드북 HTML 한 파일을 검증·미리보기 후 발행한다. 기존 핸드북은 과거 발행본의 호환 자료로 유지한다.

학생의 연습량과 설명 변화는 분리한다. 도움 기록 미존재는 도움 없이 수행했다는 증거가 아니다. 독립 수행·즉시 재시도·이후 회상·전사 정정·음성 미측정의 경계는 [학습 기록](learning-records.md)과 [발화·답변 변화](speech-growth.md)에 따른다.

2026-10-12의 메뉴 도입 기록을 보존하며 아래 현행 계약을 함께 적용한다. 각자ON은 각자의답의 학습 서비스 이름이고 AI 비서는 그 안의 보조 기능이다. 외부 FINAL 교재의 검증·발행 계약과 이후 사용자 결정을 우선한다.

## 화면 구조

| 주 메뉴 | 경로 | 역할과 자식 화면 |
| --- | --- | --- |
| MY 대시보드 | `/my` | 오늘의 과제·계획, 실제 퀴즈·면접 기록, 준비 진척, 시사 브리핑, 월간 일정, 주간 계획, 최근 리포트·영상 |
| 퀴즈 | `/quiz` | 10초 4지선다, Q&A, 답변 녹음. `/quiz/session/[id]`, `/quiz/assignments/[id]`, `/quiz/memory/[id]` |
| 모의면접 | `/interview` | Chat `/interview/chat`, Live `/interview/live`, 진행 중 면접 `/interview/[id]` |
| 내 리포트 | `/records` | 학습 상세 `sessions/[id]`, 면접 피드백 `reports/[id]`, 연습 이력 `history`, 답변 비교 `comparisons/[questionId]` |
| 지식한입 | `/knowledge` | 활동과 연결된 영상 목록, 영상 상세 `/knowledge/[videoId]`, 저장·시청 체크·메모 |

`/reports`는 내 리포트의 동일 화면을 제공한다. AI 비서 `/on`, 내 자료 `/materials`, 사실 확인 `/account/confirmations`, 설정 `/account/settings`는 보조 메뉴다. 모바일 하단에도 다섯 주 메뉴를 표시한다. 기존 `/practice`, `/chat`, 면접 `new?kind=chat|video` 주소는 호환한다. Live의 내부 DB 종류 `video`도 유지해 과거 기록과 연결한다.

## 퀴즈와 면접 입력

4지선다는 로컬 `CTD 윌리엄스/단어방/DANEOBANG`의 퀴즈 화면을 참고했다. 큰 질문, 원형 10초 타이머, 문항 진행 표시, 2×2 보기, 키보드 1–4 선택을 제공한다. 서버 시간을 기준으로 마감하고, 일시정지·재접속 시 남은 시간을 보존한다. 발행 자료에서 검수 상태·정답 키·네 개 보기가 유효한 문항만 시작할 수 있다. 사용자 경험을 묻는 질문을 임의로 정답 처리하지 않는다.

Q&A와 녹음은 발행된 항목과 당시 문항 스냅샷을 사용한다. 이용 가능한 모범답안 힌트를 누르면 첫 문장만 선명하게, 나머지는 흐릿하게 표시한다. 검수되지 않은 항목은 제외하고, 연결 발화본이 미확인·누락 상태면 다른 필드로 힌트를 우회하지 않는다. 녹음은 학생의 동의와 브라우저 마이크 권한을 받은 뒤 실제 MediaRecorder 파일을 저장한다. 로컬은 PostgreSQL bytea, Supabase 모드는 비공개 Storage를 사용하며 재생은 소유자 인증 API를 거친다. 녹음 답변의 정오를 자동 추정하지 않는다.

Chat 면접과 AI 비서 입력창은 `CTD 윌리엄스/CTD Dashboard/williams-instructor-os`의 입력창을 참고해 공유 컴포넌트로 구현했다. 이모티콘을 제외하고 **Enter로 전송**, **Shift+Enter로 줄바꿈**한다. 한글 조합 중 Enter, 빈 입력, 처리 중 재전송, 빠른 중복 전송을 막는다. 기존 면접 초안·일시정지·도움 사용 기록·원문 패널은 유지한다. Live는 카메라·마이크를 사용하는 화상 면접이며 실시간 스트리밍 AI·Face/Pose 분석은 후속 범위다.

## 학습 리포트 생성

브라우저 종료만을 저장 시점으로 삼지 않고, 실제 퀴즈 풀이·면접 답변을 DB에 저장하는 트랜잭션에서 학습 이벤트를 함께 기록한다. 같은 원본 ID의 재요청은 한 번만 집계한다. 진행 중 누적 현황과 확정 리포트를 구별하며 주관식·녹음의 미채점 상태, 시간 초과, Chat/Live, 도움 사용 여부를 보존한다.

- **학습 마치기** 또는 로그아웃은 소유한 학습 세션을 즉시 확정한다. 로그아웃은 리포트 저장 성공 뒤 진행한다.
- 각 탭은 고유 ID로 30초마다 접속 상태를 갱신한다. 한 탭을 닫아도 다른 탭이 살아 있으면 같은 학습 세션을 유지한다.
- 마지막 탭의 종료 신호는 30초 유예를 둔다. 새로고침·재접속의 갱신 신호가 오면 종료 예약을 취소한다.
- 종료 신호를 못 받은 경우 탭의 접속 유효기간 3분이 지난 세션을 다음 조회·갱신 요청에서 확정한다. 별도 백그라운드 작업이 정확히 30초나 3분에 실행되는 구조는 아니다.
- 확정 리포트는 당시 이벤트와 집계를 고정해 이후 답변·발행 버전 변화로 덮어쓰지 않는다. 전체 이력과 해당 학생의 누적 기록을 제공한다.

리포트는 저장한 데이터의 사실 요약이다. 활동 횟수를 합격 가능성이나 발화 점수로 바꾸지 않으며, 측정하지 않은 말하기 속도·무음·시선 지표를 표시하지 않는다.

## 대시보드 계획과 지식한입

월간 달력과 월요일 시작 주간 계획표에 학생 계획·과제 마감·지원처 면접 일정을 함께 표시한다. 계획 추가와 완료 변경은 PostgreSQL에 저장하고, 수정 번호로 동시 변경 충돌을 검사한다. 학교 전체 면접 기간과 발표된 개인 면접 날짜를 구별하며 한국 날짜와 윤년·월 경계를 처리한다.

지식한입은 발행된 활동·독서·키워드·연결 원문에서 주제를 찾아, 출판자와 YouTube 메타데이터로 확인한 현재 영상 21개·6개 분야와 학교 공식 원문을 제공한다. 일치하지 않는 활동은 별도의 YouTube 검색 링크로 보여준다. 새로운 검색 결과를 자동 수집하거나 검증된 추천으로 표시하지 않는다. 학생부 원문·개인 답변을 외부 영상 서비스로 전송하지 않는다. 영상 저장, 학생이 직접 누르는 시청 체크, 메모와 수정 이력은 자신의 DB 기록으로 보존한다. 출처와 세부 계약은 [지식한입 문서](knowledge-bites.md)에 있다.

## 화면과 로고

밝은 배경, Pretendard, 넓은 내용 영역과 절제된 색을 사용한다. 기능별 묶음·여백·들여쓰기로 위계를 표현하고 불필요한 구분선·중첩 카드를 줄인다. 학생 메뉴 브랜드는 각자ON이며 로고의 초록색 `#00EE77`·원본 형태·비율을 유지한다. 웹용 SVG의 검은 얼굴 요소 두 개만 흰색으로 바꾸고 원본 파일은 보존했다. 로그인의 큰 로고와 모바일 로고는 1초마다 시계방향 90°씩 빠르게 회전하며, 모션 줄이기 설정에서는 회전하지 않는다.

## DB와 데이터 보존

`supabase/migrations`의 아래 네 파일은 2026-10-12 메뉴 도입 당시의 추가 파일이다. 이후 변경은 전체 migration 이력을 따른다. 기존 환경 설정의 우선순위와 PostgreSQL/Supabase 연결 방식은 바꾸지 않는다.

| 파일 | 저장 대상 |
| --- | --- |
| `202610120003_quiz_sessions.sql` | 퀴즈 세션·답변·비공개 녹음 |
| `202610120004_study_sessions.sql` | 학습 세션·탭 접속·실제 학습 이벤트·확정 리포트 |

합성 테스터 하린·도윤의 발행 자료에는 2026-10-12 당시 서로 다른 개념 문항 세 개와 네 개의 보기를 갖춘 v3를 추가했다. 이후 버전도 별도 발행본으로 유지하며 이 문서의 v3를 현재 활성 번호로 가정하지 않는다. `scripts/upgrade-demo-quiz.mts`는 로컬 DB, 고정 테스터 ID·이메일, 합성 제작·검수 표시, 알려진 원본 문항과 원문을 확인한 경우에만 새 버전을 발행한다. 기존 v1·v2 자료, 이전 문항 스냅샷, 학생 답변·계정·학습 기록은 덮어쓰지 않는다. 실제 학생 콘텐츠를 이 스크립트로 수정하지 않는다.
