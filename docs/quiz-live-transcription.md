# 녹음 연습의 실시간 전사

녹음형 퀴즈는 질문 → 말로/글로 선택 → 마이크 확인 → 녹음과 실시간 전사 → 저장 후 전사 확인·편집으로 진행한다. 준비·3초 카운트다운 동안에는 전사용 마이크 복제 트랙이 꺼져 있다. 녹음 중 OpenAI WebRTC 전사로 글을 보여주며, 미리보기는 작성한 답변이나 채점 자료에 자동으로 반영하지 않는다. 기존 비공개 녹음 업로드와 저장 후 전사·문장 정리가 확정 답변의 경로다.

- 기존 서버의 `OPENAI_API_KEY`를 사용한다. 브라우저에는 키나 임시 인증 토큰을 전달하지 않고 서버가 SDP를 중계한다. `gpt-live-transcribe`, 한국어, 낮은 지연, 수동 발화 종료를 고정한다.
- 현재 학생의 활성 계정·진행 중인 비선택형 문항·revision을 연결 전후에 확인한다. 기존 AI 일일 요청 한도에 포함하고, 학생별 분당 6회·같은 문항 3초 간격을 적용한다.
- 연결 실패 시 녹음을 계속하고 저장 후 전사로 안내한다. 준비 취소·이탈·숨김 시 연결을 닫는다. 화면 숨김 중에도 원본 녹음의 기존 복구 정책은 유지한다. 전사는 복제 트랙만 사용하므로 원본 녹음 트랙을 중단하지 않는다.
- 원격 연결 종료는 발급된 학생·세션·문항·시도·call ID를 모두 대조한다. 브라우저는 종료 실패를 한 번 재시도한다.
- 실시간 전사 사용은 별도 API 비용을 발생시킨다. 기존 녹음 후 전사도 수행하므로 두 경로를 합쳐 사용량을 확인해야 한다.

## 검증

`npm test`에는 클라이언트 트랙 제어·이벤트 순서·취소·종료, 서버 인증·범위·한도·지연 응답, 실제 퀴즈 컴포넌트의 답변 보존·녹음 준비 취소 검사가 포함된다. `npm run build`로 타입과 프로덕션 빌드를 확인한다.

2026-10-20 로컬 브라우저에서 마이크 대신 오프라인으로 합성한 한국어 음성을 WebRTC로 보내 실제 OpenAI 전사를 확인했다. 음성 재생이 끝나기 전 글이 나타났고 전체 문장이 일치했다. 390×844 화면에서 질문 아래 녹음 시작 버튼을 확인했다. 실제 iOS/Android 마이크 권한·잠금 화면·운영 업로드는 별도 실기기 검증 대상이다. 합성 음성 검증용 임시 페이지와 파일은 배포하지 않는다.

공식 API 근거: [Realtime transcription](https://developers.openai.com/api/docs/guides/realtime-transcription), [WebRTC 연결](https://developers.openai.com/api/docs/guides/voice-webrtc?voice-api=realtime).
