반영한 개선 / 7

  • 답변 작성·전역 검색 입력 이름 연결

    답변 작성의 두 textarea를 보이는 제목과 aria-labelledby로 연결하고, 전역 검색에 aria-label을 추가.

  • AI 답변 도착 알림

    새 완료 응답에만 polite 상태 알림을 추가. 최초 저장 이력·실패·대기 상태를 새 답변으로 알리지 않음.

  • 녹음 상태·경과 시간 분리

    녹음 상태는 polite 알림으로, 경과 시간은 role=timer / aria-live=off로 분리.

  • 작은 글씨 가독성 개선

    대시보드 라벨·검토 상태·학교 출처/입력 안내·로그인 placeholder 색을 기존 색조 안에서 진하게 조정.

  • 키보드 포커스 표시 개선

    계정 메뉴·셀렉트·채팅 입력창에 2px 진한 녹색 포커스 표시 적용.

  • 관리자 모바일 메뉴 스크롤바

    상단 메뉴의 상시 스크롤바를 숨기고 가로 스크롤 탐색은 유지했습니다. 실제 DOM과 이미지로 다시 확인했습니다.

  • 404·오류 화면 브랜드 정렬

    로고·제목·복귀 동작을 같은 상태 화면 스타일로 정리했습니다. 404는 브라우저 검수, 오류 경계는 소스 개선만 확인했습니다.

입력 이름·포커스·알림 상태는 소스와 접근성 트리로 점검했습니다. 실제 스크린리더 음성 확인은 포함하지 않습니다.
