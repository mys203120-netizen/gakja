# 나의 무기고

2026-10-16 구현. 학생 메뉴 `/armory`에서 경험을 상황 → 내 행동 → 두 문장 확인으로 작성하고, 본인 확인 후 기존 공통 질문의 Chat/Live 연습에 연결한다. 기존 색상 변수, 내비게이션 레일, 모바일 하단 메뉴, 면접 준비 화면을 재사용한다.

- 경험 카드는 `experience_cards`에 학생별 저장한다. 초안 저장, 수정, 검색, 최대 3개 고정, 질문별 말할 순서, 실제 제출 답변 이력을 제공한다.
- 작성 중 내용은 학생·초안별 localStorage에 보관하고 서버에도 자동 저장한다. 결과·배운 점, 제목·유형은 선택 도구로 제공한다. ‘초안 보관하고 목록으로’는 기기 저장이 안 되면 서버 저장 확인을 기다리며, 양쪽 모두 실패하면 입력 화면과 글을 유지한다.
- 카드 생성은 학생 입력을 구조화하는 방식이다. 새로운 성과나 사실을 AI가 자동 생성하지 않는다. 기존 발행 활동은 경험을 떠올리는 단서로만 표시한다.
- 질문 목록은 현재 지원처에서 이용 가능한 공통 질문이다. 학교 기출이나 카드별 적합도 판정으로 표현하지 않는다.
- 면접 준비 URL은 `experienceCardId`, `experienceRevision`을 Chat/Live 전환과 미리보기에 유지한다. 서버가 소유권, 본인 확인, 버전을 확인한다.
- 시작 당시 카드 내용을 면접 세션에 복사한다. 이후 카드 수정은 과거 연습을 변경하지 않는다. AI 문맥에서는 학생의 미승인 진술로 구분한다.
- 면접 중 카드 열기는 기존 자료 도움 API로 기록한다. 다음 턴에서는 카드를 다시 접는다. 리포트에서 카드 보완으로 돌아갈 수 있다.
- 쓰기 요청은 인증, 학생 역할, Origin, 길이, 소유권, revision을 검증한다. RLS를 켜고 클라이언트 직접 DB 접근을 허용하지 않는다.
