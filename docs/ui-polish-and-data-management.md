# UI 정리와 데이터 관리 우선순위

2026-10-22 사용자 제공 화면을 기준으로 기존 앱을 수정했다. 화면·메타데이터·오류 안내·분석 화면 이름에서 ‘무기고’를 ‘내 경험’으로 통일했다. 내부 `/armory` 주소와 데이터 구조는 기능 이름과 독립된 구현 식별자로 유지한다.

## 반영한 화면

| 순서 | 화면 | 변경 및 확인 |
| --- | --- | --- |
| 1 | 모바일 로그인 하단 | 본문 ‘상단으로’ 버튼을 숨기고 고정 시작 CTA 하나만 표시. 버튼을 누르면 로그인 영역의 시작 버튼으로 포커스 복귀 확인 |
| 2 | 학습 리포트 목록 | 행 전체를 아이콘·내용·화살표 3열로 정렬. 데스크톱 좌우 24px, 모바일 16px의 안쪽 여백 확인 |
| 3 | 리포트 로딩 | 중복 스피너를 제거하고 보조 조회는 조용한 스켈레톤으로 표시. 실제 초기 화면의 ‘불러오는 중’ 한 개 확인 |
| 4 | 준비 목표 D-day | 설명과 날짜 숫자를 분리하고 숫자 줄바꿈 방지. 네 단계 타이포그래피의 제목 크기 24px로 표시 |
| 5 | 문의·처리 상태 선택 | 공통 선택 메뉴로 통일. 브라우저 기본 옵션 목록·두꺼운 클릭 테두리를 없애고 선택 배경과 체크로 구분. 방향키·Home/End·Enter·Escape 및 포커스 복귀 유지 |
| 6 | 훈련 시작 | 시작 버튼·경험 선택·근거 확인을 한 영역으로 정리. 시작·경험 선택·활동 근거를 모바일에서도 한 줄에 정렬. 경험 목록은 별도 펼침 영역으로 표시 |

확인은 앱에 연결된 브라우저에서 375px 모바일과 1440px 데스크톱으로 진행했다. 화면 증거와 로그는 `.local/ui-polish-2026-10-22/`에 저장했다. 주 행동을 명확히 구분하는 기준은 [GOV.UK 버튼 지침](https://design-system.service.gov.uk/components/button/), 선택 메뉴의 키보드 동작은 [W3C Listbox 지침](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)을 참고했다.

## 내 계정 → 데이터 관리 (구현 완료)

기존 제안의 모든 항목을 `/account/data`로 연결했다. 사용자 자료를 임의로 지우지 않고, 명시적으로 선택한 항목만 처리한다.

| 우선순위 | 기능 | 현재 상태·권장 범위 |
| --- | --- | --- |
| 먼저 | 항목별 삭제·선택 삭제 | 경험·초안·답변·대화·면접·학습 리포트·녹음·첨부·자료·계획 등 개인 자료를 통합 목록에서 선택해 휴지통으로 이동한다. 연결 자료와 삭제 범위를 확인 창에서 안내한다. 진행 중인 면접·연습은 먼저 마쳐야 한다. |
| 먼저 | 삭제 취소·휴지통·복원 | 즉시 되돌리기, 삭제 항목 검색, 선택 복원, 이메일 재입력 후 영구 삭제를 제공한다. 자동 만료 기간은 두지 않는다. 복원 충돌이나 삭제 처리 중인 원본을 조용히 덮어쓰지 않는다. |
| 먼저 | 내 계정의 데이터 관리 | 전체 자료 삭제·회원 탈퇴 요청, 접수·처리 중·완료·취소 상태와 접수 취소를 제공한다. 운영자 문의 관리와 연결한다. |
| 다음 | 전체 자료 백업·읽기 쉬운 내보내기 | 서버 자료·휴지통·미디어 원본이 들어가는 JSON, 현재 기록을 읽고 인쇄하는 HTML, 서버 전송 전 초안·녹음을 포함하는 별도 기기 백업을 제공한다. |
| 다음 | 기록 통합 검색·필터 | 전체 개인 기록에서 키워드·기간·지원 학교·유형으로 검색한다. 페이지 단위 조회와 선택을 제공한다. |
| 다음 | 공용 기기의 초안·로그인 관리 | 이 계정의 기기 초안·최근 선택 정리, 로그아웃 시 정리 설정, 로그인 기기 목록과 다른 기기 로그아웃을 제공한다. 다른 계정의 기기 자료와 진행 중인 녹음은 보호한다. |

확인 위치: `components/armory.tsx`, `app/api/armory/route.ts`, `app/api/armory/drafts/route.ts`, `app/api/media/route.ts`, `app/api/interviews/route.ts`, `components/chat-history.tsx`, `app/api/chat/route.ts`, `components/schools.tsx`, `components/account.tsx`, `components/records.tsx`, `app/api/student-records/export/route.ts`, `components/app-shell.tsx` (모두 `apps/web/src/` 기준).

모바일에서는 보조 가로 메뉴와 현재 위치 경로를 접고 상단 뒤로가기로 상위 화면에 돌아간다. 오늘 훈련의 자유 연습·AI 비서 진입과 준비 현황의 준비 자료 메뉴는 유지한다. AI 비서 보관함과 면접 연결을 같은 줄에 놓고, 스크롤 메뉴가 보일 때 입력창 아래 80px을 예약한다. 후속 요청에 맞춰 글자 크기는 13/15/18/24px 네 토큰으로 조정했다. 모바일 텍스트 입력과 읽기 쉬운 내보내기에도 같은 크기를 적용한다. 작성 중인 경험은 모바일에서 전체 폭 세로 목록으로 표시하고, 경험 유형 버튼은 단색으로 통일했다. 오늘 훈련·준비 현황·자유 연습의 중복 설명을 제거하고 제목 아래 간격을 줄였다.

운영 DB에는 `202610220003_account_data_management.sql`, `202610220004_account_data_tombstones.sql`, `202610220005_account_session_revocations.sql` 마이그레이션이 필요하다. 로컬에는 적용했다. Supabase 원본 파일 영구 삭제에는 기존 저장소 서비스 역할 키가 필요하며 연결이 없으면 복원을 막는 삭제 상태로 진입하기 전에 오류를 안내한다. 전체 삭제·탈퇴 요청은 운영자가 실제 처리와 본인 확인을 완료한 후에만 완료로 표시해야 한다.
