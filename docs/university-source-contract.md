# 대학 공식자료 적용 계약

2026-10-17 후속 결정: 이 앱은 학생부형 면접에 한정한다. 현재 선택 목록·전형/학과 제외·학과 개념 연결·D-day 과제의 구현과 검증은 [학생부형 면접 개선](student-record-preparation-2026-10-17.md)을 따른다. 아래 88교는 보존하는 원본 자료의 범위이며 현재 지원 목록 수와 다르다.

버전: university-source-v1.0 · 적용일: 2026-10-14. [서비스 PRD v2.2](../확정안/4.%20서비스_PRD_v2.2.md)의 학교·학과·전형·가입 일정 계약을 구체화한다. 이 문서는 대학별 사실을 새로 검증했다는 보고서가 아니다.

## 자료의 역할

`확정안/6. 대학별_면접_기준_v.1.0.md`와 `2027_면접바이블_대학별정리_v1.0.md`는 업로드 책의 88개교 본문과 페이지·경향을 보존하는 참고자료다. 책 본문이 있다는 사실은 현재 연도 해당 학과/전형의 면접·일정·인재상이 공식 검증됐다는 뜻이 아니다. 나머지 89개교의 본문 미수록은 면접 없음으로 해석하지 않는다.

학생의 활동 사실, 외부 승인 활동평가, 학교 공통 인재상/전형 자료, 서비스 생성 연습 질문, 기사, 학생의 의견은 별도 출처 종류다. 학교 자료를 학생의 개인 경험으로 편입하거나 개인 활동의 null 전공 연결을 다른 학교의 값으로 채우지 않는다.

공용 데이터에는 최소한 다음 provenance를 보존한다. 실제 구현은 관계 테이블/JSON으로 묶을 수 있으나 의미를 없애면 안 된다.

| 항목 | 의미 |
|---|---|
| source kind | 공식 입학처·대학/학과 공식 페이지·공시·책·집계 사이트·관리자 수정·서비스 생성 구분 |
| source URL/location | 실제 원문 URL·문서 제목·페이지/행/표·해당 발췌 |
| published/checked at | 게시일(확인된 경우), 조회일, 검수일을 구분 |
| academic year | 모집 학년도, 자료 자체의 발행/적용 연도와 구분 |
| applies to | 학교/캠퍼스/모집단위/전형/단계/계열·대상 조건 |
| verification/release | 확인 상태·검수 버전·기준 버전·원문/학습 snapshot 참조 |
| override/audit | 수집 원본, 관리자 변경, 변경자/시각/이유·영향·적용 상태 |

## 학교와 실제 학과/모집단위

학교 전체 이름을 학과명과 문자열로 임의 조합하지 않는다. 해당 학년도에 그 학교·캠퍼스의 모집단위/학과가 존재하는 공식 자료를 확인하고 정식 명칭·동의어·식별자·적용 범위를 저장한다.

대학의 현재 학과 페이지와 해당 학년도의 실제 모집단위가 다를 수 있으므로 둘을 분리한다. 자유전공/광역 모집은 임의로 특정 학과의 지원 정보로 변환하지 않는다. 학과 개편·통합·캠퍼스 이동은 별칭으로 추적하고 당시 학생/교재 기록을 덮어쓰지 않는다.

`공식 확인`, `과거 자료`, `부분 확인`, `미확인`, `현재 미모집/폐지 공식 확인`을 구분한다. 선택 가능한 조합 수와 원본 후보 조합 수는 다른 지표다. 후보 목록 수가 크다는 이유로 실제 학과 전수 검증 완료를 주장하지 않는다.

## 인재상과 평가요소

| 종류 | 적용 범위 | 금지할 혼합 |
|---|---|---|
| 대학 인재상 | 대학의 교육 방향/가치 | 해당 전형의 면접 채점표로 단정 |
| 학과 교육목표·역량 | 실제 학과의 교육 내용·학습 방향 | 대학 공통 문구를 고유 학과 인재상으로 표시 |
| 서류 평가요소 | 해당 전형/연도의 서류 관점 | 면접 비중으로 사용 |
| 면접 평가요소·비중 | 공식 면접 운영/평가 기준 | 질문 출제 확률로 자동 변환 |
| 서비스 질문 구성 비중 | 연습 모드의 질문 선택 설정 | 공식 학교의 출제 비율인 것처럼 표시 |

면접관은 학교의 인재상과 활동을 행동 근거로 연결해 질문할 수 있다. 추상 태그만으로 학생을 적합/부적합하게 판정하거나 없는 리더십·협업 경험을 만들어서는 안 된다. 공식 평가 자료가 부족한 학교는 일반 활동 확인과 학교 이해 범위를 제공하고 부족한 기준을 표시한다.

질문 선택의 서비스 비중은 별도 규칙 버전으로 관리한다. 공식 학업 35/잠재 40/사회 25처럼 평가 비중이 있어도 동일한 질문 수 비율을 보장하는 공식 근거는 아니다.

## 지원처 identity와 알려지지 않은 단계

기본 맥락은 학교 → 캠퍼스 → 실제 모집단위 → 전형 → 학년도다. 면접 단계는 확인된 경우 세부 맥락으로 사용한다.

- null/누락은 **알 수 없음 또는 옛 계약에 없음**이다. 확인된 다른 값과 같지 않다.
- 두 쪽의 확인된 기본 identity가 같고 교재 단계만 누락됐다는 이유로 지원처 변경으로 오판하거나 회상→면접 진입을 차단하지 않는다.
- 두 쪽 단계가 모두 확인됐고 다른 경우 차이를 명시하고 해당 세션/질문/자료의 적용 범위를 분리한다.
- 전역 현재 지원처와 진행 중 세션/과거 리포트의 당시 지원처를 분리한다. 선택 전환이 기존 질문·초안·근거를 조용히 변경하지 않는다.
- 동일 질문 ID를 재훈련할 때 당시 콘텐츠/학교 revision을 유지한다. 학교별 준비 관찰과 공통 활동 설명을 별도로 비교한다.

## 2027학년도 일정 조회

사용자가 지정한 가입 범위는 **2027학년도 수시 면접의 2026년 실제 시행일**이다. academic_year=2027과 실제 start/end 날짜를 별도로 저장한다. 자료에 정시 일정이 있다면 실제 2027년 날짜를 유지하며 학년도-1 규칙으로 치환하지 않는다.

아컨 수시 캘린더의 수집 대상은 88개 학교의 **면접** 항목이다. 논술·실기·합격발표/원서접수는 면접 일정으로 편입하지 않는다. 집계 사이트는 발견/연결 자료이며 공식 입학처 자료와 충돌하거나 미수록인 경우 해당 학년도 공식 공지·변경 요강으로 확인한다. 원문과 확인일을 보존한다.

같은 학교라도 전형·모집단위·계열·단계별 날짜가 다를 수 있다. 적용 범위가 불명확하면 후보를 안내하고 개인 확정 일정으로 저장하지 않는다. 공개 면접 기간은 개인 배정 시간과 다르다. 시간 없는 날짜에 09:00 같은 시간을 생성하지 않는다.

| 상태 | 의미 | 가입/캘린더 처리 |
|---|---|---|
| 확정 날짜/공개 기간 | 해당 범위의 시행일 공식 또는 확인된 출처 존재 | 날짜·기간·출처 표시, 학생 등록 확인 후 캘린더 연결 |
| 면접 있음·날짜 미정 | 실시 근거가 있고 날짜는 아직 미정/추후 안내 | 날짜 미정으로 등록 완료 가능. D-day·임의 이벤트 생성 금지 |
| 면접 미실시 | 해당 학년도·전형·모집단위의 공식 미실시 근거 | 면접 없음으로 구분, 가짜 일정 생성 금지 |
| 실시 여부/날짜 미확인 | 필요한 공식 근거가 아직 없음 | 확인 필요 표시. 미실시/미정으로 추정하지 않음 |
| 조회 실패 | 연결/외부 응답/수집 오류 | 실패·재시도 표시. 기존 값과 선택 보존, 미실시로 변환 금지 |
| 오래된/변경된 정보 | 캐시/과거 공지·변경 대상 | 확인일·당시 snapshot·최신 안내 비교, 새 버전/수정 이력 |

현재 UI/DB 상태 문자열이 위 표현과 다르더라도 같은 구분을 유지하고 매핑한다. 상태가 하나의 boolean으로 축약되면 조회 실패와 실제 미실시를 구별할 수 없다.

## 신규 가입의 완료 조건

학교 선택 → 실제 학과/모집단위 선택 → 전형 선택 → 2027학년도 수시 일정 자동 조회 → 등록 내용/상태 확인 → 완료를 한 흐름으로 제공한다. 명확한 미정·공식 미실시도 정상적인 완료 결과이며 날짜를 만들 필요가 없다. 자료 미확인/조회 실패를 확정일 조회 성공으로 표시하지 않는다.

완료 후 MY에는 해당 학교/학과·전형과 공개 면접 일정 또는 그 상태가 보여야 한다. 공개 일정 등록은 중복 요청·새로고침에서 멱등 처리하며 개인 시간 입력은 별도다. 외부 교재 발행/복귀가 계정 지원 정보와 학생 일정을 덮어쓰지 않는다.

관리자는 이미 등록된 일정, 학교/전형/학생 계정, 등록자/출처를 조회하고 수정·삭제한다. 삭제·수정은 권한·감사 이력·원본 보존·연결 학생 영향·알림을 처리한다. 자동 재수집이 관리자 편집을 조용히 덮어쓰지 않는다.

## 확인할 테스트

같은 학교의 단계 누락/양쪽 확인된 단계 차이, 실제 학과/광역모집/캠퍼스 조합, 학교별 인재상 vs 면접 평가요소, 동일 학과의 다른 전형, 2027 수시의 2026 날짜·정시 실제 날짜, 날짜/기간/미정/미실시/미확인/실패, 중복 등록·재접속·관리자 변경, 새 교재 이후 기존 일정/리포트 보존을 검증한다.

88개 학교와 모든 학과의 UX/공식 운영 사실을 한 학교 표본의 성공으로 입증하지 않는다. 실제 데이터 릴리스·검수 범위·테스트 결과는 [일정 문서](admission-calendar.md), [학교 인재상 문서](school-talents.md), 후속 QA에 따로 기록한다.
