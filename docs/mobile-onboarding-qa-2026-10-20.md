# 모바일 가입·진단·훈련 및 키워드 초안 검증

2026-10-20, 로컬 앱 `http://localhost:3100`의 390×844 브라우저에서 별도의 합성 학생으로 실제 화면을 조작했다. 하린의 학교·시간·답변 데이터는 테스트에 사용하지 않았다. 모바일 브라우저 크기로 확인한 결과이며 실제 휴대폰 운영체제의 키보드 동작을 검증한 결과는 아니다.

## 실제 학생 흐름

1. 학교가 없는 테스트 학생으로 로그인하면 학교 선택이 열린다.
2. 서울시립대학교 → 환경공학부 → 학생부종합전형I(면접형)를 선택했다. 지원학년도 선택 없이 2027학년도로 저장된다.
3. 학교 공개 면접일 11월 29일과 개인 응시 시간 미확정 안내를 확인한 뒤 등록했다. 확인 동의와 일정 근거의 fingerprint는 유지한다.
4. 곧바로 학습 시간 설정이 열린다. 다음 값을 입력하고 저장했다.

| 설정 | 입력·관찰 |
| --- | --- |
| 수능 전 평일·주말 | 120분·180분 |
| 수능 후 평일·주말 | 120분·180분 |
| 학습하지 못하는 날 | 10월 22일: 훈련 0개 |
| 날짜별 시간 | 10월 23일: 60분 |
| 가까운 7일 미리보기 | 13시간 |
| 오늘 계획 | 가능 120분, 계획 120분 |

5. 오늘 훈련의 첫 진단을 시작했다. 협업·자료 해석·전공 인재상 질문 세 개에 글로 답변했다. 실제 AI 피드백 세 건과 종료 리포트가 생성됐고 사용 로그의 completed 상태를 확인했다.
6. 다시 연습할 자료 해석 질문과 `전공 개념·이유`를 직접 선택했다. 오늘 화면은 진단 완료 1개와 집중 보완으로 갱신된다. 다음 날에는 고른 질문의 회상과 전공 보완이 배치된다. 답변하지 않은 활동을 새로 만들어 준비 완료로 표시하지 않는다.
7. 이어지는 탄소 순환 집중 보완에서 본질문 한 개와 실제 AI 꼬리질문 두 개에 답했다. 보완점 하나를 직접 입력하고 같은 질문에 재답변도 제출했다. 초기 답변·꼬리질문·재답변을 보존하며 동일 질문에 본질문 답변 2회, 꼬리질문 2회, 글 답변 4회로 합쳐진다. 음성 답변은 0회로 남는다. 오늘 계획은 진단·집중 보완 2개 완료로 표시된다. 전체 120분 계획 중 나머지 과제를 수행한 것으로 표시하지 않는다.

## 키워드로 문장 만들기

공통 질문에서 토글을 켜고 다음 합성 입력으로 실제 AI 초안을 생성했다.

- 환경공학에 관심
- 학교 주변 하천의 쓰레기를 보고 궁금했음
- 대학에서 공개 수질 자료를 비교하는 방법을 배우고 싶음

생성 결과는 두 문장의 초안이었다. 학생이 조사 시점·측정 단위에 관한 문장을 직접 추가한 뒤 저장했다. DB에서 편집한 최종 문장 보존, 완료 상태, `assisted=true`, `helpKinds=['writing']`, 제출 전 도움 영수증 한 건을 확인했다. AI 초안을 만든 것만으로 답변을 제출하지 않는다.

## 화면·안정성 수정

- 미등록 데스크톱 상단의 중복 로고를 숨기고 모바일 로고 한 개는 유지한다. 눈·입을 흰색으로 바꾸고 ON을 붙여 쓴 작은 윗첨자로 표시한다.
- 가입 소개·학년도 선택을 제거하고 모바일에서는 현재 단계 제목을 중심으로 표시한다. 하단의 반복 지원 정보 요약은 데스크톱에만 남긴다.
- 흰 사각형이 들어 있는 학교 로고는 원본을 보존하고 등록 화면에서 배경과 섞이도록 표현한다.
- 선택·입력 테두리를 정리한다. 필드 포커스는 배경 명암으로, 일반 버튼·링크의 키보드 포커스는 기존 표시로 구분한다.
- 초록 기본 버튼은 활성·비활성 모두 `#00ed77`, 글자는 `#220D2A`, 굵기 600이다. 일반 초록 글자는 `#008747`이다. 호버는 색 대신 작은 그림자로 구분한다.
- 실제 공통 질문 저장 버튼 계산 스타일에서 배경 `rgb(0,237,119)`, 글자 `rgb(34,13,42)`, 굵기 600, 비활성 opacity 1을 확인했다. 입력칸은 border 0px·outline none이다.
- 모바일의 반복 소개와 Live 상단 타이틀·학교 메타를 줄이고 주제 블록 사이의 여백을 정리했다.
- Live 글 답변은 질문 바로 다음에 놓는다. 명시적 글 전환과 다음 질문 때만 입력에 포커스를 주며 고정 헤더 아래로 이동한다. 실제 포커스가 `live-text-answer`로 이동하고 입력이 화면 안에 보이는 것을 확인했다.
- 긴 훈련 질문을 경로와 제목에 반복하지 않는다. 완료 후에는 질문별 답변·피드백을 접어 두고 보완점 선택을 바로 보여 준다. 피드백의 Markdown도 정상 렌더링한다.
- 학생부가 없는 학생의 공통 질문도 집계하므로 `전체 활동`을 `준비 항목`으로 고쳤다. `사실 확인 필요`도 답변을 안 했다는 뜻과 구분해 표시한다.
- 활동 메모 저장 응답 유실 후 활동만 바꿨을 때 이전 요청을 재사용하던 오류를 수정했다. 다른 내용으로 같은 ID를 재사용하면 409, 동일 재시도는 성공한다. 실제 컴포넌트와 API를 함께 실행한 재현 검증을 추가했다.

화면과 서버 관찰 결과는 Git에서 제외되는 `.local/mobile-flow-2026-10-20/`에 저장했다. 테스트용 로그인 정보는 검증 후 제거한다.
