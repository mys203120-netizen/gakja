# 각자의답 · 연결 전 자연스러움 검수

> 후속 사용자 지시(2026-11-04): 현재 얼굴을 승인하고 앞서 제안한 네 가지 보정은 건너뛰며 여성 제작·리깅 준비를 재개했다. 아래는 당시의 검수 기록이며 제작 보류 조건으로 다시 적용하지 않는다. 현재 결과는 `qa_report.md`를 따른다. Photoshop 검증은 제외하고 Computer Use를 사용하지 않는다.

사용자 지시에 따라 추가 연결 작업을 보류하고 원화부터 검수했다. 검수 대상은 원본, 기본 자세 합성 후보, 인물 제거 배경, 남성 RGBA 작업본이다. 이미지 파일을 직접 열어 비교했으며 이번 검수에서 코드 연결·원화 수정을 추가하지 않았다.

## 판정

**전체 분위기와 기본 자세는 양호. 합성용 원화 승인은 보류. 실제 동작은 미검증.**

따뜻한 창가 조명, 학생이 맞은편에서 보는 구도, 짙은 남색·베이지 의상, 부드러운 3D 재질은 대체로 유지된다. 여성의 턱 근처 손을 내리고 두 사람의 팔을 책상에 둔 합성 후보는 원본의 순간적인 제스처보다 정적인 대기에 적합하다.

## 수정이 필요한 부분

1. **얼굴의 일관성** — 남성 단독 작업본은 원본과 2인 후보에 비해 안경 렌즈 형태·크기, 눈썹, 눈밑·입가·턱 윤곽과 음영이 달라 보인다. 동일한 기준 원화에서 파츠를 분리해야 한다. 현재 여러 생성물을 그대로 혼용하지 않는다.
2. **투명 가장자리** — 남성의 머리·귀·재킷·손끝 외곽에 붉거나 보라색의 가는 테두리와 거친 경계가 보인다. 실제 알파 채널은 있으나 최종 합성 품질은 통과하지 못했다. 어두운 배경과 밝은 배경 양쪽에서 가장자리를 다시 검수해야 한다.
3. **손·펜·책상 접촉** — 2인 후보와 남성 작업본의 손 높이와 펜 방향이 다르다. 공통 캔버스에 그대로 놓으면 노트와 펜촉의 접촉, 착석 높이, 접촉 그림자가 어긋날 가능성이 크다. 배경과의 정확한 합성은 아직 만들거나 검수하지 않았다. 배경에는 책상·의자·소품이 함께 있어 최종 가림 레이어 분리도 남아 있다.
4. **표정** — 두 사람의 미소는 인사 장면에는 적합하다. 계속 웃는 한 장의 원화로 학생 답변의 중립적 경청 상태를 대신할 수 없다. 입꼬리를 낮춘 중립·집중 표정과 전환을 별도로 제작·검수해야 한다.
5. **액세서리의 자산 간 일관성** — 2인 후보의 남성 손목시계는 단독 작업본에 없다. 원본 저해상도 손목에서 시계 유무를 단정하지 말고, 원본 확대 대조 후 한 규격으로 통일한다.

우선순위는 얼굴 기준 통일 → 가장자리 정리 → 손/책상/펜 정렬 및 가림·그림자 → 중립 표정이다. 남성 한 명의 이 기준을 승인하기 전 여성의 분리 모델 제작으로 확대하지 않는다.

## 실제 확인한 파일

- `public/live2d/art/reference.png`: 제공 원본, 640×360.
- `public/live2d/art/neutral-scene-working.png`: 기본 자세 후보, 1672×941, 단일 불투명 이미지.
- `public/live2d/art/room-with-desk-working.png`: 인물 제거 배경 작업본, 1672×941. 최종 분리 레이어가 아님.
- `public/live2d/art/male-neutral-cutout-working.png`: 남성 단일 RGBA 작업본, 1672×941. 눈·입·머리 파츠 분리 전.
- `public/live2d/art/artwork-inspection.json`: 실제 크기·파일 해시·알파 픽셀 검사.

## 이번 판정에서 제외한 항목

전용 `.moc3`, `.cmo3`, `.can3`, 파츠 PSD 및 제공된 Core가 없다. 따라서 깜빡임, 고개·손 동작, 립싱크, 동작 중 얼굴·안경·목·손의 형태 유지, 모바일 30FPS를 검증하지 못했다. 정적 이미지에 대한 판정만으로 실제 면접 장면이 자연스럽다고 주장하지 않는다.

웹에서는 앞서 장면 연결 확인 페이지의 정적 이미지와 모델 대기 안내를 확인했다. 이후 `/interview`는 서버 오류가 표시되어 최종 배치·실행 검수는 완료하지 못했다. 개발 의존성 복구도 `ENOTEMPTY`로 끝나 재확인이 필요하다. 이전에 통과한 관련 52개 테스트·웹 빌드·Expo 타입 검사는 해당 시점의 결과이며 현재 최종 환경 재검증으로 계산하지 않는다.

연결 재개 전에는 개발 의존성 및 서버 표시를 복구하고, 이 원화 검수에서 지적한 항목부터 수정해야 한다. 현재 `public/live2d/scene.json`의 `blocked` 상태를 유지한다.
