# 지식한입과 계획의 학습 연결

> 현행 계약·검증 갱신: 2026-10-14. [문서 적용 순서](document-authority.md)와 [서비스 PRD v2.2](../확정안/4.%20서비스_PRD_v2.2.md)를 따른다. [개선·검증 요약](learning-remediation.md)과 [후속 QA](../.local/learning-remediation-2026-10-14/report.md)·[화면 보고서](../.local/learning-remediation-2026-10-14/report.html)에 실제 API/저장값·학교 등록·같은 질문의 학습 연결 검증을 기록했다. 아래 이전 테스트와 화면은 당시 범위로 보존한다. 실제 OAuth·Live/STT·장기 회상·88교 전 학과 콘텐츠 품질·운영 보안은 후속 인수 게이트이며, 이번 결과가 모든 기능이나 실제 학습 효과의 완료를 뜻하지 않는다.

## 2026-10-14 한 질문으로 돌아오는 흐름

영상·학교 공식 원문은 이해를 보완하는 자료다. 학생의 현재 상태에 따라 자료를 읽고 내 설명을 남기거나, 자료 없이 먼저 회상한 뒤 필요한 부분만 확인할 수 있다. 읽음/시청/자가 확인/제출은 각각의 사실이며 독립 설명 완료로 합치지 않는다.

질문·활동·지원처·당시 개인 버전/공통 revision을 다음 퀴즈·면접·리포트까지 유지한다. 면접에서 자료를 확인하면 해당 시도의 도움 증빙으로 남기고 원래 질문·초안으로 복귀한다. 계획의 직접 체크와 실제 수행은 구분하며, 이후 회상은 실제 새 무도움 답변이 있어야 관찰할 수 있다.

가입의 공개 면접 일정 연결도 같은 계획표에서 보이지만 개인 일정·학습 계획을 덮어쓰지 않는다. 전체 흐름의 주 행동은 '이번에 보완할 한 가지'에 맞추고 여러 메뉴의 같은 기능 링크를 묶는다.

2026-10-12 화면별 QA의 9단계와 계획 편의를 반영했다.

## 지식한입

- `/knowledge?questionId=...&flow=today`에서 현재 나의 질문과 연결된 영상을 먼저 보여준다. 영상 연결은 실제 활동 ID와 검수된 주제 사전으로 결정하며, 전공 이름이나 답변을 바탕으로 임의 영상을 생성하지 않는다.
- 다음 추천은 공통 학습 집계의 **현재 남은 약점**을 사용한다. 과거 오답 뒤 도움 없이 확인한 정답은 해결 상태이며, 미채점 답변·힌트 사용·AI 도움만으로 약점을 지우지 않는다.
- 영상 상세에서 짧은 확인 질문, 일시정지 가능한 30초 말하기 안내, 내 설명 저장, 스스로 확인을 제공한다. 시청 체크·자기 설명은 정답 점수나 독립 검증 결과와 구분된다. 타이머 종료나 YouTube 열기는 완료 기록을 만들지 않는다.
- 같은 질문을 면접에서 말하기, 퀴즈에서 떠올리기, 내 활동 답변에 연결하기로 이어진다. 오늘 학습 맥락을 유지한다. 면접에서 이동했다면 `sessionId`가 나의 면접 목록에 있을 때 해당 면접 복귀 링크를 제공하며 임의 `returnTo` URL을 사용하지 않는다.
- 질문과 근거·AI 도움은 같은 화면의 도움 패널에서 연다. 이 경로에서 AI 요청을 보내면 설명의 `assisted` 기록을 보존한다. 사용자가 다른 도구에서 받은 도움까지 자동 판별하지 않는다.
- 메모와 설명은 각각 4,000자 한도이며 초안은 사용자·영상·질문별로 구분한다. 설명을 다른 질문에 그대로 귀속시키지 않는다.

API GET은 `videoId`(이력), `questionId`(현재 소유 질문)를 받는다. 존재하지 않는 현재 질문은 404이며 다른 학생 자료를 반환하지 않는다. POST는 `save`, `complete`, `reflection`, `explanation`, `self_check`와 `expectedRevision`을 받는다. `self_check`는 `explained`, `needs_review`, `not_yet` 중 하나이며 정답 여부를 임의로 보내지 않는다.

현재 상태의 `snapshot.learning`과 수정 이력의 `metadata.learning`에 질문·원문·발행 버전·스스로 확인·설명·AI 도움을 보존한다. 실제 변경은 같은 트랜잭션에서 `knowledge_progress` 이벤트를 기록하고 소스 ID는 `진행ID:수정번호`로 중복을 막는다. 북마크 저장과 동일 내용 재시도는 학습 이벤트를 만들지 않는다. 과거 저장 영상의 근거 버전은 현재 자료 버전으로 바꿔 표시하지 않는다.

## 계획과 일정

- 계획을 만들 때 나의 질문·활동·영상·과제를 연결할 수 있다. 일정의 제목을 누르면 해당 항목을 시작한다.
- 서버는 연결 ID가 나의 발행 자료·개인 저장 영상·배정 과제 또는 이용 가능한 공통 질문인지 확인한다. 사용자가 보낸 임의 URL은 저장하지 않으며 경로를 서버에서 도출한다.
- 공통 질문은 개인 퀴즈가 없어도 모의면접으로 연결한다. 해당 학교의 문항은 나의 지원 학교 맥락으로 연결한다.
- 제목·날짜·학습 종류·연결 항목을 수정할 수 있다. 수정 번호가 다르면 409로 기존 계획을 보존한다.
- **직접 체크함**과 **연습 기록 있음**은 별도 상태다. 직접 체크, 링크 클릭, 체류시간만으로 실제 연습을 만들지 않는다. 연습 표시에는 해당 계획 생성 이후의 일치하는 소스 이벤트가 필요하고, 한국 날짜가 계획 날짜보다 이르면 미래 복습을 수행한 것으로 표시하지 않는다.
- 발행 자료가 변경돼 연결 대상이 사라지면 안전한 시작 링크를 비활성화하고 계획을 다른 항목으로 수정할 수 있다. 기존 계획의 제목과 기록은 보존한다.
