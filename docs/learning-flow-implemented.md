# 각자ON 화면별 QA 개선 반영

반영·검수일: 2026-10-12. [이전 QA](learning-flow-qa.md)의 개선안을 현재 Next.js·PostgreSQL 구조에 구현했다. 아래 화면은 반영 후 별도 합성 계정으로 새로 촬영했다.

## 화면별 변경

| 화면 | 반영한 개선 |
| --- | --- |
| 로그인·첫 이용 | 기존 로그인·소셜 가입을 유지하고 신규 계정에 학교 등록을 우선 제안한다. 학교 안내를 확인한 뒤 개인 자료 없이 공통 질문을 시작할 수 있다. |
| MY | 오늘 시작·이어서 한 개를 우선 표시한다. 진행한 세션, 오답·복습일, 배정 과제, 저장한 질문과 미연습 항목으로 다음 행동을 정한다. 개인 자료가 없으면 0/0 진척도와 사용할 수 없는 퀴즈 링크 대신 공통 면접 기록을 보여준다. |
| 오늘 학습 | 질문을 기준으로 기억 확인 → 연결 영상 → 내 설명 → 면접 적용 → 답변 비교 → 복습일을 연결한다. 실제 연결 자료가 있는 단계만 표시하며 ‘기록 있음’과 정답 확인을 구별한다. 모든 단계에 기록이 있으면 답변 비교와 다음 질문을 제안한다. |
| 퀴즈 진입 | 오늘 복습·자유 연습·과제를 구분한다. 준비한 미시작 세션을 재사용하고 주제·날짜·진행 수를 표시한다. 시간 제한 없는 선택형도 제공한다. |
| Q&A·녹음 | 검수된 첫 문장과 두 줄의 흐린 자리 표시를 사용한다. 입력 초안, 힌트·도움 사용, 원본 버전과 비공개 녹음 연결을 보존한다. 개념 설명을 개인 경험 질문으로 바꾸지 않는다. |
| 퀴즈 완료 | 실제 제출 답, 검수된 정답·근거, 미채점을 구분해 보여준다. 같은 질문의 1문항 면접 준비로 바로 이동한다. 옛 개념의 연결이 다르면 ‘이 활동 면접에 적용’으로 표시한다. |
| 내 리포트 | 퀴즈·면접·암기·과제·영상 설명을 중복 없이 합산한다. 과거 기록은 원본 시점으로 별도 연결하며 기존 확정 리포트는 보존한다. 남은 오답과 도움 없이 재확인한 개념을 구분한다. |
| 답변 비교 | 작성본·Q&A·녹음·과제·면접 답변을 같은 질문의 실제 이력으로 비교한다. 힌트·AI 도움·미채점·당시 자료·학교 정보를 보존한다. 검수된 AI 메시지에서 저장한 답변 후보는 서버가 소유권과 버전을 확인한다. |
| 모의면접 | 선택 질문 미리보기와 1문항 시작을 앞에 둔다. 상세 설정은 접고 Chat/Live 전환·새로고침·도움 이동 시 질문·지원처·설정을 유지한다. Enter 전송과 Shift+Enter 줄바꿈, 임시 답변 복구와 종료 확인을 제공한다. |
| 지식한입·계획 | 영상 뒤 확인 질문·30초 설명·자기 점검·면접·퀴즈로 이어진다. 계획에 실제 질문·활동·영상·과제를 연결해 바로 시작한다. 직접 완료 체크와 실제 수행 기록을 구분한다. |
| 학교·설정 | 88개 대학 참고 개요와 8개 공통 질문, 9개 적격한 제공본 일반 문항을 적재했다. 평가 배점과 출제 비중, 제공 자료와 공식 확인 상태를 구분한다. 내 기록 JSON 내보내기와 앱 알림 조절을 제공한다. |

## 기록·자료 보호

- 마이그레이션 008–011을 적용했다. 과거 집계를 연결해도 이미 확정한 리포트의 내용을 다시 쓰지 않는다.
- 하린·도윤 합성 테스터의 자료에는 검수된 힌트와 독립된 개념 질문을 새 버전 4·5로 추가했다. 이전 발행본·개인 질문·답변·면접은 보존했다.
- 과거 자료로 다시 면접을 연습하면 당시 질문·지원처를 사용한다. 현재 학교 정보와 식별 정보가 다르면 최신 프로필을 섞지 않는다.
- 도움 패널을 열기만 하거나 면접을 단순 재개한 것은 AI 응답 사용으로 표시하지 않는다. 실제 완료된 AI 응답을 받은 경로만 해당 도움 기록을 넘긴다.
- 이미 면접에 적용한 퀴즈·과제 질문을 다음 적용 후보로 반복 제안하지 않는다. 정확한 질문 ID와 원래 수행 시점을 사용하며 면접 후 새로 연습한 것은 다시 후보가 된다. 적용 완료와 오답 해결은 별개다.
- 체류시간, 시청 체크, 글자 수, 저장 횟수와 자가평가를 실력 점수로 승격하지 않는다.

## 실제 검수

1440×1000과 390×844에서 화면을 확인했다. 개인 자료가 있는 합성 계정과 개인 자료가 없는 신규 합성 계정으로 다음 동선을 직접 수행했다.

1. MY → 오늘 질문 → 개념 Q&A 힌트·답변 저장 → 같은 개념 면접 → Enter 답변 저장 → 누적 리포트·같은 질문 비교.
2. 개인 경험 질문 → 역할에 맞는 첫 문장과 두 줄 힌트 → Q&A 저장 → 중간 선택 화면 없이 1문항 면접 → 실제 전후 답변 비교.
3. 면접 초안 → AI 비서의 읽기 전용 근거 → 원래 면접 복귀. 질문·발행본·초안 유지와 단순 복귀의 도움 미기록을 확인했다. 유료 응답은 요청하지 않았다.
4. 연결 영상 → 내 설명 저장·자기 점검·시청 체크 → 계획에 실제 영상 지정 → 시작 링크와 ‘직접 체크함’ 표시.
5. 신규 계정 → 학교 등록 → 출처 있는 대학 개요 → 공통 질문 첫 면접 → 답변 저장 → 3일 뒤 복습 계획.
6. 알림 설정 끄기 → 알림 창 반영, 내 기록 JSON 다운로드와 소유한 답변 포함 확인.

브라우저에서 만든 두 계정과 관련 기록, 해당 계정의 다운로드 파일을 검수 후 정리했다. 원래 확정 리포트·면접 답변 4개·두 합성 테스터의 발행본 1–5가 보존된 것을 DB로 확인했다. 기본 화면 크기도 복원했다.

## 자동 검증

최종 프로덕션 빌드와 TypeScript 검사가 통과했다. 주요 회귀 결과는 다음과 같다. 숫자는 각 검사군의 최종 결과이며 중복 실행을 합산하지 않는다.

- 통합 기록·답변 후보 출처: 격리 PostgreSQL 검사 50개. 다음 질문의 정확한 식별·수행 시점·적용 순서 18개.
- 학교 등록·권한·과거 지원처·세션 자료·도움 재개: API 35개, 규칙 15개.
- 퀴즈 선정·힌트·서버 시간·소유권·개념 식별: API 51개. 실제 컴포넌트 초기·빈 결과 렌더 검사 17개.
- 영상: 규칙 9개, API 41개. 계획: API 59개.
- 오늘 학습·면접 설정·퀴즈 선정 순수 규칙: 18개.
- Chat 맥락·초안·발행본: 28개. Enter·IME·중복 전송 방지: 26개.
- 근거 도움 API: 소유권·버전·공통 질문·모범답안 노출 방지 8개.

이 검수에서 외부 소셜 로그인, 유료 AI의 실제 의미 평가, 카메라·마이크·발화 중 스트리밍 전사는 수행하지 않았다. 면접관의 기존 5단위 반응은 답변 제출 후 평가 방식이다. 학교 제공본을 최신 공식 모집요강과 대조하거나 MMI·집단·제시문 세트를 새로 구현한 것으로 표시하지 않는다.
