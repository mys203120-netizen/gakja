## 연결에서 고친 문제

| 발견 | 반영 |
|---|---|
| 학과 정의를 고르면 대학 공통 인재상이 사라짐 | 대학·학과의 프로필과 포인트, 각각의 출처를 함께 반환 |
| 개인 발행 자료가 없으면 퀴즈·과제를 시작할 수 없음 | 공통 학교 질문의 Q&A·녹음·실제 배정 과제를 지원 |
| 학교 질문에는 개인 활동을 선택할 수 없음 | 확인된 자기 활동만 선택해 원문 근거와 함께 고정 |
| 공통 자료 개정 번호를 개인 발행본 번호로 취급 | 두 출처를 구분하고 공통 질문의 개정 번호를 복귀·시작·도움·저장까지 보존 |
| 퀴즈·과제의 답변과 면접 답변이 다른 종류로 묶임 | 같은 질문의 답변 계열을 연결하되 별도 개념 질문은 분리 |
| 같은 질문 ID가 다른 학교·학과의 기록을 완료하거나 향상으로 처리 | 학교·학과·캠퍼스·학년도·전형·면접 단계·출처 기준으로 비교와 추천 분리 |
| JSONB 키 순서가 달라 같은 학교 설명이 숨겨짐 | 명시적인 의미 필드로 비교. 같은 영상 A→B→A의 이전 설명도 해당 이력에서 복원 |
| 긴 면접 개요 아래에 학교 정의가 묻힘 | 학교 정의와 학습 링크 먼저 표시. 면접 개요는 펼쳐 읽기 |
| 과제 제목과 문항의 긴 내용이 중복됨 | 학교 과제 제목을 포인트 이름 중심으로 짧게 표시 |
| 과제 제목 아래의 두 부제 문단이 겹침 | 학교·학과·항목 수를 정상 부제 한 줄에 모으고 음수 여백 제거 |
| 교육목표 질문도 인재상으로 안내 | 면접 준비의 공통 안내를 ‘학교 가치 질문 · 공식 원문 기반 연습’으로 변경 |
| 과제의 면접 링크에서 선택한 활동이 사라짐 | 현재 원문이 그대로일 때 활동 ID를 이어 전달. 재발행 뒤에는 옛 근거를 현재 경험으로 재해석하지 않음 |

저장·시청·자기점검 횟수를 실력이나 객관적 정답으로 승격하지 않는다. 과거 원문과 종료 리포트는 보존하며, 발화 공백은 실제 음성 측정이 있는 경우에만 비교한다.
