# 후속 네 기능 구현·전체 흐름 검수 결과

2026-10-23 · 로컬 작업 폴더 / Next.js production build · GPT Live 1 보류 유지

남아 있던 OCR, 면접 전 영역 재배치 제안, 연속 영상 관측, 완성 예시답변을 구현했다. 요구사항 대조표는 코드 연결 기준 27/27 반영이다. 배포·커밋은 하지 않았다. 유료 AI 호출, 실제 학생 개인정보, 실제 마이크·카메라 입력을 사용하지 않았다.

## 전체 흐름에서 확인한 경계

1. **입력 → 원문:** 합성 스캔 2쪽을 실제 로컬 OCR로 인식했다(신뢰도91/90). 신뢰도가 높아도 ‘출처’ 등 실제 오인식이 있어 원본 PNG와 대조하고 브라우저에서 정정했다. 모든 쪽 확인 전에는 확정할 수 없었다.
2. **원문 → 저장:** 실제 학생 화면에서 원본을 확정했다. 이후 줄바꿈 정정으로 인식문2차를 저장해도 PDF 바이트·해시·초기 OCR·1차 텍스트는 그대로였다. 분석은1차 근거임을 표시했다. 교체409, 타 계정 원본/페이지/MD404를 확인했다.
3. **분석 → 학습 자료:** 실제 발행 서비스에 합성 분석기를 주입해4활동·질문·출처·MD를 발행했다. UI/API/저장 계약 검사이며 실제 유료 분석 모델 품질 검사가 아니다. OCR 근거는 ‘학생이 확인한 인식문’ 상태·차수를 유지한다. 4지선다에 필요한 고유 활동명이 부족하면 준비 상태를 표시한다.
4. **계획 → 적용·복원:** 보완 영역 날짜 제안의 미리보기를 읽고 실제 적용했다. 공통 질문3단계가 진로활동4단계로 바뀌었다. 프로덕션에서 되돌려 원래3단계와 순서를 복원했다. 제안 조회만으로 저장하지 않는다.
5. **훈련 → 면접·복기:** 기존 원문 복습·10초4지선다·화상 준비·날짜 기록·질문별 복기 연결과 API의 지원처 분리를 검사했다. 실제 음성/TTS와 진행 상태는 이전 합성 컨트롤러 검사와 구분한다.
6. **영상 → 시간 구간:** 실제 브라우저에서 합성 WebM59시간위치와 공개13초영상130시간위치를 디코딩·추적했다. 공개 영상에서 상체2구간(0.5–3.6초,5.3–8.4초), 얼굴 관측불가·손별 관측 비율을 표시했다. 두 번째 구간 클릭 후 원본5.3초 이동을 읽어 확인했다. 이 공개 테스트 원본은5fps이므로 검출 정확도나 면접 데이터 일반화를 증명하지 않는다.
7. **예시 → 저장·다운로드:** 사실 선택·확인 후 한 문단을 저장하고 복사 완료를 확인했다. 실제 API와 개별/날짜 리포트 다운로드의 문장이 일치했다. 같은 요청의 중복 과금·저장, 다른 소유자, 미완료·무효 턴, 생성 중 바뀐 근거를 검사했다. 브라우저는 AI 미설정 연결 방식이며 유료 출력은 주입 검사만 수행했다.

## 발견 후 해결한 문제

- OCR 언어 바이너리가 Webpack 번들에 들어가 화면 컴파일 실패 → 서버 외부 패키지/패키지가 제공하는 절대 언어 경로로 수정, 실제 Next 서버에서91/90 인식 성공.
- 페이지 확인 중 업로드 폼도 함께 노출 → 확인 단계는 원본 대조 하나에 집중하고 명시적 다시 선택 때만 업로드 폼 제공.
- 되돌리기 미리보기의 순서만 UUID 정렬 → 보존된 훈련 sequence 정렬, 과거 이력도 수정된 미리보기에서 정상 확인.
- 예시의 유효 ID만 검사하면 새 행동·부정 반전 가능 → 새 내용 어휘·수치·역할과 부정 보존 검사, 미확인 질문/활동·미처리 정정은 생성 보류.
- 동일 예시 요청의 동시 유료 생성과 실패 토큰 누락 → 서버 요청 lease·사용량 보존·저장 직전 근거 재검증.
- 영상 취소·재시도 결과가 뒤늦게 섞이는 경우 → lease와 취소 검증, 취소한 부분 결과 저장 거부.

## 남은 문제·출시 전 조건

검사한 범위의 미해결 P0/P1 기능·시각 결함은 없다. 아래는 구현 누락과 별개인 정확도·운영 조건이다.

- **OCR 오인식:** 표·작은 글자·저해상도·손글씨의 정확도를 보장하지 않는다. 전 페이지 확인·정정을 계속 요구한다. 원본 진위·본인 소유 인증 기능은 아니다.
- **유료 AI 품질:** 실제 생기부 분석·예시답변의 한국어 품질과 의미적 사실성, CLOVA5음성·전사 정확도·지연은 실측하지 않았다. 예시 문장 검증은 의미 전체 일치의 증명이 아니다.
- **영상:** 얼굴 방향은 눈의 시선이 아니다.100ms보다 빠른 동작, 가림, 카메라 이동은 놓치거나 섞일 수 있다. 관측 비율은 정확도 확률이 아니다. 지원 브라우저·낮은 메모리 기기와 실제 iOS/Android 성능 검증이 남는다. 최대20MB/20분.
- **배포 운영:** 새 migration0004/0005 적용, OCR worker/WASM/canvas·언어 데이터 포함, 영상 모델 자산 빌드 준비, 임시 파일 삭제 CLI 정기 실행이 필요하다. 로컬에는 migration을 적용했지만 운영 배포는 수행하지 않았다.
- **GPT Live 1:** 계속 보류. 새 실시간 음성 모델 연동은 추가하지 않았다.
