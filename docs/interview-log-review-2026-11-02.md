## 무응답과 평가

Space는 답변 제출 의사로 처리한다. 정상 STT가 빈 원문을 확정하면 `NO_ANSWER`로 기록하되 발화가 없었던 관찰과 발화는 있었지만 전사가 없는 관찰을 구분한다. 일정 시간 조용하다는 이유만으로 자동 제출하지 않는다.

순수 재진술 답변은 원래 평가 질문과 묶고, 실제 답변 턴 ID·원문 구간을 보존한다. 재진술 자체를 별도 점수로 만들거나 무음을 가짜 답변·0점으로 채우지 않는다. 모든 시도가 비어 있으면 평가 불가 사유를 기록한다. 실제 STT 오류·미확정 전사·관찰된 무발화·전사 내용 부재의 사유도 나눈다.

## 시작 흐름

1. 중앙 모핑 클릭 → 같은 화면의 **시작 전 확인** 패널.
2. 일반 화면에서 권한 요청·실제 마이크 입력 크기·카메라 미리보기 확인. **카메라 없이 진행**도 선택 가능. 아직 세션 질문·면접 타이머를 시작하지 않는다.
3. 사용자가 **전체화면으로 면접 시작** 클릭 → 실제 전체화면 진입 확인.
4. 3초 카운트다운 → 첫 질문. 첫 질문 음성이 실제 재생될 때 면접 시간을 시작한다.

전체화면 진입 실패나 첫 질문 전에 전체화면·표시 상태를 잃으면 준비 화면으로 돌아가 재시도한다. 권한 허용 창을 면접 중 전체화면 이탈로 오인하지 않는다. 이미 시작한 면접의 기존 이탈·재개 정책은 유지한다. 기존 면접 화면 디자인은 유지하고 준비 패널·카운트다운만 추가했다.
