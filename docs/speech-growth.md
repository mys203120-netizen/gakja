# 발화와 답변 변화

> 현행 계약·검증 갱신: 2026-10-14. [문서 적용 순서](document-authority.md)와 [서비스 PRD v2.2](../확정안/4.%20서비스_PRD_v2.2.md)를 따른다. [개선 요약](learning-remediation.md)·[후속 QA](../.local/learning-remediation-2026-10-14/report.md)에 최신 API·저장값·브라우저 검증을 기록한다. 아래 검증 이력은 당시 범위로 보존하며, 실제 음성 정확도·장기 회상·모든 학교 콘텐츠 품질은 별도 인수 게이트다.

최종 정합성 검수: 2026-10-14. 확정된 학생부 분석 기준과 연결 학습 QA의 원칙을 따른다. 학생의 실제 경험, 검수된 질문별 의미 요소, 저장된 답변 원문을 유지하며 자동 문장 관찰을 능력·정답 판정으로 승격하지 않는다.

내 리포트(`/records`)의 첫 화면은 학습 완료 수 대신 실제 녹음과 같은 질문에 남긴 답변을 보여 준다. 활동 수는 접힌 보조 기록에 남긴다.

## 측정 근거

- 쉼은 실제 마이크에서 수집한 RMS 음량의 100ms 구간으로 측정한다. 답변 안의 700ms 이상 쉼, 1.5초 이상 긴 쉼, 관찰 구간의 음성 공백 비율, 답변 시작·끝 공백을 구분한다.
- 마이크가 관찰되지 않은 시간은 무음으로 만들지 않는다. 수집률이 85% 미만이거나 수집이 잘렸거나 배경 음량이 높으면 부분 측정으로 표시한다. 배경 소음과 작은 목소리에 민감한 음량 기반 추정치다.
- 습관어와 반복은 원래 STT 전사에서 직접 확인한 문자열·위치·횟수다. `음`, `어` 등 독립적인 표현만 탐지해 `음성`, `어머니`를 습관어로 세지 않는다. 반복된 핵심 용어는 잘못된 발화라고 판정하지 않는다.
- STT는 습관어를 생략할 수 있으므로 확인된 횟수는 실제 횟수의 하한일 수 있다. 원전사·AI 화면용 정리·사용자 정정문을 구분한다. 후가공에서 습관어가 사라져도 원전사 관찰값을 바꾸지 않는다.
- 말하기 속도는 원전사의 어절 수를 실제 녹음의 전체 답변 시간으로 나눈 어절/분이다. 원전사 또는 신뢰 가능한 시간 측정이 없으면 표시하지 않는다. 텍스트 입력이나 화면에 머문 시간으로 공백·속도를 추측하지 않는다.
- 같은 질문에 남긴 이전·최근 녹음만 추세로 비교한다. 짧은 쉼이나 빠른 속도가 무조건 좋은 답변이라고 판정하지 않는다.

기존 녹음은 `녹음 다시 분석`으로 비공개 음성을 브라우저에서 디코딩해 RMS 구간을 다시 생성할 수 있다. 재생하거나 마이크·카메라를 열지 않는다. 지원하지 않는 형식은 분석할 수 없다고 표시한다. 분석 음성이 없는 기존 영상은 시간 측정 없이 남는다.

## 내용 변화와 다음 연습

같은 질문·지원처·전형의 실제 작성본·Q&A·면접 답변을 연결한다. 비교 기준은 **각 답변의 당시 질문·답변 설계에 저장된 검수 의미 요소**다. 역할만 묻는 질문에 고정된 근거·수치·과정·결과 요소를 임의로 요구하지 않는다. 질문별 기준이 없는 과거 기록에는 일반적인 표현 관찰만 제공하고 이를 부족 요소나 다음 과제의 진단으로 사용하지 않는다.

의미 요소와 실제 학생 문장을 나란히 보여 준다. 관찰한 표현은 정확한 원문 인용이며, `제 담당은 … 측정표를 작성하는 일이었습니다` 같은 실제 역할 표현도 포함한다. 미래 계획, 가정, 역할을 기억하지 못한다는 답변, 다른 사람의 역할은 본인이 수행한 역할로 인정하지 않는다. 지원하지 않는 의미 요소는 동일 문구가 있는지만 관찰하고 의미를 충족했다고 추론하지 않는다.

새 문장·표현 변화·최근 표현 미확인·문장 확인 필요를 구분한다. 자동으로 찾은 문장이 없다는 것은 내용 누락·오답·낮은 능력의 판정이 아니다. 다음 행동도 `이 요소를 내 문장으로 설명했는지 확인`으로 제시한다. 분량, 추가 문장, 빠른 속도만으로 발전이나 성취를 판정하지 않는다. 학생의 화면 내 의미 체크 역시 검증된 숙련도로 취급하지 않는다.

다음 연습은 승인 요소를 유지하면서 질문 문구에 직접 해당하는 미확인 요소를 우선한다. 역할·어려움을 묻는 질문에 관련 없는 동기 요소부터 보충하라고 자동 안내하지 않는다. 명시 요청에 해당하는 요소가 모두 표현 관찰되면 같은 질문의 새 답변으로 연결하며, 모든 승인 요소가 사실·의미상 충족되었다고 판정하지 않는다.

비교에는 답변을 남긴 조건을 함께 표시한다.

- 1시간 이내의 바로 재답변, 24시간 안의 재답변, 시간이 지난 재답변을 구분한다. 이는 시간 분류이며 지연 회상 성공 기준이 아니다. 실제 복습 예정 시점을 보존한 기록만 `복습 예정 시점 이후`로 표시한다.
- 작성 내용 수정, AI 화면용 가독성 정리, 전사 정정, 실제 저장된 재녹음을 새 시도와 구분한다. AI 정리와 STT 정정은 같은 발화이므로 성장 비교의 새 연습에서 제외하며 원래 발화 기록을 유지한다. 가독성 정리로 생긴 새 문장은 학생이 실제 발화한 내용 발전으로 관찰하지 않는다.
- 입력한 답변과 실제 음성·영상으로 남긴 답변을 구분한다. Live 화면에서 텍스트로 대신 제출한 답변을 실제 음성으로 간주하지 않는다. 방식의 근거가 없으면 미확인으로 남긴다.
- 도움을 사용한 기록, 명시적으로 조회 기록이 없는 시도, 과거 도움 여부가 기록되지 않은 시도를 구분한다. 과거 미기록을 독립 수행으로 처리하지 않는다. 기록에 없는 외부 도움까지 없었다고 보증하지 않는다.
- 교재 버전이 달라지면 별도 비교 기준으로 구분한다. 당시 질문·근거·지원처를 덮어쓰지 않는다. 학교별 공통 질문의 검수 버전이 다르거나 지원처·전형이 다른 답변은 같은 비교 그룹으로 합치지 않는다.

학교·학과 이름이 제공되면 Unicode NFKC와 공백 정규화로 맥락을 비교한다. 카탈로그 ID가 없는 이전 퀴즈 스냅샷을 동일한 검수 이름의 면접 스냅샷과 연결할 수 있다. 원래 스냅샷은 수정하지 않는다. 전형·캠퍼스·연도·지원처 ID와 해당 질문의 원본 버전이 다르면 합치지 않는다. 개인 질문은 개인 교재 버전을 기준으로, 학교 공통 질문은 공통 질문 검수 버전을 기준으로 구분한다. 공통 질문의 버전이 같으면 함께 저장된 개인 교재 버전이 달라져도 같은 질문을 비교한다. `general_practice`, `book_reference`, `verified_past`, `common`은 공통 질문 네임스페이스에 해당하며 원래 유형은 기록에서 보존한다. 면접 단계의 `2단계`와 `2차 면접`은 같은 번호로 정규화한다. 단계가 없는 이전 답변은 그 밖의 맥락이 같고 해당 질문에 알려진 단계가 정확히 하나일 때만 함께 비교한다. 1단계와 2단계가 함께 있는 경우 미확인 답변이 두 단계를 연결하지 않도록 별도 그룹으로 남긴다.

같은 초안을 그대로 다시 저장한 것은 추가 연습으로 세지 않는다. 반면 실제로 새 면접·Q&A 시도를 마쳤다면 답변 문장이 이전과 같아도 별도 시점을 보존한다. 이때 내용 변화는 `같은 표현`으로 남기며, 시간이 지나 같은 답변을 남겼다는 이유만으로 독립 회상이나 실력 향상을 인정하지 않는다.

오늘 학습에는 본인 질문·지원처 ID·원본 버전이 일치하는 이전 답변도 유지한다. 과거 지원처 세부 스냅샷이 없는 경우 `지원처 세부 기준 미기록`으로 표시하고 현재 학교·학과·면접 단계의 수행 완료로 인정하지 않는다. 실제로 다른 학과·전형·원본 버전의 답변은 해당 기준의 학습에 가져오지 않는다.

뉴스는 같은 기사 ID와 본인의 브리핑 ID에 연결된 `기사에서 쓴 생각 → 해당 기사로 연습한 면접 원답변`을 별도로 비교한다. 작성과 발화의 형식 차이를 표시하고 기사 원문·내 생각 및 같은 기사 다시 말하기 링크를 유지한다. 후속 질문이나 다른 기사를 임의로 같은 답변으로 합치지 않는다.

전체 리포트의 다음 연습은 질문이 현재 발행 자료에 남아 있고 선택한 본인 지원처에 해당하면 현재 자료 버전·선택 지원처로 이어진다. 질문이 없어졌거나 지원처에 해당하지 않으면 원래 기록의 링크를 유지한다. 개별 확정 면접·학습 리포트는 당시 질문·자료 버전·지원처로 고정된다. 원래 답변이나 기록의 출처는 수정하지 않는다. 뉴스 기반 답변은 같은 브리핑과 지원처를 유지한다. 녹음이 없으면 분석 수치를 만들지 않고 녹음 연습으로 연결한다.

## API와 저장

- `GET /api/reports`는 학생 본인의 녹음 분석, 같은 질문의 내용 비교, 뉴스 생각과 발화 비교, 다음 연습을 반환한다.
- 선택 범위: `reportId`는 해당 면접 리포트의 작성 시점, `studySessionId`는 학습 종료 시점으로 기록을 제한한다. 미래 답변을 과거 리포트에 포함하지 않는다.
- `POST /api/reports {action:"analyze",recordingId,kind:"interview"|"quiz",speechTelemetry?}`는 본인 녹음만 재분석한다. 시간 자료의 범위·관찰 합계·수집 공백·기존 녹음 길이를 검증한다.
- `POST /api/reports {action:"transcribe",recordingId,kind:"quiz"}`는 저장한 퀴즈 녹음의 원전사와 별도 화면용 정리를 처리한다. 퀴즈에서 직접 입력한 답변을 원전사로 취급하지 않는다.
- 면접 업로드 및 전사 재시도와 퀴즈 전사는 공통 전사 어댑터의 현재 STT 공급사·모델과 사용량 제한을 따른다. 현행은 `STT_PROVIDER=openai`, `gpt-4o-mini-transcribe` JSON 원전사 → `gpt-6-luna` 화면용 후가공이다. 저장된 원전사는 재사용하고 정리만 재시도할 때 원음을 다시 전사하지 않는다. 이전 Google 60초 동기 전사 제한은 현행 OpenAI STT의 제한으로 적용하지 않는다. 실제 장시간 업로드와 품질은 별도 검증한다.
- `gpt-4o-mini-transcribe`에 Whisper식 단어 타임스탬프가 있다고 가정하지 않는다. 원전사 기반 습관어 보존을 요청하고 공백은 실제 RMS 관찰로 구분한다. 모델·공급자를 오류 시 조용히 교체하지 않는다. [OpenAI 공식 파일 전사 안내](https://developers.openai.com/api/docs/guides/speech-to-text)
- 새 마이크 시간 자료는 각 비공개 녹음 메타데이터에 저장한다. 원시 RMS 값은 전송·보관하지 않는다. 재분석 버전은 `speech_analysis_versions`에 원본 해시·알고리즘 버전과 함께 추가한다. 같은 입력은 중복 추가되지 않는다.
- 기존 음성, 원전사, 확정된 `interview_reports`와 `study_sessions.report`를 덮어쓰지 않는다. 새 분석은 별도 파생 기록이다. 다른 학생 ID는 404, 학생이 아닌 계정은 403으로 거부한다.

2026-10-14 사용자 결정에 따른 전사/후가공 변경의 상세 계약은 [전사·화면용 정리](transcription-pipeline.md)를 따른다. 일반 답변 영역에는 후가공 완료본을 표시하고 원전사는 명시적으로 확인할 수 있게 한다. 후가공 실패 시 원전사를 보존하고 실패·원전사 보기·정리만 재시도를 제공한다. 아래 이전 모델/측정 회귀는 새 공급자 품질·속도 검증을 대신하지 않는다.
