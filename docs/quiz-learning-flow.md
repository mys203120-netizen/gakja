# 퀴즈 학습 흐름 반영

> 현행 계약·검증 갱신: 2026-10-14. [문서 적용 순서](document-authority.md)와 [서비스 PRD v2.2](../확정안/4.%20서비스_PRD_v2.2.md)를 따른다. [개선·검증 요약](learning-remediation.md)과 [후속 QA](../.local/learning-remediation-2026-10-14/report.md)·[화면 보고서](../.local/learning-remediation-2026-10-14/report.html)에 실제 API/저장값·학교 등록·같은 질문의 학습 연결 검증을 기록했다. 아래 이전 테스트와 화면은 당시 범위로 보존한다. 실제 OAuth·Live/STT·장기 회상·88교 전 학과 콘텐츠 품질·운영 보안은 후속 인수 게이트이며, 이번 결과가 모든 기능이나 실제 학습 효과의 완료를 뜻하지 않는다.

## 2026-10-14 회상과 다음 행동

개인 경험 답변의 저장은 정답 또는 이해 완료가 아니다. 회상 상태·사실 확인 필요·도움 사용과 제출 자체를 구분한다. 도움 없는 정답 확인은 검수된 객관 개념에서만 가능하며, 과거 도움 증빙이 없는 시도는 `unknown`으로 남긴다. 새 시도에서 `assistance_recorded:true`와 도움 없음이 확인돼도 그것만으로 개인 경험의 의미 충족이나 실력 향상을 확정하지 않는다.

대학·캠퍼스·학과·학년도·전형이 같은 이전 교재에서 면접 단계가 빠진 것은 지원처 변경으로 처리하지 않는다. 회상 결과에서 같은 질문·지원처·당시 자료의 면접으로 이어지고, 실제로 다른 지원처/전형이면 당시 자료 연습과 현재 학교 준비를 구별한다.

힌트·근거·AI 응답 도움은 해당 퀴즈 세션의 현재 항목에 서버 증빙을 남겨 재접속해도 사라지지 않게 한다. 퀴즈의 도움 종류와 실제 AI 응답 완료를 구분하고, 실패한 응답을 완료된 학습으로 집계하지 않는다. 이번 격리 HTTP 검사 81개에서 도움·회상·초안·재요청·소유권을 검증했고, 브라우저에서 불확실 회상 저장 → 같은 질문 면접 진입과 실제 저장값을 확인했다. 실제 음성 수행과 이후 도움 없는 회상은 별도 게이트다.

2026-10-12의 화면별 QA를 반영했다. 기존 발행 버전, 퀴즈 질문 스냅샷과 학생 답변은 보존한다.

- 진입은 오늘 복습 / 자유 연습 / 과제로 나눈다. 오늘 복습은 6문항, 자유 연습의 기본 세트는 최대 12문항이며, 전체 적격 문항 풀에서 고른다. 특정 질문·활동·오답으로 진입하면 해당 맥락을 유지한다.
- 서버가 학생 본인의 전체 암기 시도 이력으로 현재 오답, 복습일, 미연습, 도움 사용, 최근 수행 시점을 확인한다. 현재 오답은 이후 도움 없이 검수된 정답을 확인했을 때 해소하며, 미채점 저장·자가평가 `good`만으로 해소하지 않는다. 같은 우선순위에서는 덜 최근에 연습한 문항이 먼저다.
- 같은 방식·시간 조건·발행 버전·선정 항목의 미시작 세션은 트랜잭션과 학생별 advisory lock으로 재사용한다. 준비 기록에는 질문·날짜·진행 상태를 표시하고, 반복되는 미시작 기록은 기본 화면에서 접는다. 모두 보기와 여기까지 저장으로 사용자가 정리할 수 있다. 기록 삭제는 하지 않는다.
- 선택형의 기본 10초와 서버 마감 시각 검증은 유지한다. 별도의 시간 제한 없는 선택형 연습을 제공하며, 이 경우 서버 마감 시각과 시간 초과 결과를 만들지 않는다.
- 힌트는 허용된 첫 문장만 응답한다. 나머지는 실제 답안이 아닌 흐린 자리 표시이므로 DOM/API에서 전체 모범답안을 복원할 수 없다. 흐린 영역은 두 줄로 제한한다. 힌트 사용은 서버에 저장하며, 클라이언트가 `hintUsed:false`를 보내거나 다시 접속해도 기록을 지울 수 없다.
- 근거·영상 조회는 같은 학생의 현재 문항에 `assist` 증빙을 먼저 남긴다. AI 도움은 첫 유효 응답 노출 전 서버가 receipt를 남기고 부분/완료/중단을 구분한다. 답변·암기 시도·학습 이벤트에는 실제 도움 종류와 원본 버전을 보존한다. 출력 없는 AI 실패를 도움 사용으로 기록하지 않는다.
- 종료 화면에는 실제 제출 답변, 선택형의 검수된 정답, 저장 당시 근거 발췌가 표시된다. 미채점 Q&A는 답변 저장으로 표시한다. 주 행동은 같은 질문을 면접에서 말하기이며, 관련 영상·내 말로 설명·오답 재확인이 이어진다.
- 검수된 선택형 문항은 같은 개념을 Q&A나 녹음으로 설명할 수 있다. 원래 개념 질문에서 설명형 문장을 만들며 다른 개인 활동 질문으로 바꾸지 않는다. 이 설명은 정오를 추측하지 않고 미채점 연습으로 보존한다.
- 새 자료에 없는 항목으로 들어오면 학생 본인의 저장 당시 질문을 보여준다. 같은 ID 또는 같은 종류·질문 ID/질문 문장으로 확인되는 최신 항목만 연결한다. 동등 항목이 없으면 사유와 원본 기록을 제공한다. 옛 질문을 읽는 일과 최신 문항으로 재훈련하는 일을 구별한다.
- 합성 테스터의 첫 문장 힌트를 기록된 본인 역할로 고쳤다. 기록되지 않은 어려움을 만들어 넣지 않았다. `scripts/upgrade-demo-hints.mts`는 알려진 두 합성 계정·기존 문장을 확인한 뒤 새 발행 버전만 추가한다.

API 계약: `GET /api/quiz`는 기존 `library`, `sessions`에 `recommendation`(`count`, 공개 `items`, `wrong`, `due`, `unseen`, `reason`, `href`)과 요청 맥락에 대한 `requested`를 추가한다. `POST create`는 `focus:today|free`, `timed:boolean`을 지원한다. 기본값은 오늘 복습·선택형 10초다. `assist`는 현재 문항에 도움 사용 사실을 기록하며 AI를 자동 호출하지 않는다.

## 2026-10-14 녹음 전사 개정

Q&A 녹음의 표시 문장은 `gpt-4o-mini-transcribe` 원전사를 보존하고 `gpt-6-luna`의 문장부호·띄어쓰기·줄바꿈 후가공까지 마친 뒤 보여준다. 처리 중 전사/문장 정리 상태를 표시하며 완료본과 원전사를 구분한다. 내용·사실·경험을 보충하지 않으며 후가공은 모범답안 도움이나 새 학습 시도가 아니다.

원전사·AI 화면용 정리·학생 직접 정정·새 녹음을 분리한다. 발화 습관어·반복·속도는 원전사, 쉼은 실제 RMS 관찰을 사용한다. 후가공 실패 시 원음을 보존하고 원전사 확인/정리만 재시도를 제공한다. 다른 문항이나 새 녹음으로 바뀐 뒤 늦게 끝난 처리 결과는 현재 답변을 덮어쓰지 않는다. 저장된 원전사의 후가공만 재시도할 때 STT를 중복 호출하지 않는다. 상세 계약과 전환 검증 상태는 [전사·화면용 정리](transcription-pipeline.md)를 따른다.

## 이전 기능 검증 이력

검증: 순수 규칙·선정 테스트 13개와 로컬 합성 계정 API 검증 48개, 웹 TypeScript 검사 통과. API 검증에는 전체 16문항의 뒤쪽 오답 선정, 동시 준비 세션 재사용, 기존 10초 마감·재요청·접근 권한·비공개 녹음, 시간 제한 없는 연습, 서버의 힌트·도움 기록, 삭제된 문항의 원본 보기, 같은 개념의 미채점 설명이 포함된다. 테스트 계정과 해당 계정의 합성 데이터만 정리했으며 실제 학생 데이터는 변경하지 않았다. 외부 AI 호출은 0회다.
