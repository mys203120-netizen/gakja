# 공개 안내·문의·검색·분석 적용

2026-10-22 첨부 검토안 17항목을 기존 로그인/소개 화면에 반영했다. 사용하지 않는 `landing.tsx`를 새 홈으로 전환하지 않았다. 운영 값·외부 GA 실계정·배포 검증과 코드 구현을 구분한다.

## 운영에서 확정할 설정

비밀 값은 `.env.local` 또는 배포 환경에만 설정한다. `.env.example`은 빈 예시다. 기존 키와 데이터는 바꾸지 않는다.

| 변수 | 실제로 확인할 값 |
| --- | --- |
| `APP_URL` / `NEXT_PUBLIC_APP_URL` | 등록된 운영 HTTPS 도메인. 임의 도메인·localhost를 사이트맵에 넣지 않음 |
| `SITE_ORGANIZATION_NAME` | 실제 운영 주체명. 회사명 추정 금지 |
| `SUPPORT_EMAIL` | 운영자가 실제 확인하고 회신할 이메일 |
| `SUPPORT_RESPONSE_TIME` | 약속 가능한 응답 시간. 임의로 24시간 등의 수치를 확정하지 않음 |
| `SUPPORT_RETENTION_NOTICE` | 문의 보관기간과 종료/삭제 기준 |
| `PRIVACY_OFFICER`, `PRIVACY_CONTACT_EMAIL` | 실제 개인정보 담당자와 연락처. 연락처 미설정 시 SUPPORT_EMAIL 사용 |
| `PRIVACY_RETENTION_NOTICE` | 계정·학생부·답변·대화·미디어·로그·백업의 실제 보관/파기 기준 |
| `PRIVACY_PROCESSORS_NOTICE` | 실제 저장소·인증·AI·음성 처리 수탁자/업무/계약 |
| `PRIVACY_TRANSFERS_NOTICE` | 국외이전 수령인·국가·시점·방법·항목·목적·보유기간·적용 근거·거부 방법. 실제 계약과 배포 지역 기준 |

현재 소스만으로 알 수 없는 운영 사실은 발명하지 않는다. 개인정보 페이지는 이 값이 확정되기 전에는 **확인 중인 안내**로 표시하고 noindex로 둔다. 운영 빌드의 문의 폼은 운영 주체·이메일·응답 시간·문의 보관 안내를 설정한 후 접수를 받는다. 로컬 개발에서는 시험 운영 안내와 함께 기능을 검증할 수 있다. 개인정보 처리방침의 명확성·구체성은 [개인정보보호위원회 작성지침 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS074&mCode=C020010000&nttId=11133)를 참고했으며, 운영 사실과 계약 검토를 대체하지 않는다.

## 문의 처리

`202610220001_support_inquiries.sql`을 앱 배포 전에 적용한다. 공개 POST만 로그인 없이 허용하고 목록·처리 변경은 관리자만 허용한다. 학생과 배정 담당자는 문의 전체를 읽을 수 없다. 테이블은 RLS를 활성화하고 anon/authenticated 직접 권한을 부여하지 않는다.

내용은 5,000자, 실제 요청 본문은 24,000바이트로 제한한다. 현재 버전 수집 동의·이메일·유형을 검증하며 이메일별 1시간 3건/1일 10건 및 전체 1시간 100건/1일 500건의 안전 한도와 중복 요청 방지를 DB 트랜잭션으로 처리한다. 전체 한도는 다른 이메일을 계속 입력하는 익명 요청에도 적용한다. 접수번호만으로 문의를 조회하는 공개 API는 제공하지 않는다.

관리자는 `/admin/inquiries`에서 접수·확인 중·처리 완료 상태와 내부 메모를 저장한다. 저장은 답변 메일 발송을 뜻하지 않는다. 실제 이메일 회신과 개인정보 요청의 본인/대상 확인·처리·결과 통지는 운영자가 수행한다. 자동 탈퇴·전체 자료 삭제나 문의 자동 파기를 구현한 것으로 안내하지 않는다. 보관기간 확정 시 해당 기간에 맞는 운영 삭제 작업도 함께 준비한다.

## 분석 설정

`NEXT_PUBLIC_GA_MEASUREMENT_ID`와 `NEXT_PUBLIC_GA_MANUAL_MEASUREMENT_CONFIRMED=true`를 설정하고 새로 빌드한다. 확인 플래그를 켜기 전에 GA4 관리 화면에서 **향상된 측정 전체**(특히 히스토리 페이지뷰·폼·다운로드)를 비활성화한다. `send_page_view:false`만으로 히스토리 자동 수집이 꺼지지 않는다. [Google 수동 페이지뷰 안내](https://developers.google.com/analytics/devguides/collection/ga4/views).

`/privacy`에서 브라우저별 통계 수집에 명시적으로 동의해야 태그가 로드된다. 인증 콜백·로그인·가입·비밀번호 복구와 API는 제외하고 식별자·쿼리·해시·실제 제목·외부 referrer를 전송하지 않는다. `cta_start_click`만 클릭으로 기록하고 가입·첫 답변·면접 완료는 DB에 저장된 서버 확인 영수증만 사용한다. 기존 답변은 첫 답변 전환으로 소급 집계하지 않는다. 테스트 계정도 집계에서 제외한다.

`202610220002_analytics_conversions.sql`도 앱보다 먼저 적용한다. 실제 GA 전송·광고 차단·네트워크 실패 환경에서는 통계 누락이 생길 수 있으며 서비스 저장 결과가 통계 전달에 의존하지 않는다.

서버의 전환 확인 이력은 계정별 중복 집계 방지에 사용하고 계정 삭제 시 함께 삭제한다. 브라우저의 현재 선택 동의 이후 발생한 최근 24시간의 이력만 전달한다. Google 스크립트가 준비되기 전에는 이력을 소비하지 않는다. 여러 탭에서는 원자적으로 한 번만 꺼내므로 전송 직후 통신이 끊기면 누락될 수 있다.
