# 각자ON UI 구현 프롬프트

적용일: 2026-10-16. 클라썸 LMS 참고 프롬프트를 각자ON의 기존 제품과 사용자 결정에 맞춘 시각 구현 지침이다. 제품 범위·학교 정보·평가 기준·발행 계약은 `document-authority.md`의 현행 정본을 따른다.

## 역할과 제품 맥락

너는 각자의답의 입시 면접 학습 서비스 **각자ON**을 개선하는 Senior Frontend Engineer이자 UI/UX Designer다. 학생이 자신의 활동과 지원 학교·학과·전형을 바탕으로 질문의 근거를 읽고, 기억을 꺼내 답하고, 실제 발화와 답변의 변화를 비교하고, 다음 복습으로 이어지도록 구현한다.

기존 앱의 기능과 데이터 계약을 보존하며, 밝고 담백한 학습 공간으로 다듬어라. 숫자나 기능을 많이 노출하는 운영 대시보드보다 지금 답할 질문과 다음 행동이 먼저 보여야 한다. 학생에게 보이는 문장은 짧고 구체적으로 쓴다.

## 실제 기술 스택

- Next.js App Router + React + TypeScript.
- 기존 CSS Modules와 `brand-clarity.css`, `clarity-chrome.css`, `clarity-practice.css`, `clarity-reading.css`를 사용한다. 새로운 전역 스타일 덮어쓰기를 누적하지 않는다.
- Lucide React 아웃라인 아이콘, Pretendard를 사용한다.
- 이 시각 개선에 Tailwind 마이그레이션이나 컴포넌트 라이브러리 교체를 섞지 않는다.
- PostgreSQL, API, 지원처·발행본 식별자, 학습 기록·음성·리포트의 연결 방식을 유지한다.

## IA와 화면 골격

1. 주요 메뉴는 **오늘 / 연습 / 자료 / 내 리포트** 네 개를 유지한다.
2. PC는 72px 레일을 유지하고 아이콘 아래에 오늘·연습·자료·내 리포트 이름을 항상 표시한다. 데스크톱 헤더의 AI 비서도 이름을 함께 표시한다. 상시 펼친 서브 사이드바는 추가하지 않는다.
3. 헤더에는 현재 작업 영역과 지원처 선택, 기존 AI 비서·검색·알림·계정 기능을 정렬한다. 구현되지 않은 북마크 버튼을 장식으로 추가하지 않는다.
4. 연습·자료의 하위 페이지는 같은 밑줄 탭 문법을 사용한다. 교재 내부의 활동·질문·초안·책 탐색은 한 단계 들여써서 구분한다.
5. 실제 독서·대화 화면의 목록과 본문은 기존 master-detail 구조를 활용한다. 집중 답변 화면에서는 지역 탐색 탭을 숨기는 기존 규칙을 유지한다.
6. 모바일은 네 개 하단 메뉴와 가로로 탐색 가능한 지역 탭을 사용한다. 입력창·하단 CTA와 메뉴가 겹치지 않게 safe area를 확보한다.

## 화면별 적용

- **오늘:** 현재 질문과 하나의 주요 CTA, 오늘 할 일, 같은 질문의 이전 답을 먼저 배치한다. PC의 충분한 너비에서는 일정과 이어 볼 자료를 나란히, 좁은 화면에서는 세로로 보여준다. 캘린더는 등록한 모든 학교의 이름·일정·학교별 색상과 응시 시간 미정 상태를 유지한다.
- **연습:** 퀴즈와 모의면접을 명확히 구분하고 작은 민트 아이콘으로 시작점을 보여준다. 과제·복습·AI 도움은 보조 행동으로 정렬한다.
- **퀴즈:** 질문과 선지·답변을 넓고 읽기 쉽게 배치한다. 10초 타이머와 남은 시간 경고, 정답·오답 상태를 유지한다. 결과의 다음 행동은 면접·답변 비교·복습으로 연결한다.
- **자료:** 추천·저장과 검색·필터는 동일한 컨트롤 문법을 사용한다. 지식한입은 목록을 바로 이어 보여주며, 행과 기사 중심으로 구성하고 썸네일은 16:9를 유지한다.
- **내 리포트:** 발화의 쉼·습관어·반복·답변 내용의 변화와 근거가 우선이다. 학습 완료 개수로 성장을 대신하거나 데이터가 없는 차트를 그리지 않는다. 빈 상태에는 실제 가능한 다음 행동을 둔다.
- **학교 등록·관리:** 학교→학과·전형→2027학년도(2026년) 일정 확인의 흐름과 추가·수정·삭제 기능을 유지한다. 미정·면접 없음·시간 미발표를 서로 다른 상태로 표현한다.
- **로그인:** 중앙 정렬과 1초 간격으로 시계 방향 90도씩 회전하고 멈추는 기존 로고 모션을 유지한다. 학교와 학습이 분리된 새로운 시작 페이지를 만들지 않는다.

## 컴포넌트와 읽기 리듬

- 제목은 과도하게 굵게 만들지 않는다. 제목 450~500, 본문 400을 중심으로 정렬·간격·색·들여쓰기로 묶음을 구분한다.
- 긴 질문과 답변은 자연스럽게 줄바꿈하고 본문은 15~16px 이상, 행간은 1.7~1.85를 기본으로 한다. 표와 미디어는 필요한 너비를 사용한다.
- 버튼·입력은 8px, 현재 질문·다음 복습 같은 필요한 컨테이너는 12px 정도의 모서리를 사용한다. 모든 정보를 둥근 사각형으로 감싸지 않는다.
- 글래스·큰 그림자·반복 구획선을 추가하지 않는다. 팝오버와 모달의 경계와 약한 그림자만 유지한다.
- 주요 행동은 한 묶음에 하나, 취소·수정·가져오기 같은 보조 행동은 중립색 또는 텍스트 링크로 표현한다.
- 기존 `ActionButton`의 스피너·처리 문구·비활성·중복 전송 방지를 유지한다. 단순 아이콘으로 버튼 이름을 대신하지 않는다.
- hover는 빠르고 작게, 키보드 포커스는 명확하게, `prefers-reduced-motion`에서는 모션을 줄인다.

## 완료 조건

기존 데이터·라우트·학교 맥락·답변 복구·음성 처리·Markdown을 보존한다. 변경한 주요 화면의 PC·모바일, 메뉴 이동과 직접 접속을 확인하고 새 스크린샷으로 비교한다. 스타일 때문에 기능이나 실제 데이터가 사라지지 않았는지 관련 회귀 테스트와 빌드를 통과시킨다. 테스트 데이터는 원본 학생 계정과 격리한다.

## 참고 범위

| 실제 화면에서 확인한 원칙 | 각자ON 적용 |
|---|---|
| 좁은 전역 아이콘 레일과 옅은 회색 탐색 영역 | 네 개 주요 메뉴의 72px 레일과 민트 현재 위치 |
| 작업 영역 이름과 선택한 공간이 보이는 헤더 | 현재 영역과 지원 학교·학과 선택의 정렬 |
| 지역 목록과 흰 본문의 분리 | 섹션별 밑줄 탭, 교재·대화의 기존 목록/본문 구성 |
| 열린 콘텐츠 행, 작은 상태 배지와 보조 메타데이터 | 자료·리포트의 열린 행, 출처·날짜·학습 상태의 일관된 표시 |

각자ON의 레일·섹션 탐색·본문은 입시 면접의 학습 흐름에 맞춘다. 참고 서비스의 수업·주차·구성원·개인 게시물은 이 앱의 콘텐츠나 데이터로 사용하지 않는다. 실화면 증거는 이번 실행의 로컬 QA 폴더에 보관한다.
