## 화면 흐름 확인

1. 홈의 두 시작점 → 오늘 훈련 / 마이 대시보드.
2. 대시보드의 실제 계획 완료율, 7일 완료 면접 집계, 일정, 준비 분포.
3. 하루 한 영역 → 원문 복습 → 10초 퀴즈 → 다음 훈련. 실제 가상 계정으로 복습·퀴즈 저장 후 완료율 2/4 반영.
4. 네 보기·타이머·시간 초과 자동 제출 → 요약 결과, 기본 접힌 문항별 상세.
5. 학과 등록된 새 가상 계정 → PDF 선택 → 고정 안내 → 실제 문서 인식 → 원본 고정. 교체 입력이 없어지고 원문·원본 다운로드와 미설정 분석 상태를 표시하는 것을 확인.
6. 실제 훈련 API → 5명 무대와 녹음 동의 전 준비 화면. 동의나 장치 권한을 부여하지 않았다.
7. 가상 발화 상태 → 답변 주변 원전사, 기본 접힌 카메라 → 이름 버튼으로 도움 캐릭터 → 원래 면접관 복귀.
8. 가상 실전 상태에서 도움·글 제출·재답변 제어가 노출되지 않는 것 확인. 종료 후 질문별 복기·원답변·평가 요약·정확한 질문 링크 확인.
9. 날짜 캘린더 → 완료한 훈련 → 질문 답변·평가·피드백. 선택 날짜 리포트 HTML을 브라우저에서 다운로드하고 파일 생성 확인.
