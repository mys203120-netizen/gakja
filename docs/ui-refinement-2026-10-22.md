# 2026-10-22 UI 후속 정리

- 앱 및 읽기 쉬운 내보내기의 폰트 크기를 13 / 15 / 18 / 24px 네 가지로 고정했다.
- 탭 위·아래 여백과 페이지 제목 여백을 줄였다. 오늘 훈련, 준비 현황, 자유 연습의 반복 설명을 제거했다.
- 모바일 학교 선택 메뉴를 헤더 안의 상대 위치 대신 화면 양쪽 16px에 고정했다. 뒤로가기 유무와 긴 학교·학과 이름에 관계없이 메뉴가 화면 안에 머문다.
- 작성 중인 경험은 모바일에서 전체 폭 세로 목록으로 표시한다. 경험 유형 버튼은 단색 표면을 사용한다.
- 데스크톱 AI 비서는 대화·입력 영역의 820px 제한과 큰 가운데 여백을 없애고, 시작 질문을 두 열로 배치했다. 동일 지원처 문구와 시작 안내를 중복 표시하지 않는다.
- 리포트 아이콘의 가운데 정렬을 명시했다. 녹음 한 개에는 선택기를 생략하고, 여러 개에는 같은 질문 제목을 반복하지 않는다. 비교 자료가 없는 빈 비교 영역을 제거했다.
- 모달 배경을 중립 회색으로 변경했다. 모바일 종료창의 주 동작은 두 열 전체 폭을 차지한다.
- 훈련 안에서는 제목을 한 번 표시하고, 답변 상태와 AI 도움을 같은 줄에 배치한다. 보조 답변 도구는 펼쳐서 사용할 수 있다. 질문 펼침 아래에 간격을 추가했다.

## 면접 종료·음성

`저장하지 않고 종료`는 미제출 초안과 현재 기기 녹음만 버린다. 제출된 답변과 원본 미디어는 유지한다. 서버의 세션 잠금 안에서 미제출 초안을 지우고 종료한다. 다른 계정·다른 녹음 시도에는 영향을 주지 않는다.

이미 시작한 녹음 업로드가 늦게 응답하거나 종료 요청이 실패해도, 버린 미디어를 재개 시 자동으로 전사·제출하지 않는다. 이 경쟁 상태를 재현한 회귀 검사를 추가했다.

재생 중 화자를 지정할 때 말하기 신호가 덮어써지는 경로와, 중단된 오디오 분석 컨텍스트가 재개되지 않는 경로를 보완했다. 실제 출력 음량에 따라 입 모양을 움직이고 다른 면접관을 어둡게 표시한다. 무음·정지·학생 답변 시 밝기를 되돌린다.

## 검증

- 전체 단위·컴포넌트 검사 1,116개 및 bootstrap 검사 31개 통과.
- 최종 `npm run build` 및 `git diff --check` 통과.
- 마지막 표시 문구 정리 후 `tests/training-hub-render.mjs` 재검증 통과.
- 320×740, 375×812 모바일 및 1440×900 데스크톱에서 화면 확인.
- 학교 메뉴의 320px 화면 경계는 왼쪽 16px, 오른쪽 304px이며 수평 넘침이 없다.
- 리포트 아이콘과 상자 중심의 오차는 가로·세로 모두 0px이다.
- 모바일 대화 메뉴가 나타날 때 입력 영역 하단 724px, 메뉴 상단 744px로 겹치지 않는다.
- 로컬 합성 음성으로 파일·스트림 재생, 재생 중 화자 변경, 정지를 확인했다. 마이크 및 외부 음성 생성 서비스는 사용하지 않았다.

이번 실행의 화면 및 로그는 로컬 `.local/ui-refinement-2026-10-22/`에 저장했다. 기존 계정의 제출 답변 삭제나 녹음·답변 제출은 QA에서 실행하지 않았다.
