# 문서에서 언급하지만 현재 프로젝트에 없는 연결 정보

확인 대상은 루트의 질문 생성 가이드라인 v2.1, 답변 분석·평가·코칭 가이드라인 v2.1, 구현 프롬프트, 윤지우 학생부 PDF와 `universities.json`·`departments.json`·`admission_tracks.json`이다. 현재 실행 자료는 이 세 루트 JSON을 직접 읽어 연결하며 이전 `data/references/university-interviews-talents-2027.json` snapshot을 참조하지 않는다. 이번 구현은 `/interview` 한 화면의 로컬 테스트다. 아래의 제품 전체 연결을 이번 화면의 선행 조건으로 추가하지 않는다.

런타임은 `universities.json`의 대학 ID, `departments.json`의 대학·학과 ID, `admission_tracks.json`의 대학·학과·전형 ID를 연결하고 학년도·전형명·본교 여부를 대조한다. 선택한 전형의 공식 시간·위원 수·평가요소를 준비 화면과 질문 생성 문맥에 전달하며, 새 면접의 진행 시간은 해당 근거에서 정한 **720초(12분)**다. 아래의 ‘현재 자료’와 미연결 항목은 모두 이 연결 상태를 기준으로 한다. 과거 스냅샷은 보관 이력일 뿐 현재 런타임의 필수 입력이나 대체 자료가 아니다. 세 루트 JSON 원본은 수정하지 않았다.

CLOVA 콘솔에 장문·단문·스트리밍 생성 메뉴가 모두 보이면, 이번 앱은 **스트리밍 인식 도메인**을 선택한다. 언어는 한국어(`ko`), 플랜 선택이 있으면 Basic, 선택 기능인 Papago 번역은 사용하지 않는다. 현재 생성 화면에서 Storage ‘미사용’을 선택할 수 있으면 이 로컬 앱도 미사용으로 연결할 수 있다. 앱은 gRPC 응답을 직접 받아 로컬 `data/`에 저장하며 Object Storage에 의존하지 않는다. Storage를 별도로 사용하려는 경우에는 도메인의 결과 저장 경로를 콘솔에서 설정한다. 앱에 Object Storage 키를 추가할 필요는 없다. 일반 가이드의 버킷·경로 설명은 Storage를 사용하는 경우와 구분해 읽는다. 공식 릴리스 노트는 2023년 장문 도메인 내 스트리밍과 2025년 Streaming 2.0 출시를 구분한다. gRPC 페이지에 남아 있는 ‘Basic 장문 인식’ 표현만으로 현재 신규 생성 유형을 장문으로 안내하지 않는다. 현재 스트리밍 빌더가 동일한 gRPC API와 `semanticEpd`를 연결하는 점까지 대조하여 위 선택을 정했다. provider의 호스트·인증·PCM·Config 계약에는 변경이 필요하지 않았다. [공식 릴리스 노트](https://guide.ncloud-docs.com/docs/en/clovaspeech-releasenote), [gRPC API](https://api.ncloud-docs.com/docs/ai-application-service-clovaspeech-grpc)

## 확정되지 않은 정책과 연결

**문항별 점수 산식은 이미 있다.** 답변 문서 제12~18조는 I/A/S/R/C 앵커 0~4, 기능별 가중치, 반올림, 39·59점 상한, 평가 불가 `null`을 규정한다. 시선·표정·말속도와 활동 우선도를 내용 점수에 합산하지 않는다.

반면 답변 문서 제33조④는 **회차별 집계 점수 산식, 문항 가중치, 최소 유효 문항 수, 누적 회차 통계**를 미정으로 남긴다. 향후 승인된 리포트 기준·제품 정책이 필요하다. 임의의 합격확률이나 공식 종합점수를 만들지 않는다.

학생부·음성·영상·면접 기록의 보존기간, 삭제 정책, 접근통제와 운영 동의 문구는 별도 정책 연결 대상이다(질문 제24·26조, 답변 제26조). 이번 로컬 테스트의 자료 준비·구현을 멈추기 위한 별도 확인 절차를 만들지는 않는다. 상용 운영 전 해당 정책을 정하고 저장 어댑터에 반영해야 한다.

## 현재 연결된 로컬 자료

학생부 PDF는 24쪽이며 텍스트 추출이 가능하다. `npm run prepare:context`는 확인한 원문 구간을 비공개 `data/prepared/student.json`에 준비하고, PDF SHA-256·페이지·추출 오프셋을 함께 저장한다. 면접마다 다시 PDF를 읽거나 다른 학생 자료를 섞지 않는다. `data/prepared/source-manifest.json`은 실제로 읽은 루트 JSON 3종과 학생부·MD의 파일 해시, 대학·학과·전형 ID, 학년도, 면접 개요·720초, 선택 규칙을 기록한다.

현재 면접에는 질문·평가 가이드라인의 실제 규칙, 루트 JSON 3종에서 정확히 선택한 대학·학과·전형 레코드, 해당 학생의 원문 근거를 연결했다. 제공 자료와 직접 대조한 공식 근거에 없는 학교 평가정보·학생 활동·S/A 우선도는 생성하지 않는다. 학생부 업로드·OCR 접수·분석 등록·개인별 가이드북·제품 전체의 답변 보관함은 이 연결 작업으로 구현된 기능이 아니며, 위의 미연결 항목과 범위를 그대로 유지한다.
