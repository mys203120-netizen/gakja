# 면접 훈련·UI 안정화 검증

2026-10-20 로컬 앱과 PostgreSQL에서 확인했습니다. 유료 AI 통합 검증은 별도 합성 학생을 사용하고 소유 데이터를 정리했습니다.

## 확인한 흐름

1. **마이크 캡처 — 통과.** 브라우저에서 카메라를 끄고 저장 동의 후 실제 마이크를 연결했습니다. 약 47초 WebM 녹음 381,235바이트가 서버에 저장됐습니다. 발화가 없는 녹음은 전사 실패로 남고 답변 수는 0을 유지했습니다. 오류 상태에서 탭을 이동한 뒤에도 원음을 보관하고 종료할 수 있는 것을 새 페이지에서 확인했습니다.
2. **실제 AI 처리 — 통과.** Windows 한국어 Heami 음성으로 생성한 25.5초 WAV를 실제 업로드 경로에 전달했습니다. 실제 전사 161자, 문장 정리, 음성 답변 피드백, 꼬리질문과 최종 리포트가 생성됐습니다. 이 발화 검증은 물리 마이크를 통한 사람의 발화 품질 검증과 구분합니다.
3. **같은 활동 누적 — 통과.** 같은 경험의 글 1회와 음성 1회가 총 2개 시도로 합쳐졌습니다. 이전 글·원음·원전사는 유지되고 같은 제출 요청 재시도는 시도를 늘리지 않았습니다.
4. **다음 날 재계획 — 통과.** 생산 플래너에 다음 한국 날짜를 전달해 120분 예산 안에서 회상 20분, 집중 65분, 연결 면접 15분, 정리 10분, 휴식 10분을 확인했습니다. 실제 답변 기록과 학생이 직접 선택한 보완점을 사용하며, AI 피드백을 임의의 능력 점수로 변환하지 않습니다. 열린 화면의 한국 자정 갱신도 타이머·브라우저 검증을 추가했습니다.
5. **모바일 화면 — 통과.** 검색·알림을 열고 닫아도 본문·헤더 폭 349px와 하단 메뉴 위치/크기가 유지됐습니다. 헤더 64px, 하단 메뉴 204×56px이며 메뉴는 접근성 이름을 유지한 아이콘 전용입니다. 캘린더의 긴 질문은 모바일 날짜 셀의 점·개수와 선택일 상세로 나누었습니다.
6. **하린 계정 — 초기화 완료.** 로그인·프로필·가입일은 유지하고 지원 학교, 교재, 경험, 답변과 훈련 기록을 백업 후 비웠습니다. 기존 인증 상태로 학교 선택 첫 화면 진입을 확인했습니다. 백업은 Git에서 제외된 `.local/harin-reset/`에 있습니다.

## 수정한 오류

- Live 면접 재개 요청이 이미 활성인 녹음의 세대를 변경하여 정상 녹음을 거절하던 문제.
- 전사 실패 녹음을 다시 제출하도록 강요해 종료가 막히던 문제. 원음 보관 종료는 실패 녹음을 답변으로 계산하지 않습니다.
- 자동 훈련을 기존 계획 API에서 수동 완료·날짜 변경할 수 있던 우회.
- 브라우저 타이머 수신 객체를 잃어 자정 갱신에서 발생하던 `Illegal invocation`.
- 검색·알림의 스크롤바 제거에 따른 화면 폭·하단 메뉴 이동.
- 첫 로딩에서 실제 지원 정보를 받기 전 미등록이라고 표시하던 상태.

## UI 변경

중성 배경, 흰 카드와 로고의 밝은 초록을 기준으로 색을 정리했습니다. 어두운 초록 버튼·민트 그라데이션·녹색 그림자를 제거하고, 학교 선택 팝오버·작은 메뉴 토글·중복 구분선·툴팁 호버·여백을 보정했습니다. 내 기록 내보내기는 탭 옆 아이콘으로 배치했습니다. 시간 설정은 현재가 수능 전이면 수능 전 시간을 먼저 보여주며 수능 후 시간을 선택적으로 나눕니다.

## 재현과 증거

- `npm test`: 748개 테스트와 bootstrap 검사 통과.
- `npm run build --workspace=@gakja/web`: 최종 빌드·타입 검사 통과.
- 실제 AI 종단 검사: `tests/voice-training-e2e.mts`, 24개 확인. 명시적 `RUN_PAID_VOICE_TRAINING_E2E=1`과 `VOICE_TRAINING_AUDIO`가 있어야 외부 AI를 호출합니다.
- 화면·달력·시간 설정·자료 렌더 검사도 별도 통과했습니다.
- 실행 결과: `.local/voice-training-e2e-result.json`, `.local/physical-mic-check.json`.
- 실제 캡처: `.local/ui-polish/01-before-mobile.png`부터 `05-reset-onboarding.png`까지.

기기·브라우저별 마이크와 입력 음량, 다양한 학생 발화의 인식 품질 전체를 보장하는 검증은 아닙니다. 이번 결과는 실제 마이크 저장/무음 처리와 선택한 한국어 발화의 실제 AI 연결을 확인한 범위입니다.
