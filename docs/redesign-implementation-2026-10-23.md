## 함께 연결한 기능

- 하루 한 생기부 영역: 복습 → 10초 퀴즈 → 화상 답변 → 오늘 정리. 학교 마감·활동 분량·중요도·운영 규칙 버전을 계획에 저장한다.
- 답변 연습 → 실전 면접 → 종합 리포트 → 최종 보완 단계. 완료된 실전과 실제 리포트가 있는 보완 질문을 우선 편성한다. 시작·완료·수동 이동한 일정은 보존한다.
- 학생이 훈련 순서, 반복 간격과 중지를 조절한다. AI 보완 평가는 원발화에 있는 인용을 확인해야 반복 근거가 된다.
- 실전은 화상 입력·종료 후 피드백을 적용하고 도움·재시도·글 제출을 서버에서도 차단한다. 연습 압박은 운영 규칙, 실전 일반/압박은 학생 선택을 적용한다.
- 5초 침묵 자동 제출을 제거하고 답변 완료 버튼으로 제출한다. 질문/힌트 재생 중 입력을 차단한다.
- 질문별 4항목 평가·정확 인용·피드백·인용 기반 구성 예시. 판단 근거가 부족하면 점수를 보류한다. 종료 화면에서 질문별 복기와 해당 리포트로 연결한다.
- 날짜 → 훈련 → 질문 → 답변·피드백·영상. 완료한 날짜에만 캐릭터 도장을 표시하며 선택 날짜/훈련을 인쇄 가능한 HTML로 다운로드한다.
- 분석·질문·평가·피드백·커리큘럼 지침의 초안 → 검토 → 게시와 버전 이력.
- 비언어 관찰은 종료된 본인 영상의 최대 6개 정지 화면과 원본 시점 연결로 구현했다. 연속 영상의 시선·동작 횟수 분석이나 감정·태도 평가는 제공하지 않는다.

## 설정과 실제 검증 범위

| 기능 | 필요한 설정 / 현재 상태 |
| --- | --- |
| CLOVA 음성 | `CLOVA_TTS_ENABLED=true`, `CLOVA_TTS_CLIENT_ID`, `CLOVA_TTS_CLIENT_SECRET`. 현재 예시와 미리보기는 꺼짐. 실제 한국어 5음성 청취·지연·요금은 미측정. |
| 생기부 자동 분석 | `STUDENT_DOCUMENT_ANALYSIS_ENABLED=true`, 서버 `OPENAI_API_KEY`, 접근 가능한 모델. 미설정 상태에서도 원본 고정·다운로드·원문 확인이 가능하다. |
| 영상 표본 관찰 | `NONVERBAL_ANALYSIS_ENABLED=true`와 이미지 입력·구조화 출력 지원 모델. 실제 모델 품질과 브라우저별 영상 프레임 추출은 추가 실측 대상. |
| 실시간 자막·이름 호출 | `INTERVIEW_LIVE_TRANSCRIPTION_ENABLED=true`와 기존 전사 설정. 기본 꺼짐이며 GPT Live 1 음성 대화와 별개다. |
| 원전사 표시 정리 | `TRANSCRIPT_CLEANUP_ENABLED=false`가 기본. 켜더라도 단어 보존 검증을 통과해야 한다. |

검수 중 실제 유료 AI 호출·마이크·카메라 권한 부여를 하지 않았다. 실제 서버에서 퀴즈 타이머/결과, 생기부 PDF 인식·고정, 훈련 세션 준비, 날짜별 기록, 리포트 다운로드를 확인했다. 면접 발화·도움·실전·종료 상태는 실제 컴포넌트/CSS에 가상 컨트롤러를 연결해 확인했다.

## 1차 구현 당시 남은 네 범위 — 이전 이력

아래는 **1차 구현 시점**의 23개 반영·4개 부분 반영 기록이며 현재 미완료 목록이 아니다. 네 항목의 후속 승인 범위와 완료 결과는 [후속 구현·QA 기록](followup-implementation-qa-2026-10-23.md)에 정리했다. 특히 C02는 눈의 시선이 아닌 얼굴 방향과 관측 가능한 움직임으로 범위를 명확히 했다. 당시 기록은 다음과 같다.

1. 스캔 PDF OCR: 현재 문자 선택 가능한 PDF만 지원하며 읽을 수 없는 페이지는 고정 전에 거절한다.
2. 면접 전 같은 영역 날짜가 없을 때 영역 배치를 바꾸는 제안: 반복 간격·중지와 용량 경고·수동 이동은 구현됐다.
3. 연속 영상의 시선 이탈 구간·반복 동작 횟수: 현재 최대 6개 표본 관찰이다.
4. 완성된 모범답안 생성: 현재 검증된 원문·본인 발화를 활용하는 구성 예시이며 미확인 개인 역할을 만들어 주지 않는다.
